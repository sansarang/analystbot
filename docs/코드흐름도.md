## 🔴 이어지면 안 되는 길 (코드가 막는다)

```
 Elo(BaseProb) ───✗──▶ λ·확률        → ⑫ 검증(V1)으로만
 시장(MarketProb) ─✗──▶ λ·확률·**등급** → ⑫ 표시만(C12 · `grade_step` 삭제)
 시나리오 ────────✗──▶ **생존**        → 생존은 시뮬 분포에서(R7)
 규칙(T1~T13) ────✗──▶ λ 직접         → **축 경유만**(R4)
 LLM 문장 ───────✗──▶ direction·weight·strength·survival·verdict
 변수 ──────────✗──▶ 로그 오즈(③ 이동) → C7 로 경로를 지웠다
 원장(ledger) ───✗──▶ 규칙·문턱·가중치  → 검증에만
 V3·V4(말·일정) ──✗──▶ λ·확률          → 검증 줄로만(P2 · 2026-10-12)
 반증(⑫b) ───────✗──▶ λ·확률          → 등급만(C2) · 되돌림 경로만 예외(1회)
 상태 배율 ───────✗──▶ 축3 합산        → ⑪ 시뮬에서만(S1 · 한 표)
 우선순위 지수 ───✗──▶ 축0 값          → 근거 줄·K5 입력만(P1)
 "현재 상태"(순위표·시즌 누계·명부) ─✗──▶ 재현의 λ·확률 → 표시만(L2)
 as_of 이후 경기 ─✗──▶ 어떤 목록       → `fotmob.before_as_of` 한 문(L1)
```

## 🔴 C4 — **상성 우위와 방향**(사용자 결정 2026-10-12)

```
 상성 기여의 λ 이동 방향  ===  상성 우위 팀 쪽        ← C4 는 **이것**을 센다
 최종 확률(= 상성 + 홈 이점 상수)                     ← 반대일 수 있다
   └ 반대면 카드가 적는다: "상성 X 우위 · 홈 이점이 뒤집음(배율 홈 ×a · 원정 ×b)"
```
⚠️ 옛 C4(*"상성 우위 = 최종 확률이 높은 팀"*)는 **홈 이점이 큰 경기에서 늘 깨진다** —
   그래서 바꿨다(실측: K리그1·친선에서 상수가 작은 축 우위를 뒤집었다).

## 한 몸인지 보는 법 (같은 수가 두 칸에 나오는가)

| 이어짐 | 앞 칸이 낸 것 | 뒤 칸이 받은 것 | 카드에서 맞대 보는 자리 |
|---|---|---|---|
| ③→⑨ | 라인업 **상태**(확정/예상) | 축0·축2 근거 | `📋 라인업 …` ↔ `MatchupReport` 축0·축2 `근거 변수` |
| ④→⑨ | 깃발 **r** | 축1·축3 경기 가중 | `TURN-*` ↔ `r 가중 {home, away}` |
| ⑥→⑨ | 자리별 변수 | 축의 근거 변수 | `🔢 변수` 자리 ↔ 각 축 `근거 변수` |
| ⑨→⑪ | **홈·원정 특징**(att·dfn) | λ홈·λ원정 | `MatchupReport` 축값 ↔ `🎯 상성 확률` 의 `λ 이동 홈/원정` |
| ⑪→⑫ | ProbOut(λ·xg·over) | 가설 신호의 시뮬 값 | `🎯 상성 확률` ↔ `🧪 검증표` 의 `시뮬 x.xxxx` |
| ⑪→⑭ | **스코어 분포** | 보드 생존 | `🎲 시뮬` ↔ `7. 보드 대입` 생존 |
| ⑫→⑬ | supported | 시나리오 근거 | `🧪 검증표` ✅ ↔ `6. 시나리오` `← 근거` |
| ⑫→⑭ | grade | 등급 | `등급 조정` ↔ `7. 보드` 등급 |

⚠️ 어느 칸이든 **못 받으면 0 이 아니라 사유**가 들어간다(#3) — 카드에 `⬜` 와 까닭이 남는다.
