## §1 설계 — 🔴 **이것이 뼈다**(사용자 지시 2026-10-18)

> **지난경기를 가지고 오늘를 예측해서 확률를 내는거다** .. 지난경기의 자료를
> 가지고 **오늘 경기에 대입하는거다** .. **경기력**이고 .. **오늘 경기력의
> 변수는 오늘 라인업·날씨·피로도 등**이다

```
과거 5경기 = 경기력(실력)   →  오늘에 대입  →  확률의 바탕   ×1.05
오늘 변수(라인업·피로도)     →  그 바탕을 조정               ×1.03
```
크기는 `config/variable_routing.yaml` 의 `lambda_rules.by_layer` 가 든다
(`past` 1.05 · `today` 1.03 · `past_types` 목록).

### 확률은 한 곳에서 난다 — `probmodel.flat_prob`
```
① 홈·무·원정 = 1/3 씩
② 변수마다 한쪽 ×(층 크기) · 반대쪽 ÷(층 크기)
   🔴 버리는 것 — 기사 변수(from_doc) · 맥락 전용 · 자리가 축·λ상수가 아닌 것
   🔴 **자리(배치표)와 λ 보정표에 둘 다** 있어야 센다(한쪽만으론 0)
③ 순 쏠림 단계만큼 무를 ÷1.05^n
④ 정규화
```
