# MOD-1 영향 지도 — ⑪이 쓸 확률을 흐름이 스스로 만든다

## 1. 무엇이 틀렸나 (실측 원문)

`pick_ledger.model_probs` 가 **1,382행 전건 NULL** 이고, 그래서 ⑪의 구조 후보가
0 이었다(Phase 0 D-6).

원인을 코드에서 찾았다:

```python
# app/pipeline.py:3763
if sport in BASEBALL_SPORTS:
    # 🔴 [SEND-1 결정 B-1 2026-09-13] **야구는 이 분기를 탄다** —
    #    아래 `continue` 로 λ 경로를 건너뛰므로 …
    jg["lam"] = None
    jg["lambda_missing"] = []
    jg["h2h_lambda_unused"] = True
```

캐시가 그 모양 그대로다: `lam=null · lambda_missing=[] · model_valid=False`.

그런데 **λ 모델은 멀쩡하다.** 캐시 재료로 직접 돌려 봤다:

```
g10085 λ home=3.486 away=4.378  missing=[]
   · 기본 λ 4.40 (리그 평균 득점)
   · home 타선 xwOBA 0.302 → 양 팀 평균 ×1.004
   · home 상대 선발 허용 xwOBA 0.300 → ×0.938
마켓 키: ['f5', 'h2h', 'lambda', 'spreads', 'totals']
```

**팀토탈이 없다.** 그런데 그 함수는 이미 `score_pmf(lam_away)` 를 갖고 있다 —
원정 팀토탈 언더 3.5 는 그 분포의 `P(X ≤ 3)` 이다. **새 가정이 0이다.**

## 3. 영향 지도 5문

**① 09-13 결정을 되돌리나.**
🔴 **아니다.** `pipeline.py` 의 그 분기는 **손대지 않는다.** 그것은 옛 발송
경로의 확률을 정하는 결정이고, 되돌리면 KBO·NPB·MLB 보드의 `p_send` 가 바뀐다.
v1.4 흐름은 별도 경로이므로 **거기서 따로 계산한다.**

**② 팀토탈에 새 가정이 드나.**
안 든다. `mlb_market_probs` 는 이미 양 팀 득점 pmf 를 만든다(`ph`·`pa`).
팀토탈은 그 pmf 의 꼬리 합일 뿐이다 — 새 계수도 새 분포도 없다.
계약이 "λ 가 크면 언더가 낮아진다"와 "같은 λ면 같은 값"을 확인한다.

**③ 기본 라인은.**
반 점만 만든다. 정수 라인은 푸시가 생겨 오버/언더 합이 1이 아니고,
`_default_total_lines` 머리말이 이미 그 이유를 적고 있다 — 같은 규칙을 쓴다.

**④ 정확도 목표가 있나.**
🔴 **없다.** 지시문 3-4 의 교정 원칙 그대로다 — 목표는 **"None 대신 숫자가
⑪에 도달"** 이다. 계수는 이미 `rules.yaml`·`settings` 에 있고
**30건 채점 전에는 바꾸지 않는다.**

**⑤ 무엇이 조용히 0이 되나.**
캐시가 없거나 `missing` 이 차면 λ 가 안 선다. 그때 **None 이고 사유를 로그로
남긴다** — "모델이 없다"와 "안 불렀다"는 다르다. 마켓 배당이 없으면 ⑪이
`edge` 를 못 내는데, 그건 2-1(ODN-3 적재) 의존이고 따로 보고한다.

- 계수를 만지지 않는다(30건 채점 전 동결).
- 축구 λ(`soccer_lambdas`)를 건드리지 않는다.
