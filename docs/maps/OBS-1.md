# OBS-1 — 상시 관측 모드: 24시간 보되 대부분 침묵한다 (Part 4)

## 왜

지금 봇은 "슬레이트 전체를 시각에 맞춰 한 번 판정하고 발송"한다. 페이블
방식은 반대다 — **모든 경기를 계속 보되 대부분은 침묵하고, 조건이 갖춰진
소수만 단계적으로 올려서, 라인업 확정 후에 최종 한 번 말한다.**

실측(오늘): 축구 20경기 관측 → 후보 6 → 라인업 확정 후 최종 2.

그리고 이 구조가 **오늘 잰 결함을 직접 막는다.** 추천 게이트가 괴리 큰 경기를
골라 담아 적중 0.273(n=11)이었다 — 조건 B 가 "라인업 확정 전엔 말하지 않는다"와
"불리한 변화가 있으면 취소"를 넣어 그 자리를 막는다.

## ① 이 함수/상태를 읽는 곳 **전부**

새 모듈이라 지금은 없다. 앞으로:
```
상시 루프(1분)   next_state · cond_a · cond_b · dispatch_for
카드·발송        dispatch_for 가 "최종"|"취소"|None 을 준다
원장             promoted_at · finalized_at · cancel_reason
```
빌려 쓰는 원본 — 새로 만들지 않는다:
| 무엇 | 원본 |
|---|---|
| 동시 실행 상한 | `triggers.MAX_CONCURRENT` — **같은 객체**를 쓴다(계약이 `is` 로 단언) |
| 시점 | `triggers.KINDS` |
| 이동 분류 | `odds_move.NEWS`·`MONEY`·`CONTRA` |
| 게이트 분류 | `gate.OVER`·`DOUBT`·`AGREE` |
| 확신 등급 | `confidence.by_code` |

## ② 만드는/바꾸는 상태

| 상태 | 성격 |
|---|---|
| `app/engine/observer.py` | 새 **순수 함수** 모듈(상태 기계·조건) |
| `games.watch_state` | 한 칸 |
| 원장 `promoted_at`·`finalized_at`·`cancel_reason` | 세 칸 |

🔴 **상태 전이는 코드만 한다.** LLM 출력은 조건 A·B 의 **입력일 뿐**이다.
   여기서 LLM 을 부르면 그 자리가 판정이 된다 — 계약이 임포트를 잠근다.
🔴 **최종은 경기당 한 번이다.** 재판정 카드·수정 카드가 없다.
🔴 **라인업 확정 전엔 말하지 않는다**(조건 B-1). 잠정 발송이 없다.

⚠️ 실제 발송 규칙 변경(기존 슬레이트 일괄 카드 → 보드 요약 1건)은 **이 단위에
   없다.** 상태 기계와 조건까지다 — 발송 경로를 바꾸는 것은 카드가 안 나가는
   P0 위험이 있어 별도 단위로 간다.

## ③ 리그·종목·경로 분기

없다. 야구는 "라인업 확정" = 타순 발표, `midweek` = 이동연전·연투로 **입력의
이름만** 다르다. 상태·조건은 같다(지시문 7-6).

## ④ 조용히 실패하는가

| 위험 | 대응 |
|---|---|
| 🔴 **잠정 발송이 나간다** | 조건 B-1 `xi_status == official` 필수 + 계약 |
| 🔴 `contra` 를 놓친다 | **어떤 상태에서든** 즉시 취소. 전 상태 전수 계약 |
| 취소·종료에서 되살아난다 | 두 상태는 고정 + 계약 |
| 이유 없는 괴리가 후보가 된다 | 조건 A-2: 결장·일정·폼 사실 1개 이상 필수 |
| 확신 `하` 가 나간다 | 조건 B-6 + 계약 |
| 라인이 움직였는데 옛 우위로 낸다 | 조건 B-5: 새 라인에서 다시 +6%p |
| 검색이 24시간 돈다(예산) | `uses_search` 가 **후보 이상**에서만 참 + 계약 |
| 상한을 두 곳에 적는다 | `triggers.MAX_CONCURRENT` 를 **같은 객체**로 참조 |
| 재판정 카드가 또 나간다 | `dispatch_for("추천","추천") is None` + 계약 |

⚠️ **아직 못 잰 것**: 완료 조건(관측 20 → 후보 6 → 추천 2)은 **티어가 채워지고
   축구 배당 시계열이 하루 쌓여야** 돈다. 오늘은 축구 배당이 어제까지 0건이었다.
⚠️ 추천 비율 5~15% 는 **7일 집계**로만 확인된다.
