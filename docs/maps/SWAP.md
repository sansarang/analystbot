# SWAP — 구경로를 흐름으로 바꿔 끼운다 (영향 지도 5문)

사용자 2026-09-22: **"바꿔끼우기 진행해라… 버그가 있어서도 안 되고
옛 경로로 가서는 안 된다"**

## ⓪ 지금 상태 — 실측

```
흐름 1회 (2026-09-22 21:5x)
  games 19 · stopped {n11_no_value: 16, n06_unknown: 3} · sent 0

누적 스냅샷 (analysis_runs)
  n01_prior 152경기 → n03_gate 152 → n04_hyp 111 → n06_verdict 111
  → n07_adjust 54 → n11_value 54 → n12_text 6 → n13_send 2
```

**흐름은 13노드가 전부 돌고 사유별로 멈춘다.** 구경로는 `판정 실패` 하나로
뭉뚱그렸다. 기능상 흐름이 더 완전하다 — 구경로에 없는
**사전값(n01)·게이트(n03)·가설(n04)** 이 흐름에는 있다.

## ① 무엇이 끊기나 — 바꿔 끼울 때 이어야 할 것 넷

| # | 끊기는 것 | 왜 |
|---|---|---|
| **A** | **원장** | 흐름은 `analysis_runs`(노드 스냅샷)만 쓴다. `pick_ledger` 는 **읽기만** 한다 → 채점(`grade_pending`)·CLV·`decision_ledger` 가 흐름 판정을 못 본다 |
| **B** | **위성 게이트** | `satellite.py:1050` 이 `pick_ledger.gate_of`(**구경로**)에서 라벨을 받는다. CLAUDE.md 가 "순서가 끊겨 있다"고 지목한 그 자리 |
| **C** | **카드** | 텔레그램 카드는 `engine.card.build_card` 가 구경로 산출물로 만든다. 흐름은 **자체 4문장**(`n12_text`)을 낸다 |
| **D** | 오늘 수정 | `CODE-V`·`NOLLM` 은 전부 구경로 수정이다 — 흐름으로 가면 쓸모가 줄어든다 |

## ② 순서 — **한 걸음씩, 각각 1커밋**

```
SWAP-1  흐름이 판정을 원장에 남긴다        ← 채점·성적표가 생긴다. 이게 먼저다
SWAP-2  위성 게이트를 n03_gate 로          ← CLAUDE.md 가 지목한 단절 해소
SWAP-3  카드를 흐름 산출로                  ← n12_text + 구조를 카드에
SWAP-4  구경로를 **스위치로 끈다**          ← 지우지 않는다
SWAP-5  한 슬레이트 관측 후 삭제 판단
```

🔴 **SWAP-1 이 먼저인 이유**: 원장이 없으면 "흐름이 더 나은가"를 **잴 수가 없다.**
   오늘 만든 `decision_ledger`·지표 모듈이 바로 그 자리다.
🔴 **구경로를 지우지 않는다** — 사용자 지시는 "옛 경로로 가서는 안 된다"이지
   "지워라"가 아니다. 스위치로 끄면 되돌릴 수 있고, 되돌릴 수 없는 변경은
   버그가 났을 때 밤에 복구할 방법이 없다.

## ③ 무엇이 깨질 수 있나

- 🔴 **발송.** `pipeline_v14_send=false` 다. **이 값을 건드리지 않는다** —
  전환과 발송은 다른 결정이다. 계약이 이 값을 잠근다.
- 🔴 **깔때기가 좁다.** 흐름은 19경기 중 **16건을 ⑪가치에서 멈춘다.**
  카드를 흐름으로 바꾸면 **카드 수가 급감할 수 있다.** 전환 전에 그 분포를
  보고하고, 줄어드는 것이 의도인지 확인받는다.
- ⚠️ 흐름의 `n12_text` 는 **LLM 을 부른다**(4문장 규격). 오늘 지시("서술은
  템플릿")와 충돌한다 → SWAP-3 에서 같이 정리한다.
- ⚠️ `analysis_runs.run_id` 는 **uuid** 다. 조회 코드가 문자열로 다루면 터진다
  (실측: `operator does not exist: uuid ~~ unknown`).

## ④ 롤백

각 단계가 **스위치 한 줄**이다. 코드를 지우지 않으므로 어느 단계에서든
되돌아갈 수 있다.

## ⑤ 완료 조건 (단계별)

- **SWAP-1**: 흐름 판정이 원장에 남고, 같은 경기를 구경로와 **나란히** 비교하는
  표가 나온다(승자 일치율 · p 차이). 전체 스위트 통과.
- SWAP-2: 위성이 `n03_gate` 라벨을 본다. 두 게이트 값이 같은지 실측 표.
- SWAP-3: 카드가 흐름 산출로 나온다. 카드 수 변화 보고.
- SWAP-4: 구경로 스위치 off. 한 사이클 실측.

## ⚠️ 오늘 밤에 하는 것은 **SWAP-1 까지**

전환 전체를 한 번에 밀면 버그가 난다. 사용자 지시가 "버그가 있어서도 안 된다"
이므로 **한 걸음씩 간다.**
