# THR-1 — 잡음 문턱 하나가 **야구 결장 한 명을 구조적으로 배제한다**

## 왜

실측 2026-09-17:
```
딥서치 결장 1명 → 1.5%p → 문턱 2.0 아래 → 버림 → changed=False
        2명 → 3.0%p → 반영
```
오늘 딥서치가 **"서호철 1군 말소"·"고종욱 1군 말소"** 를 찾아냈는데 **가감은 0**
이었다. 야구는 결장이 대개 **한 명씩** 난다.

**딥서치로 크기를 확인했다**(→ `docs/FORKS.md` F-10). WAR 는 "그 선수를 잃으면
시즌 순위가 몇 경기 떨어지나"다 — 경기당으로 나누면:
```
평균 주전 WAR 2   → 1.2%p
좋은 주전 WAR 4   → 2.5%p
역대급   WAR 11.5 → 7.1%p
```
→ **1.5%p 는 "평균 주전" 자리다. 크기는 맞다.**
→ 틀린 것은 **문턱**이다. `2.0` 은 **WAR 3.2 미만을 전부 버린다.**

⚠️ **축구는 다르다.** F-1 에서 찾은 "확정 라인업 변경 하나 = 승률 **2~9%p**" 는
   이 문턱을 넘는다. **같은 값 하나가 두 종목에 다르게 작동하고 있었다.**

사용자 지시 2026-09-17: **"해제하고 고쳐라"** (파라미터 변경 승인)

## ⚠️ 먼저 정정 — 이 문턱이 걸리는 자리는 한 곳뿐이다

`drop_small` 의 **운영 호출부는 `rejudge.reweigh` 하나**다. `adj_pp`(S7)는
이 문턱을 **안 거친다.** 그래서 이 수정이 고치는 것은 **재판정(S10) 경로** —
딥서치·확정 XI 결장이 버려지던 바로 그 자리다.
(PA-27-a 주석의 "기존 가감은 이미 이 규칙을 통과해 들어온 값"은 부정확하다.)

## ① 이 함수/상태를 읽는 곳 **전부**

```
adjust.MIN_CONTRIB_PP        ← 기본값(축구·레거시). **값은 안 바꾼다**
adjust.min_contrib(sport)    ← **신규**. 종목별 문턱
adjust.drop_small(adj, sport) ← 인자 추가. 기본값은 종전 동작
rejudge.reweigh              ← 유일한 운영 호출부. sport 를 넘긴다
config/rules.yaml adjust     ← 값의 **원본**
scoring.BASEBALL_SPORTS      ← 종목 분류의 **원본**(prob._table 과 같은 것)
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **축구는 종전 그대로 2.0 이다.** 자료가 축구는 문턱을 넘는다고 말한다 —
  낮출 근거가 없다. 계약이 잰다.
- 🔴 **`sport` 를 안 주면 종전 동작**(2.0)이다. `drop_small(adj)` 를 부르는
  옛 코드·테스트가 안 깨진다.
- 🔴 **`MIN_CONTRIB_PP` 상수를 안 없앤다.** U13 계약이 그 이름으로 rules.yaml
  대조를 한다(`test_u13_rules`). 기본값의 이름으로 남는다.
- 🔴 **잡음은 야구에서도 버린다.** 1.0 미만(예 0.5%p)은 그대로 제외된다 —
  문턱을 없애는 게 아니라 **크기에 맞추는** 것이다. 계약이 잰다.
- 🔴 **숫자를 손으로 안 적는다.** 1.0·2.0 은 `config/rules.yaml` 이 원본이다.
- 🔴 **종목 분류를 새로 만들지 않는다** — `scoring.BASEBALL_SPORTS` 를 쓴다
  (`prob._table` 과 같은 원본).
- ⚠️ **되돌릴 수 있다.** rules.yaml 값 한 줄이다.
- ⚠️ 이 변경으로 **야구 재판정이 늘어난다**(종전 0건 → 결장 1명도 잡힌다).
  그만큼 잡음도 들어올 수 있다 — `regraded_by`·`analyze_check` 로 쌓아
  다음 표에서 본다.
