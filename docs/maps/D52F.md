사용자 결정 2026-09-22: "(가). 조건 셋. 1. `gather_kbo` 에 Bing RSS(`rss_hits`)
를 잇는다. 같은 커밋에서 NPB(`_yahoo_fetch`)·MLB(transactions+tor) 는 건드리지
않는다 — 오늘은 KBO 하나만. 2. 계약 두 개를 추가한다 — '차단'과 '대체'를 둘 다
시험한다. 3. 배포는 16:30 전."

## ① 무엇이 틀렸나 (실측)

```
2026-09-22 10:29 KST · 오늘 경기 KT Wiz @ SSG Landers (18:30 KST)
  gather_kbo → 기사 0건   (search.daum.net 8회 전부 SourceDisabled)
  gather_npb → 기사 9건
```

DEC-2(2026-09-21)가 `daum_search` 를 끄면서 적은 문장:

> "DS-3 이 `rss_hits` 를 Bing 으로 갈았으므로 **대체가 이미 있다.**"

🔴 **그 문장이 틀렸다.** `rss_hits` 를 부르는 경로는 축구 하나뿐이었다
(`satellite_soccer.gather_soccer` → `rss_supplement` → `rss_hits`).
`gather_kbo` 는 `_daum_fetch` 만 썼다. **만들었지만 KBO 는 아무도 안 이었다.**

정정 문구(사용자 지시 — 삭제가 아니라 정정):
**"대체가 이미 있다" → "대체 함수는 있었으나 KBO 에 미연결이었다. 2026-09-22 연결."**

⚠️ 같은 미연결이 MLB 에도 있다(D48). **오늘 커밋에서는 손대지 않는다**
   (사용자 지시: 별도 커밋으로 내일).

## ② 어제 계약이 왜 통과했나

'차단'만 시험했다 — `require("daum_search")` 가 요청을 막는지는 쟀다.
**막힌 자리를 무엇이 메우는지는 아무도 안 쟀다.** 5,519건이 통과했다.
이번에 추가하는 계약 2가 그 자리다.

## ④ 왜 `rss_supplement` 가 아니라 `rss_hits` 인가

`rss_supplement` 는 `scout_config.rank_and_pick` → `screen` 을 태운다.
`screen` 의 팀 선별은 `_tokens(team)` — **DB 표기(영문)** 를 제목에서 찾는다.
한국 매체 제목은 한국어다:

```
_tokens("Doosan Bears") → ["Doosan","Bears"]   제목 "두산 베어스 …" → 폐기
_tokens("SSG Landers")  → ["SSG","Landers"]    제목 "SSG 랜더스 …"  → 통과(우연)
```

10팀 중 6팀이 전량 폐기된다. KBO 는 **별칭표를 쓰는 `_mentions_team`** 이
정답이고 그것이 이미 `gather_kbo` 에 있다(SAT-12). 그래서 `rss_hits` 를
직접 태우고 **기존 선별을 그대로 쓴다.** 새 함수 0개.

⚠️ `screen` 을 한국어로 고치는 것은 축구·NPB 전부에 닿는다 — 범위 밖이다.

## ⑤ 되돌릴 수 있나

`gather_kbo` 안의 순서 하나다. `sources.daum_search.enabled: true` 로 되돌리면
다음 검색이 다시 1순위가 된다(RSS 가 0건일 때만 부르던 것이 반대가 되지는
않는다 — RSS 가 먼저다. 그 순서는 코드에 있다).

## ⑥ 틀렸을 때 누가 알려주나

계약 2건 — **차단과 대체를 따로 시험한다**:

1. `test_kbo_gather_uses_rss_when_daum_disabled` — 가짜 RSS 서버.
   다음이 꺼진 실제 설정에서 `bing.com` 으로 요청이 나가고, `search.daum.net`
   으로는 0건이고, 기사가 **0이 아니고**, 본문이 비지 않고, 귀속이 **DB 표기**다.
2. `test_disabled_source_has_wired_fallback` — 꺼진 소스마다 `fallback` 선언이
   있고, `fallback_consumers` 에서 그 함수로 **호출 그래프가 닿는다.**
   ⚠️ "함수가 존재한다"로는 D52 를 못 잡는다 — `rss_hits` 는 존재했고 축구에서
      불리고 있었다. **막힌 소비처에서 닿는가**를 본다.
   ⚠️ 대체가 없는 소스는 `fallback: none` + 사유를 적게 한다(KBO 공식 = D33).
      모른 채 비는 것과 알고 비는 것은 다르다.
