# U12 — 최종 판정·서술·발송. analyze 를 **배선한다**

## 왜

```
재현 7건:
  analyze 를 부르는 코드가 app/ 전체에 0건 — 3단(추출→스왑→서술)이 미배선
  config/fable_cases.yaml 없음 · 사례집 검색 모듈 없음
  조건 B 와 취소 통지 규칙 없음
  L2(승자·확신 글자 일치) 없음 · 금지어 목록 없음
  favored 가 v3 경로에서 안 찬다(U0-c)
```
U5~U11 이 만든 것이 **카드에 닿을 길**이 이 U 다. `analyze` 는 두 달 전에
만들어졌는데 호출부가 0건이었다.

## ① 이 함수/상태를 읽는 곳 **전부**

```
analyze.build_input · l1 · swap · to_ledger · SCHEMA   ← 지금까지 테스트만 불렀다
(신규) analyze.l2 · BANNED
(신규) cases.similar · config/fable_cases.yaml
(신규) dispatch_rule.condition_b · cancel_notice

```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **발송을 켜지 않는다.** 이 U 는 `analyze` 를 배선하고 조건 B 를 계산해
  **원장에만** 남긴다. 실제 경로 전환은 U14 다(섀도 7일 뒤).
  지금 켜면 검증 없이 카드가 바뀐다.
- 🔴 `analyze` 는 **LLM 호출**이다. 게이트 대상에만 돌린다 — 전 경기에 돌리면
  무료 한도가 즉시 터진다(CHN-1 실측: groq 8,000 TPM).
- 🔴 `main_axis` 는 **U8 코드 값이 정본**이다. analyze 값과 다르면 원장
  `axis_disagree` 에 남기고 **코드 값을 쓴다**. LLM 이 결정축을 바꾸면
  P0-1 에서 고친 구조가 다시 깨진다.
- 🔴 `favored` 복사(U0-c)는 **predicted_side 를 그대로** 넣는다. 새 계산을
  하지 않는다 — 두 칸이 갈리면 채점이 어느 쪽인지 모른다.
- ⚠️ 사례집 값은 **사용자가 채운다**(24건). 골격만 만든다.

## ③ 되돌리기

커밋 1개 revert. 새 모듈 둘(`cases.py`·`dispatch_rule.py`) 삭제,
`config/fable_cases.yaml` 삭제. `analyze` 배선은 호출 한 곳이라 떼면 종전처럼
미배선으로 돌아간다. 발송 경로를 안 건드렸으므로 카드는 그대로다.
