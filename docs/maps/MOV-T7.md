## ⓪ 실측 — 지금은 이유를 찾으려는 시도조차 없다

```
3%p 이상 움직인 20경기  →  **20/20 전부 "뉴스 근거 없음"**
  g1752 KT@한화 16.62%p · g1750 SSG@롯데 7.66%p · g9479 소뱅@오릭스 6.29%p
딥서치 로그: 발동=True · **검색=0** · 이동=0.0%p · status=capped/failed
```
`odds_move.classify` 가 스스로 적고 있다 —
`"{pp}%p 이동 — 뉴스 근거 없음(**딥서치 미실행** 또는 무소득)"`.

🔴 **원인: 가격 이동을 방아쇠로 쓰는 트리거가 없다.**
   T1 경계확률 · T2 **시장괴리**(우리 확률 vs 시장 — 시간 이동이 아니다) ·
   T3 추가확인 · T4 선발변경 · T5 라인업이상 · T6 라인업최초확정 · T0 전수.

## ③ 무엇이 깨질 수 있나

- 🔴 **조사가 늘어난다.** T0_전수가 이미 붙으므로 트리거 수는 늘어도 **조사
  횟수는 안 늘어난다**(경기당 1회 · 중복 키 · 상한 그대로). 늘어나는 것은
  **이유 문구의 정확도**다. 계약이 상한을 안 건드리는지 확인한다.
- ⚠️ **이동을 못 재면 트리거를 안 건다.** 0 으로 채우지 않는다 —
  "안 움직였다"와 "모른다"는 다른 말이다(`record_move` 와 같은 규약).
- ⚠️ 측정이 DB 를 한 번 더 읽는다. 경기당 1회이고 `odds_snapshots` 조회다.
