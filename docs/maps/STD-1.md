# STD-1 — **팀 성적이 분석에 없다** (목표 분석의 첫 축)

## 왜

사용자 목표 분석(2026-09-17)의 첫 축:
> "팀 축: 격차 극대. **KIA .544(4위**, LG 추격·두산 방어 동기 살아있음)
> vs **키움 .352(최하위, 3연패)**"

우리 상태: 순위·승률 테이블이 **없다**(`team_standings`·`standings`·
`elo_ratings` 전부 부재 — 실측).

🔴 **그런데 새 소스가 필요 없다.** `games` 에 종료 경기가 있다:
```
mlb 496 · kbo 259 · npb 195 · soccer 121   (종료·점수 있음)
```
그걸로 뽑으면 **KIA .551(3위) · 키움 .373(9위)** 가 나온다 — 사장님 값
(.544/.352)과 가깝다.

⚠️ **차이는 보유 창 때문이다.** KBO 는 2026-06-28 부터만 있다(시즌 3월 시작).
   그래서 이건 **"시즌 순위"가 아니라 "보유 구간 성적"** 이다.
   🔴 **그렇게 밝혀 적는다.** 없는 것을 있다고 쓰면 그게 곧 거짓 재료다.

## ① 이 함수/상태를 읽는 곳 **전부**

```
app/engine/standings.py        ← 신규. **순수 함수**(DB·HTTP 안 부른다)
  table(rows)                  ← 종료 경기 목록 → 팀별 성적·순위·연승연패
  line_of(st, team)            ← 한 줄 글자
pick_ledger.record_confirm_and_analysis ← 종료 경기를 읽어 blk 에 싣는다
analyze.build_input            ← [팀 성적] 줄
analyze.fact_words (ANL-6)     ← 팀명·연승연패가 사실 낱말이 된다
games(status='final')          ← 유일한 재료. 새 소스 없음
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **순수 함수다.** `report.py` 와 같은 규약 — 행 목록을 받아 표를 돌려준다.
  그래야 DB 없이 테스트가 돈다. 계약이 잰다.
- 🔴 **"보유 구간"이라고 밝힌다.** 창 시작일과 경기 수를 함께 적는다 —
  시즌 순위인 척하지 않는다.
- 🔴 **무승부를 승률에서 뺀다**(야구 관례: 승/(승+패)). KBO·NPB 는 무승부가 있다.
- 🔴 **경기가 없으면 빈 표다.** 0으로 채우지 않는다 — 0.000 과 "모름"은 다르다.
- 🔴 **종료·점수 있는 경기만.** 진행 중·취소를 세면 성적이 거짓이 된다.
- 🔴 **양 팀이 다 없으면 줄을 안 쓴다**(ANL-5·ANL-9 와 같은 규칙).
- ⚠️ `l1` 의 숫자 검사 기준이 넓어진다(승률·경기 수). 입력에 있는 사실이므로
  인용 허용이 맞다 — ANL-5·ANL-9·MKT-4 와 같은 판단이다.
- ⚠️ **동기(순위 싸움)는 안 만든다.** 잔여 경기·매직넘버가 없으면 지어내는
  것이다. 목표 분석의 "LG 추격·두산 방어"는 이번 범위 밖이다.

## ③ 되돌리기

커밋 1개 revert. 새 파일 하나 · blk 한 칸 · 렌더 한 줄.

## ④ 측정

①과 **같은 명령**이 통과한다. 그리고 운영에서 KBO 표를 뽑아 사장님 값과
대조한다(⑨).

## ⑤ 계약

빈 입력이면 빈 표 · 종료 경기만 · 입력 블록에 들어감 · **"보유 구간"을 밝힘** ·
양 팀 없으면 줄 없음 · fact_words 가 안다 · DB·HTTP 안 부름.
