# U11 — T-60 재판정 완성. diff 를 **다시 계산에 넣는다**

## 왜

`fotmob.diff_xi` 는 이미 `bench_notable`·`surprise_in` 을 낸다. 그런데
`_lineup_recheck` 는 그것을 **game_trace 에 적고 끝난다.** 확정 라인업이
예상과 달라도 `p_code` 도 등급도 그대로다 — T-60 재판정이 이름뿐이었다.

```
재현 4건:
  app/engine/rejudge.py 가 없다
  원장에 adj_after · p_code_after · grade_after 칸이 없다
```

## ① 이 함수/상태를 읽는 곳 **전부**

```
(신규) rejudge.reweigh · starter_changed
fotmob.diff_xi          ← bench_notable · surprise_in (입력)
adjust.contrib_out · contrib_return · drop_small · axes        ← U8
prob.p_code · shrink_and_cap                                   ← 재계산
confidence.CODE_HIGH_P · CODE_MID_P · cap_by_snippet           ← 등급
scheduler._lineup_recheck                                      ← 호출부
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **원래 값을 덮지 않는다.** `adj`·`p_code`·`grade` 는 그대로 두고
  `*_after` 를 따로 남긴다. 덮으면 "판정이 어떻게 바뀌었나"를 잃는다.
- 🔴 **복귀는 결장의 반대가 아니다.** 예상 결장이 실제로 뛰면 `+`(U8 의
  ×1.5×1.5), 예상 선발이 빠지면 `−`(×1.5). 한 규칙으로 뭉치면 둘 중 하나가
  거꾸로 간다.
- 🔴 `p_code_after` 도 **승률 상한**을 지난다(`prob.p_code` 를 그대로 쓴다).
  재계산이 상한을 우회하면 그 경기만 규칙 밖이 된다.
- 🔴 diff 가 **비어 있으면 아무것도 안 바꾼다.** `after == before` 이고
  `changed=False` 로 남는다(조용한 0 금지).
- 🔴 시장값을 **다시 읽지 않는다.** `p_code − Σ축소(adj)` 로 되짚는다 —
  재판정이 배당을 또 긁으면 요청이 는다.
- ⚠️ 야구 `starter_changed` 는 **예고 선발 vs 실제**다. 축구 XI diff 와 이름이
  달라 섞이면 안 된다(한 명 vs 열한 명).
