# U3 — 사전값 정합. 티어 미기입은 중앙값이 아니라 **없음**이다

## 왜

```
team_elo(None) → elo=1560.0 src='tier:미기입'      ← 중앙값(3)으로 메운다
티어 파일 11개 · 빠진 것 ['eredivisie','jleague2','kleague2','ligue1']
load_tiers('acl') → 0팀                            ← 키가 'teams:' 라 안 읽힌다
form_pp(WWDWD) = 4.0  (기대 2.0)                   ← 무패/무승 ±2 가 없다
form_pp(LDLDL) = -4.0 (기대 -2.0)
```
티어가 비었는데 **리그 중앙(1560)** 으로 계산하면, 채운 팀과 안 채운 팀이
같은 근거를 가진 것처럼 보인다. 리즈 사례가 그 결과였다(`config/tiers/epl.yaml`
키 `"Leeds"` vs DB `"Leeds United FC"` → 미기입 → 중앙값 → 게이트 오분류).

🔴 `acl.yaml` 은 **ACL-1 에서 내가 키를 틀렸다** — `teams:` 로 썼는데
   `load_tiers` 는 `tiers:` 를 읽는다. 그래서 ACL 티어는 처음부터 0팀이었다.

## ① 이 함수/상태를 읽는 곳 **전부**

```
prior.team_elo      ← pick_ledger.record_prior (유일 호출부, 736행)
prior.load_tiers    ← record_prior · 계약(test_prior)
prior.form_pp       ← record_prior
prior.TIER_DEFAULT  ← team_elo 안에서만
config/tiers/*.yaml ← load_tiers
p_prior·prior_src   ← pick_ledger._PRIOR_SAVE → 게이트(gate.py)
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **`team_elo` 가 None 을 돌려주면 호출부가 터질 수 있다.** `record_prior`
  가 `soccer_prior(th, ta)` 로 바로 넘긴다 — None 이면 TypeError.
  → 호출부에서 **먼저 막고** `p_prior=None, prior_src="none"` 으로 끝낸다.
  계약이 "미기입이면 p_prior 가 NULL"과 "예외가 안 난다"를 함께 본다.
- 🔴 **게이트가 p_prior=None 을 못 다루면 경기가 통째로 빠진다.** U4 가
  `보드고정` 분류를 넣기 전까지는 `gate` 가 None 을 어떻게 읽는지 확인만 한다
  (U3 에서 게이트를 고치지 않는다 — 한 U 한 변경).
- ⚠️ `form_pp` 를 ±2 로 나누면 **기존 ±4 경로가 약해진다.** 전승·전패만 ±4 다.
  실측 근거가 없는 값이므로 지시문 값을 그대로 쓰고 출처를 주석에 남긴다.
- ⚠️ 새 티어 파일 4개는 **골격만** 만든다. 값은 사용자가 채운다(추측 금지).
