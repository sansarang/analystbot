# PRI-1 — 사전값(티어 + 올해 성적). 검색 **전에** 확정한다.

지시문 Phase 2. 허가 범위: `config/tiers/{league}.yaml` · `app/engine/prior.py`
(신설) · 테스트 · 원장 두 칸.

## 왜

지시문이 정의한 6단계 중 **② 사전값**이 봇에 없는 유일한 부품이다.
그리고 핵심 원칙이 둘 적혀 있다:
- **사전값은 검색 전에 확정한다.** 검색 후 적으면 뉴스 어조에 끌린다.
- 가감은 사실 기반·크기 고정. **LLM 은 크기를 정하지 않는다.**

## ① 이 함수/상태를 읽는 곳 **전부**

새 모듈이라 지금은 없다. 앞으로 읽는 곳은 **둘뿐**이고 그 경계가 이 수정의 핵심이다:
```
Phase 3 gate.py      gap = p_prior − p_market   ← 딥서치 대상 선정
카드 서술             "내 사전값 h/d/a"           ← 표시
```
🔴 **`p_code` 는 `p_prior` 를 읽지 않는다**(지시문 금지 사항 · 3차 결정 G).
   계약이 `prob.p_code`·`prob.p_send` 소스에 `p_prior` 부재를 단언한다.

빌려 쓰는 원본:
| 무엇 | 원본 |
|---|---|
| 리그 목록 | `app/leagues.py` (계약이 파일 존재를 전수 대조) |
| 승률 절사 | `scoring.cap_probability` — 야구 0.32~0.68 |
| 팀 표기 | 운영 `games` — 골격을 그 표기로 만들었다 |

## ② 만드는/바꾸는 상태

| 상태 | 성격 |
|---|---|
| `config/tiers/*.yaml` 10개 | **골격만.** 값은 전부 `null` — 사용자가 채운다 |
| `app/engine/prior.py` | 새 순수 함수 모듈 (DB·HTTP 없음) |
| 원장 `p_prior`·`prior_src` | 두 칸 |

🔴 **티어를 추측해 채우지 않는다**(지시문 Phase 2-1 명시). `null` 은 계산에서
   **리그 중앙(3)** 으로 처리하고 `prior_src="tier:미기입"` 으로 그 사실을 남긴다.
   0 이나 평균으로 조용히 메우면 "채웠는지 안 채웠는지"를 영영 모른다.

⚠️ **지시문과 우리 시스템의 리그 목록이 어긋난다.** 지시문은 리그1·에레디비시·
   J2·K리그2 를 요구하는데 `leagues.LEAGUES` 에 **없다**. 반대로 덴마크
   수페르리가는 우리에만 있다. 골격은 **우리 시스템에 있는 것**으로 만들었다 —
   없는 리그의 티어 표를 만들면 그것이 곧 사본이고 오탐이다. 보고 대상.

## ③ 리그·종목·경로 분기

축구 3-way(홈 이점 60 · 무승부 곡선)와 야구 2-way(홈 이점 25 · 절사)가
**다른 함수**다. 분기가 아니라 두 식이다 — 무승부가 있는 종목과 없는 종목은
같은 식으로 못 쓴다.

## ④ 조용히 실패하는가

| 위험 | 대응 |
|---|---|
| 🔴 **p_prior 가 p_code 에 샌다** | `prob` 소스 전수 부재 단언 |
| 🔴 미기입 티어가 조용히 평균 | `prior_src="tier:미기입"` + 계약 |
| 확률 합이 1 이 아니다(3-way) | 합 단언 |
| 무승부가 음수/과대 | 상하한 0.10~0.34 를 전 구간에서 단언 |
| 야구 절사가 풀린다 | 극단 입력에서 0.32/0.68 단언 |
| 폼 보정이 아무 때나 붙는다 | 전승·전패·무패·무승 **네 경우만**. 나머지 0 을 단언 |
| 팀 표기가 어긋나 매칭 0 | 골격을 운영 DB 표기로 생성 + 계약 |

⚠️ **아직 못 잰 것**: 지시문의 검증 기준(셀타-말라가 49~52/28~30/19~22)은
   **티어가 채워져야** 잴 수 있다. 지금은 전부 `null` 이라 사전값이 전부
   중앙값으로 나온다. **사용자가 채운 뒤 재측정한다.**
⚠️ 릴-트루아(61~65)는 **리그1이라 우리 시스템에 없다** — 잴 수 없다.

## ⑤ 사본

리그 목록·승률 절사·팀 표기를 손으로 적지 않는다. 티어 상수·공식은 지시문
2-2 를 그대로 쓰고 **여기 한 곳에만** 둔다.
