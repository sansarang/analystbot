# DS-1W — 기사 본문 열기를 런타임으로 (영향 지도 5문)

사용자 지시 2026-09-21: "이어해" (배선 5순위 · **1단만**)

## ① 범위를 먼저 쟀다 — 한 번에 할 일이 아니다

```
httpx.AsyncClient 직접 호출   33파일 · 43곳
  LLM·알림 (llm/* · notify · perplexity)        5   robots 무관(키 있는 API)
  키 있는 배당 API (espn·oddsapinet·sharp)        3   robots 무관
  🔴 웹 수집                                    23   robots 대상
```
23파일을 한 커밋에 옮기면 **무엇이 깨졌는지 못 가린다.**
그중 `fotmob`·`tor_search` 는 **사용자 결정 대기 중**이라 지금 건드리면 안 된다.

## ② 왜 `_fetch_article_body` 부터인가

`satellite.py:379`. 검색 결과에서 온 **임의 도메인**을 연다 —
**우리가 도메인을 미리 모르는 유일한 자리**다. 나머지 수집기는 도메인이
고정이라 [3] 감사에서 한 번 확인했다.

그리고 DS-3 이 소스를 Bing 으로 바꾼 뒤 여기 들어오는 도메인이 늘었다:
`osen.co.kr` · `yna.co.kr` · `mt.co.kr` · `fnnews.com` · `newspim.com` ·
`sportsworldi.com` · `ajunews.com` · `msn.com`(실측).

🔴 지금 이 함수는 **robots 검사 0건**이고 예절도 서킷도 없다.

## ③ 어디를 건드리나

`app/collectors/satellite.py` 의 **함수 하나**. 그 안의 `httpx` 를 런타임으로
바꾼다. 반환 계약(`실패하면 빈 문자열`)은 **그대로**다 — 호출부가 그것을 본다.

## ④ 사본이 생기나

- 요청·robots·예절·서킷: DS-1 런타임.
- 본문 길이 상한: `extract_body` 가 원본이다 — 여기서 다시 자르지 않는다.
  계약이 `1200` 이 이 함수에 없음을 확인한다.

## ⑤ 되돌릴 수 있나

함수 하나라 커밋 되돌리기로 끝난다. 스위치를 두지 않았다 —
robots 검사를 끄는 스위치는 두면 안 된다.

⚠️ **부작용 위험**: robots 가 거부하는 매체의 본문이 이제 안 열린다.
   그때 제목만 남고 `body` 가 빈다 → `extract_game_facts` 가
   `본문 있는 기사가 없다` 로 건너뛸 수 있다.
   **그것이 맞는 동작이다**(차단을 우회하지 않는다). 다만 몇 건이 그렇게 되는지
   배포 후 첫 사이클에서 봐야 한다.

## ⑥ 틀렸을 때 누가 알려주나

계약 5건: 런타임을 지나나 · robots 가 막으면 빈 문자열인가 · 실패해도 예외가
아닌가 · `httpx` 를 직접 안 부르나 · 상한을 베끼지 않았나.
