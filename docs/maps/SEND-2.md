# SEND-2 — 우세도 확률이 정한다. 한 카드가 두 말을 하지 않게.

## 왜 (실측, 배포 전)

SEND-1 을 켜면 **승자는 제미나이가, 확률은 시장이** 정한다. 둘이 갈리면:

```
우세 NC 다이노스 43.3%      ← 우세인데 50% 아래다
우세 삼성 라이온즈 45.6%
```
오늘 슬레이트 기준 **8경기 중 2건**이 이렇게 나간다. 아직 배포 전이라
사용자에게는 안 갔지만, 22:00 에 그대로 올리면 나간다.

원인은 `favored_side_and_p` 가 **서로 다른 뿌리에서** 둘을 꺼내기 때문이다:
```python
p    = jg["p_send"]        # 시장 + 조정 + 딥서치
side = m["우세"]            # 제미나이
```

🔴 SEND-1 의 계약 12건이 이걸 못 잡았다. "원정 우세면 뒤집어 준다"만 봤지
   **뒤집은 값이 50%를 넘는지**는 안 봤다. 그 계약을 이번에 넣는다.

사용자 결정 2026-09-13 "가": **우세도 확률에서 정한다.** 제미나이의 승자는
서술·원장에 남고, 카드의 우세 표시는 확률 한 뿌리에서 나온다.

## ① 이 함수/상태를 읽는 곳 **전부**

```
$ grep -rn "favored_side_and_p" app/
app/engine/form_card.py   정의 · 카드 안 3회
   → 우세 팀 이름 · 확률 · 별표 · 신호등 · 가치 · 추천/보드만
```
`matchup["우세"]` 를 읽는 다른 곳은 그대로다 — 원장 `favored`,
`predicted_side`(`matchup["승자"]`), 서술. **제미나이 판정은 안 지운다.**

## ② 만드는/바꾸는 상태

| 상태 | 성격 |
|---|---|
| `favored_side_and_p` 의 `side` | `p_send` 가 있으면 **확률로** 정한다 |
| 반환 `p` | 항상 우세 쪽 확률 → **50% 이상** |

🔴 **카드의 우세 팀이 제미나이와 달라질 수 있다.** 오늘이면 2건.
   그게 B-1 의 의도된 결과다 — 확률이 시장이면 우세도 시장이어야 한다.
⚠️ `p_send` 가 없으면(배당 미수집) **종전 경로 그대로**다. 분기가 아니라 폴백.

## ③ 리그·종목·경로 분기

없다. 축구도 같은 함수를 쓰는데 `p_send` 가 서면 같은 규칙으로 간다.
⚠️ 축구 3-way 의 `무` 는 이 함수가 다루지 않는다(종전에도 그랬다).

## ④ 조용히 실패하는가

| 위험 | 대응 |
|---|---|
| 🔴 **우세인데 50% 아래** ← 이번 결함 | 0.30~0.68 전 구간 × 제미나이 우세 3종에서 `p ≥ 0.5` 단언 |
| 정확히 0.5 에서 갈린다 | 0.499/0.50 을 계약에 넣는다(홈 기준 `>=`) |
| 배당 없는 경기가 깨진다 | `p_send` 없으면 종전 결과 그대로인지 단언 |
| 제미나이 판정이 사라진다 | 원장 `llm_winner`·`predicted_side` 는 안 건드린다(SEND-1 계약이 이미 잠금) |

⚠️ **아직 못 잰 것**: 우세가 갈리는 경기의 적중률. 원장에 제미나이 승자와
   코드 우세가 둘 다 남으므로 채점이 붙으면 바로 갈린다.

## ⑤ 사본

승률 상한·조정 표를 다시 적지 않는다. `p_send` 가 이미 절사된 값을 준다.
