# PA-27-d — **부분 출처가 완전한 출처를 덮는다** (FORKS F-2 · F-3)

## 왜

PA-27 이 기사 결장 명단(딥서치)을 PA-27-b 의 대체 통로에 넣었다. 그래서
**부분 명단이 `주전결장`(오늘 타순 전체 집계)을 대체한다.** 기사가 두 명만
말하고 실제로 다섯 명이 빠졌으면 −6.0 이 **−3.0 으로 줄어든다.**

딥서치로 찾은 자료(→ `docs/FORKS.md` F-2)는 반대를 가리킨다. 이건 스포츠
문헌이 아니라 **데이터 통합(MDM) survivorship** 문제였고, 표준 규칙 넷 중
둘이 같은 답을 준다:

```
Most Trusted Source Wins   공식 팀시트 > 기사    → 주전결장이 이긴다
Most Complete Wins         전체 집계 > 부분 명단  → 주전결장이 이긴다
Profisee: "완전성 규칙은 오류 위험이 높다" · "속성 단위로 규칙을 짜라"
```

F-3: 값을 모르는 선수를 1.0(평균)으로 세는 것 **자체는 자료가 지지**한다
(미측정 프로는 대체선수가 아니라 리그 평균). 그런데 **몇 명의 가치를 알았는지
가 아무 데도 안 남는다** — panna #242 가 정확히 그 함정이다.

## ① 이 함수/상태를 읽는 곳 **전부**

```
rejudge.reweigh                       ← 고치는 곳 (source 인자 추가)
rejudge.SRC_OFFICIAL/SRC_NEWS/CAN_REPLACE  ← 신규 상수. 출처 이름의 **원본**
rejudge.KEY_BASE_OUT · KEY_OUT · KEY_IN
pick_ledger.record_confirm_and_analysis    ← 유일한 호출자. SRC_NEWS 를 넘긴다
pick_ledger.REGRADE_DEEPSEARCH             ← **없앴다**(사본이었다)
db: regraded_by                            ← 값이 SRC_NEWS 와 같다
scheduler._lineup_recheck                  ← 아직 reweigh 를 안 부른다(기본값이 맞다)
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **공식 XI 는 종전대로 대체한다**(F-1). 기본값이 `SRC_OFFICIAL` 이라
  기존 호출·테스트가 그대로 돈다. 계약이 잰다.
- 🔴 **빈자리는 채운다.** `주전결장` 이 없으면 기사 명단을 그대로 쓴다 —
  축구 T-3h 판정 구간이 여기다. 물러나는 것은 **더 좋은 자료가 있을 때뿐**.
- 🔴 **얹지도 않는다.** 얹으면 PA-27-b 가 고친 이중 계산이 되살아난다.
- 🔴 **결장 축 하나만 물러난다.** 짧은휴식·복귀 등은 그대로 간다.
- 🔴 **물러난 이유를 남긴다**(`yielded_to`·`why`·로그). "조용한 0"은 결함이다.
- 🔴 **F-3 은 기록만 한다.** 값을 모른다고 벌점을 주지 않는다 — 자료가
  평균(1.0)을 지지한다. 계약이 known/unknown 결과가 같은지 잰다.
- 🔴 **출처 이름을 원장에 다시 적지 않는다.** `rejudge` 가 원본이다 —
  이름만 베끼면 **권한 없는 사본**이 된다. 계약이 잰다.
- ⚠️ 부분 출처가 물러나면 `changed=False` 라 원장에 아무것도 안 쓴다.
  그 사실은 로그에 남는다.
