# SCT-2 — 딥서치 설정: 세 가지만, 현지어로, 화이트리스트에서

지시문 Phase 4. 허가 범위: `config/search_terms.yaml` · `config/sources.yaml` ·
추출 스키마 · 테스트. **검색 엔진은 기존 통로 그대로**(그라운딩·RSS·토르 DDG).

## 왜

지금 축구 딥서치는 팀명만으로 다음 뉴스검색을 긁는다. 지시문은 **현지어
검색어**로 **화이트리스트 소스**에서 **세 가지만**(결장·예상 XI·직전 3경기)
뽑으라고 정했다. 전적·감독 코멘트·팬 반응은 `notes` 한 줄 외에는 버린다.

## ① 이 함수/상태를 읽는 곳 **전부**

새 모듈이라 지금은 없다. 앞으로 읽는 곳:
```
Phase 4 실행부   queries() · pick_sources() · validate()
Phase 5 가감     validate() 결과의 out·predicted_xi·last3
Phase 6 서술     notes
```
🔴 **위성(층1)의 `_SOCCER_TERMS = ""` 는 건드리지 않는다.** 그건 다음
   뉴스검색 채널이고, 검색어를 붙였더니 맥도날드·프로야구·연예 기사가 왔다는
   실측(2026-09-12)이 코드에 남아 있다. 여기 만드는 것은 **층2** 채널의 것이다.

빌려 쓰는 원본:
| 무엇 | 원본 |
|---|---|
| 리그 목록 | `app/leagues.py` (계약이 전수 대조) |
| 한국어 토르 거부 | `tor_search.is_tor_safe_query` — 다시 구현하지 않는다 |

## ② 만드는/바꾸는 상태

| 상태 | 성격 |
|---|---|
| `config/search_terms.yaml` | 새 표. 리그별 현지어 2개 |
| `config/sources.yaml` | 새 표. 4등급 |
| `app/engine/scout_config.py` | 새 순수 함수 모듈 |

🔴 **구단 공식 도메인(tier1)을 추측해 채우지 않는다.** 100여 개를 지어내면
   티어 표와 같은 문제다 — 빈 목록으로 두고 "사용자가 채운다"를 파일에 적는다.
   계약이 그 빈 상태와 문구를 단언한다.
⚠️ tier2·tier3 는 **지시문이 직접 준 도메인**만 넣는다. 늘리지 않는다.

## ③ 리그·종목·경로 분기

분기가 아니라 표 조회다. 다만 **한국어 검색어는 토르로 못 나간다**
(`is_tor_safe_query` 가 거부한다 — 한국 사이트가 깨지기 때문). 그래서 표가
`tor_safe(league)` 를 들고 있어야 호출부가 **조용히 0건을 받지 않는다.**

⚠️ 지시문 검색어 표에 있는 **리그1·에레디비시**는 우리 시스템에 리그가 없어
   넣지 않았다. 반대로 **덴마크**는 지시문에 없어서 **덴마크어 검색어를 지어내지
   않았다** — 영어로 두고 그 사실을 파일에 적는다. 보고 대상.

## ④ 조용히 실패하는가

| 위험 | 대응 |
|---|---|
| 🔴 스키마 밖의 것이 판정에 샌다 | `validate` 가 8칸만 남긴다. 전적·감독·팬반응 폐기를 계약이 단언 |
| 🔴 어느 팀 것인지 모르는 추출 | `team` 없으면 **버린다**(None) |
| 빈 추출을 결손으로 읽는다 | 빈 목록은 **사실이다**(결장 없음). None 과 구분 |
| 공식 도메인을 지어낸다 | 빈 목록 + 문구를 계약이 단언 |
| 쓰레기 소스를 fetch 한다 | 등급 판정 후 **상위 3개만**. 등급 밖은 제외 |
| 한국어가 토르로 나가 0건 | `tor_safe()` + 계약(`is_tor_safe_query` 와 대조) |
| 검색 호출이 는다 | 팀당 1 · 경기당 fetch 3 을 상수로 두고 계약 |

⚠️ **아직 못 잰 것**: 실제 추출 성공률. 지시문 완료 조건(헤이렌베인 `out` 4명·
   브라이턴 7명·말라가 5명)은 **지금 못 맞춘다** — 헤이렌베인은 에레디비시라
   리그가 없고, 대상 선정에 티어가 필요하다. 티어가 채워진 뒤 실행한다.

## ⑤ 사본

리그 목록·한국어 거부 규칙을 다시 만들지 않는다. 검색어·도메인은 지시문이
준 것을 **한 곳에만** 적고 코드에 흩지 않는다.
