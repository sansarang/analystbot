# ANL-6 — 사실 검사가 **거꾸로 걸린다**

## 왜

`l1` 의 사실 검사:
```python
words = {w for w in _nouns(out["결정축_근거"]) if len(w) >= 3}
if words and not (words & src):        # src = build_input(blk) 의 낱말
    return False, "결정축_근거가 입력 블록에 없는 사실이다"
```

실측 2026-09-17 — **세 가지가 동시에 틀린다:**

```
빈 근거            → 통과   (`if words and …` — 비면 검사를 건너뛴다)
'홈'               → 통과   (2자 이하도 건너뛴다)
'말소된 선수가 …'   → 반려   (입력 notes 의 '말소' 와 낱말이 안 맞는다)
'원정팀 감독이 …'   → 반려   (이건 맞다)
```
운영 실측에서도 결정축 **`'홈 사실'` 이 L1·L2 를 다 통과**했다.
→ **구체적으로 쓸수록 반려당하고, 비어 있을수록 통과한다.**

원인 셋:
1. **빈 답 면제** — `if words and` 가 내용 없는 답을 무사통과시킨다.
2. **낱말 통째 비교** — 한국어는 조사가 붙는다. `결장` vs `결장으로` 가 다르다.
3. **`src` 가 렌더된 글자**다 — `[원정 사실]`·`[경기]` 같은 **라벨 낱말**이
   섞여 있어, 라벨만 따라 써도 통과할 수 있다.

## ① 이 함수/상태를 읽는 곳 **전부**

```
analyze.l1                     ← 고치는 곳 (사실 검사 한 덩어리)
analyze._nouns                 ← 토큰화. **안 건드린다**
analyze.l1 의 숫자 검사         ← `blk_text` 를 계속 쓴다. **안 건드린다**
                                 (숫자는 렌더된 [숫자] 줄에 있다)
scout_config.EXTRACT_SCHEMA    ← 사실 칸 이름의 **원본**
analyze.run → out["l1"] → ANL-4 analyze_check → 원장
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **느슨하게만 만들면 안 된다.** 입력에 **전혀 없는 사실**은 여전히 잡아야
  한다. 계약이 그 반대 위험을 먼저 잰다("원정팀 감독이 사임했고 매각 협상 중").
- 🔴 **`src` 를 사실 값에서만 만든다.** 렌더된 글자에는 `원정`·`경기`·`사실`
  같은 **라벨**이 섞여 있어, 부분일치를 켜면 `원정팀…` 이 `원정` 에 걸려
  통과해 버린다. 값(팀명·결장자·notes·최근3…)만 모은다.
- 🔴 **칸 이름을 손으로 안 적는다** — `EXTRACT_SCHEMA` 를 돌린다.
  `source`·`published`·`fetched_at` 만 뺀다(URL·날짜는 판단 재료가 아니다).
- 🔴 **숫자 검사는 그대로 `blk_text`** 를 본다. 숫자는 렌더된 `[숫자]` 줄에
  있고, 그 기준은 바뀌면 안 된다.
- 🔴 **빈 근거는 이제 반려**다. 종전에 통과하던 것이 반려로 바뀐다 —
  **의도한 변화**이고, `l1` 반려는 원장을 막지 않는다(ANL-2 성질).
- ⚠️ 부분일치는 **미탐이 는다**(느슨해진다). 그래서 `src` 를 값으로 좁혀
  균형을 맞췄다. 두 방향을 계약이 함께 잰다.
