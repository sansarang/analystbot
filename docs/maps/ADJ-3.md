# ADJ-3 — 원정 팀 피로는 구조적으로 반영될 수 없었다

## 왜 (실측 2026-09-13)

롯데@KT: **원정 3명 연투 · 홈 1명** 인데 `adj = {}` 였다.

```python
jg["bullpen_b2b"] = max(0, b2b["home"] - b2b["away"])   # max(0, 1-3) = 0
```

`max(0, …)` 라 **원정이 더 지친 경우는 언제나 0** 이다. 오늘 조정이 붙은 2건이
전부 "홈이 더 피로한" 경우뿐이었던 것도 이 때문이다(삼성 −2.0, 세이부 −1.0).

제미나이는 같은 경기 글에 "롯데 불펜 핵심 자원들의 연투 피로 누적"이라고
썼다. **서술은 봤는데 코드 축은 비어 있었다.**

## 함께 고치지 않으면 터지는 것 — 상한이 한쪽만 막는다

```python
val = max(raw, cap) if cap < 0 else min(raw, cap)
```
`필승조연투` 의 cap 은 **−3.0** 이라 음수 쪽만 막는다. 입력을 부호 있는 값으로
바꾸는 순간 원정 9명이면 `max(+9.0, −3.0) = +9.0` — **절사 없이 통과**한다.
실측:
```
bullpen_b2b = -3  →  +3.0      (상한 3 인데 통과)
bullpen_b2b = -9  →  +9.0      🔴
bullpen_b2b = +9  →  -3.0      (이쪽만 막힌다)
```
그래서 **상한을 크기(절댓값)에 건다.** 기존 동작은 그대로다 — 지금까지 입력은
전부 0 이상이었고, 그 구간에서 두 식의 결과가 같다(계약이 단언).

## ① 이 함수/상태를 읽는 곳 **전부**

```
$ grep -rn "bullpen_b2b" app/
app/engine/adjust.py   attach 안 1회 (쓰기)
app/engine/prob.py     ADJ_RULES["baseball"]["필승조연투"] = ("bullpen_b2b", -1.0, -3.0)

$ grep -rn "adjustments(" app/
app/pipeline.py        _attach_market_spine 1회   ← 유일한 호출부
```
`adjustments` 의 상한 로직은 **표 전체**(주전결장·필승조연투·이동연전·선발변경,
축구 4종)에 걸린다. 그래서 회귀 위험이 이 수정의 핵심이다.

## ② 만드는/바꾸는 상태

| 상태 | 성격 |
|---|---|
| `jg["bullpen_b2b"]` | `max(0, h−a)` → **부호 있는 `h−a`** |
| `prob.adjustments` 상한 | 한쪽 → **크기 양쪽** |

🔴 **발송 숫자가 바뀐다.** 원정이 더 지친 경기에 **+%p** 가 붙는다.
   ⚠️ 다만 카드는 아직 `p_code` 를 읽지 않는다(원장 전용) — 오늘 사용자에게
      보이는 숫자는 안 바뀐다.
⚠️ **`주전결장` 은 안 건드린다.** 같은 비대칭(`max(0, …)` + 죽은
   `out_starters_away` 키)이 있지만 그건 ① 의 몫이고 지시 범위 밖이다.
   상한이 양쪽으로 열린 것은 이 수정으로 **준비만** 된다.

## ③ 리그·종목·경로 분기

없다. 표 조회 그대로다. 축구 표에는 `필승조연투` 가 없어 무해하다.

## ④ 조용히 실패하는가

| 위험 | 대응 |
|---|---|
| 🔴 **기존 방향이 바뀐다** ← 가장 큰 반대 위험 | 홈이 더 지친 경우 `-2.0` 그대로인지 단언(오늘 실측값과 동일) |
| 🔴 **반대편 상한이 없어 +9%p 가 나간다** | 표 전 항목에 대해 양쪽 절사 단언 |
| 부호를 거꾸로 연다 | 원정이 더 지치면 **홈에 유리(+)** 인지 값으로 단언 |
| 0 과 미계산이 섞인다 | 기존 `adj_missing` 경로 유지. `b2b` 가 None 이면 종전대로 미계산 |

⚠️ **아직 못 잰 것**: 원정 피로 조정이 실제로 맞는 방향인지. 표의 크기(−1.0/명)를
   반대편에도 **같은 크기로** 쓰는 것은 선형 가정이다. 검증은 CLV 로 한다(결정 B).
⚠️ 오늘 슬레이트에 적용하면 롯데@KT 에 **+1.0%p**(축소 후 +0.5%p)가 붙는다.

## ⑤ 사본

크기·상한을 다시 적지 않는다 — `ADJ_RULES` 가 원본이고 계약도 그 표를 읽는다.
