# ANL-1 — 분석 LLM 3단 구조 (Part 3 / Phase 4.5)

## 왜

페이블의 분석은 **추출·계산·추론·서술** 네 일이 섞인 것이다. 지금 봇은
추출(위성)·계산(코드)·서술(Gemini)만 있고 **추론 자리가 없다** — 코드가 숫자를
내면 LLM 이 바로 서술을 쓴다.

"헤이렌베인 60%는 과대"는 확률 계산이 아니라 **사실 두 개를 시장 가격과 대조한
추론**이다. LLM 은 이 대조를 잘 하고 **숫자 생성은 못 한다**(원장 실측
AUC 0.5151 · 브라이어 0.2529 > 기저 0.2431). 역할을 그렇게 가른다.

## ① 이 함수/상태를 읽는 곳 **전부**

새 모듈이라 지금은 없다. 앞으로:
```
verdict 호출 앞   analyze 1줄 (야구·축구 러너 공통)
Phase 5-2         구조_후보 → 코드가 +6%p 로 채택 판정
Phase 6-6         서술 입력에 ② 출력
원장·집계         main_axis · swap_agree · gate_vs_llm
```
빌려 쓰는 원본:
| 무엇 | 원본 |
|---|---|
| 게이트 분류 | `gate.OVER`·`DOUBT`·`AGREE` |
| 조정 크기 | `prob.adjustments` (코드가 이미 계산한 값을 **보여줄 뿐**) |
| LLM 호출 | `llm.provider.build_provider` |

## ② 만드는/바꾸는 상태

| 상태 | 성격 |
|---|---|
| `app/engine/analyze.py` | 새 모듈. 입력 조립·L1·스왑·사슬 |
| `prompts/analyze_{soccer,baseball}.md` | 새 프롬프트 |
| 원장 8칸 | main_axis·counter_axis·market_view·swap_agree· structure_candidates·analyze_model·gate_vs_llm·analyze_failed |

🔴 **② 출력은 `p_code`·확신·pick 을 바꾸지 않는다.** 구조 후보는 Phase 5-2
   규칙에 **제출될 뿐**이고 채택(+6%p)은 코드가 한다.
🔴 **LLM 은 숫자를 만들지 않는다.** 확률·배당·% 가 출력에 있으면 L1 이 반려한다.
🔴 **배당 원값은 입력에 없다.** 확률 %p 가공값과 파생 디빅 확률만 간다
   (지시문 공통 원칙 3).

## ③ 리그·종목·경로 분기

축구·야구가 **프롬프트 파일만 다르다**(축 명칭: 결장·일정 ↔ 선발·불펜·타순).
코드 경로는 하나다.

🔴 **모델 사슬이 지시문과 다르다 — 실측이 강제했다.**
```
지시문 1순위 gemini-pro 무료  → 429 "prepayment credits are depleted"
                                (무료 티어가 아니라 유료 선불, 잔액 0)
지시문 2순위 nvidia nemotron  → 404(계정 미할당) 또는 45초 타임아웃
실측 가능    groq 0.14s · 한도 헤더 가시   ← 1순위로
             openrouter :free 0.33s        ← 2순위(모델별 폴백 필요)
```
⚠️ groq `gpt-oss-120b` 는 **추론 토큰을 먼저 쓴다.** `max_tokens` 가 작으면
   추론에 다 쓰여 `content` 가 **빈 문자열**로 온다(실측: 24토큰 → `''`,
   256토큰 → 정상 JSON). 상한을 넉넉히 준다.
⚠️ `qwen/qwen3.6-27b` 는 `<think>` 를 content 에 섞는다 — 사슬에 넣지 않는다.

## ④ 조용히 실패하는가

| 위험 | 대응 |
|---|---|
| 🔴 **LLM 이 숫자를 지어낸다** | L1 이 확률·%·배당 패턴을 반려. 계약이 세 형태로 단언 |
| 🔴 입력에 없는 사실을 든다 | `결정축_근거` 명사를 입력 블록과 대조 |
| 🔴 없는 시장을 제안한다 | `구조_후보.시장` 을 파생 디빅 목록과 대조 |
| 배당 원값이 샌다 | 입력 조립에 배당 문자열 부재를 계약이 단언 |
| 모델이 입력을 안 읽고 찍는다 | 사이드 스왑 2회 · 갈리면 **판단불가 강제** · 불일치율 기록 |
| 유료 모델이 사슬에 앉는다 | 사슬 전수에서 anthropic·xai·perplexity·deepseek 부재 단언 |
| 반려가 반복돼 발송이 막힌다 | 2회 반려 → ② 없이 ③ 으로, `analyze_failed=true` |
| 호출이 는다 | 하루 상한 32 (게이트 대상 6~8 × 스왑 2 + 재실행) |

⚠️ **아직 못 잰 것**: 완료 조건(헤이렌베인·랑스·유베·아틀레티코 4경기 출력)은
   **리그가 없어**(에레디비시·리그1) 잴 수 없고, 게이트 대상 선정에 **티어가
   필요**하다. 스왑 일치율·`gate_vs_llm` 분포는 실제 슬레이트에서 처음 본다.
⚠️ **호출 배선은 이 단위에 없다.** 입력 조립·L1·스왑·사슬까지다 — 러너에
   1줄을 넣는 것은 게이트 대상이 정해진 뒤라야 의미가 있다.

## ⑤ 사본

게이트 라벨·조정 크기·확률 계산을 다시 만들지 않는다. 프롬프트 문구는 파일에
두고 코드에 적지 않는다.
