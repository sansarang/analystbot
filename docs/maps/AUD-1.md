# AUD-1 — 검색 공급자 오디션 도구 (영향 지도 5문)

사용자 지시 2026-09-21: "도구 만들어라" (내 제안 5순위 · 지시문 DS-3a 3)

## ① 왜 도구인가 — 지금은 고를 근거가 없다

오늘 실측이 두 번 내 판단을 뒤집었다:
1. "짧을수록 좋다" → 영어는 반대였다
2. "회수 수가 많을수록 좋다" → 좁히면 **수는 줄고 정확도는 오른다**

두 번 다 **내가 고르려다 측정이 막았다.** 공급자 선택도 같다 —
표 없이 고르면 그건 취향이고, 취향은 사용자 돈으로 검증된다.

## ② 🔴 지시문의 1순위 지표를 바꾼다 — 근거를 적는다

지시문 DS-3a 4: "오디션에서 **당일 기사 회수율**을 1순위 지표로 본다."

실측 2026-09-21 (Bing, 같은 시각):
```
川崎フロンターレ        11항목/8최근 → 최신 「감독이 반성한 후반 23분 교체책」(쓸모없음)
川崎フロンターレ スタメン  5항목/2최근 → 최신 「【川崎vs鹿島】スタメン発表」(찾던 것)
한화 이글스            12항목/8최근
한화 이글스 선발        12항목/10최근  ← 좁혔는데 최근이 늘었다
```
🔴 회수율을 1순위로 두면 **쓸모없는 기사를 많이 받는 쪽이 이긴다.**
→ 1순위를 `verified`(DS-6 검증 통과 사실 수)로 바꾼다.
⚠️ 회수 수(`got`·`fresh`)는 **버리지 않고 함께 싣는다** — 지시문이 요구한
   값이고, 둘을 나란히 봐야 이 뒤집힘이 보인다.

## ③ 무엇을 만드나

`tools/search_audition.py` — **판정·배포 경로와 분리**(지시문 요구).
```
python -m tools.search_audition [--out docs/SEARCH_AUDITION_<날짜>.md] [--dry]
```
- 입력: 오늘 슬레이트의 **경기 전** 경기 × `config/search_terms.yaml` 질의
- 지표: 회수 · 당일(≤24h) · **검증 통과** · 폐기 사유 분포 · 화이트리스트
  도메인 비율 · 중앙 응답 ms · 건당 비용
- 출력: `docs/SEARCH_AUDITION_<날짜>.md`

## ④ 사본이 생기나

- 질의: `config/search_terms.yaml` (`scout_config.SEARCH_TERMS`) 가 원본
- 공급자: `deepsearch.search.REGISTRY`·`active_names()`
- 검증: `deepsearch.search.verify` → `situation.is_recap`·`published_before`
- 요청: DS-1 런타임
- 도메인 등급: `scout_config.rank`
**새로 만드는 것은 표와 정렬뿐이다.**

## ⑤ 기존 경로를 건드리나

**0건.** 🔴 **설정을 쓰지 않는다** — 지시문 "자동 채택 금지". 표만 낸다.
계약이 `rules.yaml`·`deepsearch.yaml`·`chain =` 이 소스에 없음을 확인한다.

⚠️ **경기 전 시점만** 쓴다. 과거 경기로 돌리면 경기 후 기사가 섞여 회수율이
   좋아 보인다(지시문 경고). `starts_at > now` 인 경기만 본다.
⚠️ 유료 키가 없으면 그 공급자는 **빠진다**(`active_names`). 표에 "키 없음"으로
   적는다 — 빈칸은 "0"과 "안 쟀다"를 섞는다.

## ⑥ 틀렸을 때 누가 알려주나

T-ADD 10(유료 키 없이 표) · 1순위가 `verified` · **자동 채택 안 함** ·
경기 전 시점만.
