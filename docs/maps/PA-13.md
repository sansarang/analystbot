# PA-13 — 위성이 게이트 결과를 모른다. 지시문 §3 의 절반만 돈다

## 왜

「인공위성 검색 강화 지시문」§3 원문:
> 입력: **게이트 결과**(동의 / 시장 과대 / 가치 의심 / 보드 고정).
> 검색 대상 = **`시장 과대`·`가치 의심` + 태그 `빅매치`**.
> 상한 슬레이트 30%(최소 2, 최대 8), 우선순위 |gap| 큰 순.
> 원장에 `search_selected=true/false` 와 사유.

지금은 **빅매치 하나만** 본다(`extract_game_facts` 의 `if not tag.big: return {}`).
게이트 대상이어도 빅매치가 아니면 추출이 `{}` 다. 재현 4건:

```
· 원장에 게이트 라벨 칸(gate_label)이 없다
· gate_reason 텍스트가 라벨과 다르다: 저장 '보드고정' vs gate.BOARD '보드 고정'
· gate.select(§3 대상 선정)을 부르는 코드가 app/ 전체에 0건
· 게이트 대상(시장 과대)인데 추출이 비었다
```

🔴 **`gate.select` 는 §3 을 글자 그대로 구현해 놓고 아무도 안 부른다** —
   `analyze`·U9·U10 과 **같은 병**이다(만들고 안 이음).
🔴 **텍스트 파싱은 답이 아니다.** `gate_reason` 은 `f"{label} · {why}"` 인데
   PA-6 이 쓴 "보드고정"은 띄어쓰기가 없어 `gate.BOARD`("보드 고정")와
   글자가 다르다. 파싱하면 **조용히 어긋난다.**
⚠️ 실측 2026-09-16: NPB 2경기가 기사 7건씩 모으고 추출 0건이었다.

## ① 이 함수/상태를 읽는 곳 **전부**

```
gate.select(rows)                  ← §3 구현체. 호출 0건 (이 단위에서 잇지 않는다*)
gate.OVER / DOUBT / BOARD / AGREE  ← 라벨 원본. 문자열을 베끼지 않는다
pick_ledger._PRIOR_SAVE            ← 여기서 라벨을 **칸으로** 함께 쓴다
pick_ledger.record_prior           ← 라벨을 아는 유일한 자리(반환값에도 있다)
  └ PA-6 보드 고정 분기도 같은 칸을 쓴다
satellite._DUE_SQL                 ← 대상 조회. 여기에 라벨을 실어 온다
satellite.gather → extract_game_facts(jg=…)
  └ is_big_match(...)              ← 빅매치 태그. **없애지 않는다** — OR 로 더한다
db/schema.sql                      ← gate_label TEXT (신규 칸)
```
\* `gate.select` 의 30%·2·8 예산 배선은 **다음 단위**다. 이 단위는 "게이트
   대상이면 추출한다"까지다 — 한 단위 한 변경.

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **빅매치 경로를 없애지 않는다.** §3 은 `게이트 대상 **+** 빅매치` 이고
  둘 중 하나면 대상이다. 빅매치 판정이 사라지면 게이트가 없는 경기(사전값
  미기입)가 통째로 빠진다.
- 🔴 **라벨을 손으로 적지 않는다.** `gate.py` 상수를 쓰고, `gate_reason`
  텍스트는 **읽지 않는다**(이미 어긋나 있다).
- 🔴 **LLM 콜이 는다.** 게이트 대상은 슬레이트의 일부지만(오늘 실측: 괴리
  4%p 초과 57%) 지금 추출이 거의 0이므로 증가폭이 크다. 첫 사이클에서
  `[quota]` 로 한도를 봐야 한다. 상한(30%·최대 8)은 다음 단위에서 건다 —
  **이 단위만으로는 상한이 없다.** 이것이 이 단위의 가장 큰 위험이다.
- 🔴 **위성이 원장을 읽는다.** "레저는 측정 전용" 규약과 맞닿는다. 다만
  지시문 §3 이 "입력: 게이트 결과"라고 명시했고, 읽는 것은 **판정 결과가
  아니라 선별 신호**다(확률·승자를 읽지 않는다). 계약이 그 경계를 고정한다.
- ⚠️ 새 칸은 NULL 허용 — 기존 행과 라벨이 없는 경기는 종전대로 돈다.

## ③ 되돌리기

커밋 1개 revert. 새 칸은 NULL 허용이라 남겨도 무해하다. `extract_game_facts`
의 조건이 `tag.big` 단독으로 돌아가고, `_DUE_SQL` 의 조인이 빠진다.

## ④ 측정

①과 **같은 명령**이 통과한다. 그리고 배포 뒤 야구 슬레이트에서 게이트 대상
경기의 `[scout] … 추출` 로그와 원장 `confirmed` 가 빈 배열이 아닌 원문.
