# W1 영향 지도 — 자가 점검(selfcheck) + /health 노출

## 0. 왜 먼저 만드나

이후 단계(W2~W11)는 전부 "배선을 고쳤다"고 말하는 일이다. **나아졌는지
말하려면 재는 자가 먼저 있어야 한다.** 09-20 하루에 드러난 사고 여섯 가지는
전부 자료를 눈으로 보고서야 알았다 — 기계가 세고 있었다면 그날 아침에 알았다.

```
결장 명단이 양 팀에 똑같이 복사됨        마치다@가시와 · AT마드리드@레알
결장자가 선발 XI 에도 있음               인천 무고사 · 대전 하창래
오늘 XI 가 아님(lastStarting11)          09-20 K리그 2경기 전건
휴식 시간 597~621h                       포항 · 서울
open == now (스냅샷 하나)                포항-서울 등 4경기
KBO 등판 적재가 09-12 에 멈춤            2026-09-21 기준 9일째
```

## 1. 영향 지도 5문

**① 어디를 만드나.**

| 파일 | 무엇 |
|---|---|
| `app/ops/selfcheck.py` (신규) | 불변식 13개 · **순수 함수**로 나누고 `run()` 만 DB·Redis 를 본다 |
| `config/rules.yaml` | `ops.selfcheck.*` 문턱 (미검증 사전값 주석) |
| `app/health.py` | `selfcheck_line()` — /health 에 요약 한 줄 |
| `tools/coverage_report.py` (신규) | 리그별 칸 채움률 → `docs/COVERAGE_<날짜>.md` |
| `tests/fixtures/wiring_0920/` (신규) | 09-20 실측 조각 6개 |

**② 판정을 건드리나.** 건드리지 않는다. **표시 전용**이다 — `selfcheck` 결과가
확률·등급·픽에 들어가는 경로를 만들지 않는다.

**③ 규칙은 어디에 한 번만 두나.**
- 코드 이름표는 `selfcheck.CODES` 한 곳 (보고·집계가 이 이름으로 센다).
- 문턱 숫자는 `config/rules.yaml ops.selfcheck.*` 한 곳 (코드에 박지 않는다).
- 이름 정규화는 **이미 있는** `fotmob.norm` 을 쓴다 — 새 정규식을 짓지 않는다.

**④ 무엇이 깨질 수 있나.**
- 🔴 **점검이 파이프라인을 죽이는 것**이 최대 위험이다. 자료가 비거나 모양이
  달라도 예외를 올리지 않는다(`test_selfcheck_never_raises` 가 쓰레기 입력
  9종으로 잠근다). 못 재면 "못 쟀다"고 적는다.
- ⚠️ **오탐**이 두 번째 위험이다. 실사고 2026-09-05: 감시 오탐을 고친다며
  측정 없이 규칙을 넓혀 184→137건으로 악화시켰다. 그래서 픽스처마다
  **정상 자료가 안 잡히는 것**을 함께 잠근다 — 휴식 192h(8일)는 정상,
  MLB·NPB 적재는 정상.
- ⚠️ /health 가 길어진다. 요약 **한 줄**이고 상세는 export `coverage` 다.

**⑤ 틀렸을 때 알려줄 테스트.** `tests/test_w1_selfcheck.py` — 사고 6종 +
쓰레기 입력 무예외 + 문턱이 config 에서 오는가 + 코드 목록 단일 + /health 노출.

## 2. 문턱 (전부 미검증 사전값)

| 이름 | 값 | 왜 이 값인가 |
|---|---|---|
| `rest_hours_max` | 200 | 리그 경기 간격이 8일(192h)을 넘는 일은 드물다. 09-20 정상값 192h 는 통과, 597h 는 잡힌다 |
| `ingest_stale_hours` | 36 | 일일 적재 잡이 하루 1회이므로 이틀치 여유 |
| `source_blank_ratio` | 0.5 | 지시문 값 그대로 |
| `results_pending_hours` | 6 | 지시문 값 그대로 |
| `lineup_missing_min` | 30 | 발송 규율의 첫 카드 보장선 T-30 |

⚠️ 실측이 쌓이면 고친다. **지금 값은 근거가 아니라 시작점이다.**
