# W3-2 영향 지도 — 연장·승부차기를 1X2 채점에서 제외한다

## 0. 재현 (실측 2026-09-21)

```
games 에 result_basis 칸  → **없다**
```

FotMob 은 `reason.short` 로 `FT`·`AET`·`Pen` 을 주고 `fotmob.status_of` 가
그것을 이미 읽는다(FMR-1). 그런데 **저장할 자리가 없어 버려진다.**

그러면 연장에 가서 3-2 로 끝난 경기가 `home_score=3, away_score=2` 로만 남고,
1X2 채점이 그것을 **정규시간 홈 승**으로 읽는다. 실제로는 90분에 2-2 무승부였을
수 있다 — 그 경우 우리 픽의 적중 판정이 통째로 거짓이 된다.

⚠️ 지금 운영에 AET/Pen 은 **0건**이다(09-20·21 적재 `needs_90` 0).
   그래도 막는다 — 녹아웃이 시작되면 그때는 이미 틀린 채점이 쌓인 뒤다.

## 1. 함께 잰 것 — D07b 는 **결함이 아니었다**

W0 에서 "결과는 있는데 미채점 11건"으로 적었는데, 갈라 보니 전부 정상이다:

```
진짜 미채점(graded_at IS NULL)   0건
무승부(hit=None · 분모 제외)      9건   ← 의도된 동작
predicted_side=None (보드)       2건   ← 픽이 없으니 적중도 없다
```

`grade_pending` 의 규칙 그대로다: `hit = None if (side is None or winner == "draw")`.
→ **D07b 를 오탐으로 정정한다.** 밀린 채점(W3-6)은 지금 닫을 것이 없다.

## 2. 영향 지도 5문

**① 어디를 고치나.**

| 파일 | 무엇 |
|---|---|
| `db/schema.sql` | `games.result_basis TEXT` |
| `app/collectors/game_match.py` | `apply_result(..., result_basis=None)` — 저장 |
| `app/collectors/fotmob.py` | `upsert_slate` 이 그 값을 넘긴다 |
| `app/engine/pick_ledger.py` | `gradeable_basis()` · `grade_pending` 이 제외 |

**② 새 표를 만드나.** 만들지 않는다. 칸 하나다.

**③ 규칙은 어디에 한 번만 두나.** `pick_ledger.gradeable_basis` 하나.
`fotmob._FINAL_REASONS` 는 "종료인가"를 답하고, 이쪽은 "채점해도 되는가"를
답한다 — 다른 질문이라 표를 나눈다. ⚠️ **모르는 표지는 제외**한다(추측 금지).

**④ 무엇이 깨질 수 있나.**
- 🔴 **막느라 정상 채점까지 멈추는 것**이 최대 위험이다. `None`·`FT`·빈 문자열은
  **그대로 채점**한다(옛 행·다른 소스는 전부 None 이다). 계약이 잠근다.
- ⚠️ 제외는 **조용히 사라지지 않는다** — 건수를 로그와 반환값에 남긴다.
- ⚠️ 승부차기 득점은 애초에 합산하지 않는다(FMR-1 `score_at_90` 규약).

**⑤ 틀렸을 때 알려줄 테스트.** `tests/test_w3_2_aet.py` — 스키마·적재·채점
배선 · **정상 경기 보존** · AET/Pen 제외 · 모르는 표지 제외 · 제외 보고.
