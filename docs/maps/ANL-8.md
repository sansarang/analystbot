# ANL-8 — `l1` 이 `구조_후보` 모양을 믿고 **터진다**

## 왜

실측 2026-09-17 운영 (SSG@NC · game 1754):
```
[analysis] game=1754 분석 실패: 'str' object has no attribute 'get'
```
지점:
```python
for c in out.get("구조_후보") or []:
    if str(c.get("시장") or "") not in names:   ← c 가 dict 라고 가정
```
```
구조_후보=['스프레드 -1.5'] → 🔴 AttributeError
구조_후보=[None] / [123]    → 🔴 AttributeError
```

🔴 **ANL-2 가 분석을 살려내니 그 다음 방어선이 무너졌다.** 어제까지는 JSON
   자체가 안 와서 이 줄에 도달한 적이 없었다.
🔴 **모양이 틀린 것은 반려 사유지 크래시가 아니다.** 크래시는 `analyze_failed`
   로도 안 남고(예외가 위에서 잡혀 로그 한 줄이 된다) 로그는 재배포로 날아간다 —
   오늘 실제로 그래서 원인을 못 볼 뻔했다.
⚠️ 그리고 프롬프트(ANL-2 `output_spec`)가 **항목 모양을 안 말한다** —
   "목록. 없으면 빈 목록"까지만 말하니 모델이 문자열을 넣는다.

## ① 이 함수/상태를 읽는 곳 **전부**

```
analyze.l1 (구조_후보 대조)      ← 고치는 곳
analyze.output_spec             ← 항목 모양을 말한다(ANL-2)
structure.attach_derived        ← 항목 모양의 **원본** `{"시장","라인","쪽","확률"}`
structure.CAND_FIELDS           ← **신규 상수**. 두 곳이 같은 것을 본다
analyze.to_ledger structure_candidates ← 원장 저장. **안 건드린다**
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **올바른 모양은 종전 그대로다.** 빈 목록 통과 · 파생에 없는 시장 반려.
  계약이 둘 다 잰다.
- 🔴 **반려로 바꾼다. 통과로 바꾸지 않는다.** 모양이 틀렸다는 것은 모델이
  스키마를 안 지켰다는 뜻이고, 그게 바로 L1 이 잡을 일이다.
- 🔴 **항목 이름을 손으로 안 적는다** — `structure.CAND_FIELDS` 가 원본이고
  `attach_derived` 가 그 이름으로 만든다. 계약이 **생산물의 키**와 상수가
  같은지 잰다(상수만 고치고 생산을 안 고치는 사고를 막는다).
- ⚠️ 프롬프트가 한 줄 길어진다. 콜 수는 안 는다.
- ⚠️ 이 반려는 원장을 안 막는다(ANL-2 에서 잠근 성질) — 결정축은 남는다.

## ③ 되돌리기

커밋 1개 revert. `isinstance` 한 줄과 상수 하나, 프롬프트 한 줄.

## ④ 측정

①과 **같은 명령**이 통과한다. 그리고 오늘 밤 게이트 경기에 다시 돌려
`analyze_check` 에 크래시 대신 반려 사유가 남는지 본다(⑨).

## ⑤ 계약

8건 — 문자열·None·숫자 항목이 **반려**된다(터지지 않는다) · 빈 목록 통과 ·
올바른 항목은 종전대로 · 프롬프트가 항목 모양을 말한다 · 항목 이름 사본 금지 ·
`attach_derived` 생산 키가 상수와 같다 · 반려가 원장을 안 막는다.
