# BIG-1 — 빅매치 태그 (사용자 지시)

## 왜

FOT-3(3순위 구단 공식 RSS)과 FOT-4(LLM 한정)가 **"빅매치 태그"를 조건으로
쓰는데 그 태그가 시스템에 없다.** 그래서 두 곳 모두 조건 가지를 만들지
못하고 열려 있었다(각 커밋에 그렇게 적어 두었다).

사용자가 정의를 줬다 — 셋 중 하나면 빅매치다:
1. 같은 리그 **순위 3계단 이내** 대결
2. **더비 목록**(config)
3. **상위 6팀 간** 대결

재현:
```
PYTHONPATH=. .venv/bin/python <scratchpad>/repro_big1.py
  → No module named 'app.engine.bigmatch'
```

## ① 이 함수/상태를 읽는 곳 **전부**

새 함수라 지금은 없다. 쓸 곳(각각 **별도 단위**):
```
FOT-3  둘 다 결장 미상 → 빅매치만 구단 공식 RSS 1회
FOT-4  LLM 추출을 빅매치에만
D2~D4  예산이 붙는 수집의 우선순위
```
이 단위는 **판정 함수까지**다. 호출부를 이번에 만들지 않는다.

## ② 만드는/바꾸는 상태

| 무엇 | 성격 |
|---|---|
| `config/derbies.yaml` | **새 설정(사용자 편집).** 리그별 더비 쌍 |
| `app/engine/bigmatch.py` | 순수 함수 — DB·HTTP 없음 |

순위는 **인자로 받는다.** 이 모듈이 순위표를 직접 읽지 않는다 — 그래야
호출부가 어느 표(리그 순위·Elo·티어)를 쓸지 정할 수 있고, 여기서 소스가
고정되지 않는다.

⚠️ 순위를 **모르면 `None`** 이다. 그때는 더비 목록만으로 판정하고, 순위
   조건은 "모른다"로 남긴다 — 0위로 읽지 않는다.

## ③ 리그·종목·경로 분기가 생기는가

더비 목록만 리그별이다. 규칙(3계단·상위 6)은 리그 무관이고 상수 둘이다.
야구도 같은 함수를 쓸 수 있다(순위만 넘기면 된다).

## ④ 실패하면 "시끄럽게" 실패하는가

- 반환이 `(big, reason)` 이다 — **왜 빅매치인지**가 항상 붙는다. 나중에
  "왜 이 경기에 돈을 더 썼나"를 원장만 보고 답할 수 있어야 한다.
- 순위가 없으면 `reason` 에 그 사실이 남는다.

## ⑤ 시스템에 이미 있는 사실을 다시 적고 있지 않은가

- 팀 이름 정규화는 새로 만들지 않는다 — 더비 비교는 `aliases_local` 과 같은
  규칙(악센트·법인격 제거)을 쓰는 기존 헬퍼를 부른다.
- 리그 키는 `app/leagues.py` 가 원본.
