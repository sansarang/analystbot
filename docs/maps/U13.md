## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **이번 커밋은 값을 바꾸지 않는다.** yaml 에는 **지금 코드에 있는 값
  그대로** 넣고, 계약 테스트가 `rules.get(...) == 종전 상수` 를 잰다.
  값이 하나라도 달라지면 U5~U12 판정이 전부 달라진다.
- 🔴 **사본을 만들지 않는다.** 값은 yaml 에만 있고 모듈은 읽기만 한다.
  양쪽에 적으면 원본이 바뀔 때 사본이 안 따라간다(실사고 2026-09-02 워치독).
- 🔴 yaml 이 배포 이미지에 안 올라가면 **조용히 기본값으로 돈다** — CFG-1 과
  같은 사고다. 로더가 파일 없음을 WARNING 으로 남기고, 계약이 그 경로를 잰다.
- ⚠️ 리포트는 **스케줄러에 걸지 않는다.** 지시받지 않았다. 사람이 부른다.
- ⚠️ 새 칸 3개는 NULL 허용이라 기존 행은 그대로다.
