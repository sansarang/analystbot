# SCT-3 — 위성 검색 개편 (Part 2). SCT-2 를 대체한다.

## 왜

오늘 페이블이 실제로 정보를 가져온 방식을 이식한다 — **리그별 현지어 검색어 →
결과 중 제목·날짜·신선도로 걸러 → 구단·지역 매체 우선 → 결장·XI·직전 3경기만
추출.** 지금은 팀명만으로 긁고, 걸러내는 규칙이 제목 문 하나뿐이다.

실측이 가리키는 결함: 검색 결과에 **2021·2023·2025 시즌 프리뷰**가 섞여 나온다.
지금은 그것을 fetch 하고, 그 본문이 그대로 판정 재료가 된다.

## ① 이 함수/상태를 읽는 곳 **전부**

`scout_config` 는 SCT-2 에서 만들었고 아직 **아무도 안 읽는다**(배선 전).
그래서 이 단위는 **대체가 안전하다** — 호출부가 없다.
```
$ grep -rn "scout_config" app/
app/engine/scout_config.py   정의뿐
```
빌려 쓰는 원본:
| 무엇 | 원본 |
|---|---|
| 리그 목록 | `app/leagues.py` (계약이 전수 대조) |
| 한국어 토르 거부 | `tor_search.is_tor_safe_query` |
| 층1 검색어 | `satellite_soccer._SOCCER_TERMS` — **건드리지 않는다** |

## ② 만드는/바꾸는 상태

| 상태 | 성격 |
|---|---|
| `config/search_terms.yaml` | **2단계**(pre·lineup)로 재작성 + 확정 키워드·오늘 말 |
| `config/sources.yaml` | **리그별** tier1/tier2 + tier3 공통 + blocked/js_only |
| `scout_config` | 선별(`screen`)·정렬(`rank_and_pick`)·확장 스키마·충돌(`merge`) |

🔴 **층1 위성은 그대로다.** `_SOCCER_TERMS = ""` 에 검색어를 붙이면 다음
   뉴스검색이 맥도날드·프로야구 기사를 준다(실측 2026-09-12).
🔴 **구단 공식 도메인을 추측해 채우지 않는다.** 지시문 자신이 그 자리를
   `"구단 공식 도메인 목록"` 이라는 **자리표시자**로 적어 두었다 — 값이 없다는
   뜻이다. 비워 두고 파일에 적는다.
⚠️ `bench_notable` 은 **코드가 채운다** — 예상 XI 대비 공식 XI 에서 빠진
   주전이다. LLM 자기보고가 아니다(지시문 4-4 명시).

## ③ 리그·종목·경로 분기

분기가 아니라 **표 조회 2단**(리그 → 단계). 소스도 리그별 표다.
⚠️ 지시문 리그 키(laliga·seriea·jleague·kleague)를 우리 키(la_liga·serie_a·
   j1·kleague1)로 옮겼다. 우리에 없는 리그(ligue1·eredivisie·championship·
   j2·kleague2)는 **넣지 않았다** — 없는 리그의 도메인은 사본이자 오탐이다.

## ④ 조용히 실패하는가

| 위험 | 대응 |
|---|---|
| 🔴 **지난 시즌 페이지를 연다** | 날짜 문 — 경기 날짜(±1일)·"오늘" 말·연도 중 하나 없으면 폐기. 계약이 `2023/24` 로 단언 |
| 🔴 오래된 기사를 라인업으로 읽는다 | 신선도 pre 48h · lineup 3h. **발행시각을 모르면 버리지 않는다**(모르는 것 ≠ 오래된 것) |
| 베팅 제휴가 섞인다 | 도메인 목록 + **조각**(bet·odds·tipster) 차단 |
| JS 페이지를 열어 빈손 | `js_only` 는 정렬 전에 제거 |
| 확정 기사가 tier 에 밀린다 | `lineup` 단계에서 확정 키워드 최우선. **`pre` 에서는 안 먹는다**(계약) |
| 왜 버렸는지 모른다 | 사유별 건수를 반환·로그 |
| 두 소스가 다른 결장 명단 | tier 높은 쪽 채택 + `conflict=true`(계약) |
| 예산이 는다 | 경기당 검색 3 · fetch 5 · 단계당 3 을 상수로 |

⚠️ **아직 안 한 것**: `satellite_soccer` 배선. 이 단위는 **설정과 규칙까지**다.
   배선은 트리거(TRG-1)가 단계를 쏘는 구조가 서야 의미가 있고, 완료 조건의
   실행 검증은 **티어 표가 채워져야** 대상이 정해진다.
⚠️ 완료 조건의 헤이렌베인·랑스·유베는 **에레디비시·리그1이라 리그가 없다.**

## ⑤ 사본

리그 목록·토르 거부 규칙·층1 검색어를 다시 만들지 않는다. 도메인·검색어는
yaml 한 곳에만 두고 코드에 흩지 않는다.
