# LOC-3 — 리그앙·에레디비시는 **검색이 한 번도 안 나갔다**

사용자 2026-09-22: "야구만 지금 하는 게 아니라 해외도 해야 한다고 각 리그
그 나라의 언어로 뉴스 검색을 하고 있는지 우선 확인해봐" → **"3줄 추가 먼저해라.."**

## 재현 (①을 대신하는 실측)

```
scout_config.locale("ligue1")      → None
scout_config.locale("eredivisie")  → None
scout_config.locale("denmark")     → {hl: en, gl: DK}   ← terms 는 덴마크어
```

`rss_hits` 는 로케일이 없으면 **그 자리에서 빈손으로 반환**한다:

```python
loc = locale(league)
if not loc or not query:
    return []
```

즉 두 리그는 검색 요청이 **한 번도 나가지 않았다.**

⚠️ 설정 주석이 "아래 둘은 우리 시스템에 리그가 없다"고 적고 있었는데
**틀렸다.** `league_labels()` 실측:

```
리그앙     → ligue1        최근 30일 49경기
에레디비시  → eredivisie    최근 30일 53경기
```

## 영향 지도 5문

① **파일** — `config/search_terms.yaml` 한 곳(로케일 3줄 + 낡은 주석 2곳 정정).
   코드는 **한 줄도 안 고친다** — `scout_config.locale()` 은 표만 읽는다.

② **테이블·잡** — 없음. DB 스키마·잡 주기 변화 0. 영향은 `rss_hits` 가
   Google News RSS 에 **요청을 보내기 시작한다**는 것뿐이다(종전 0건).

③ **깨질 테스트** — 로케일 표를 세는 계약이 있으면 개수가 바뀐다. 전체
   스위트로 확인한다.

④ **되돌릴 길** — 세 줄을 지우면 종전과 같다(빈손 반환). 코드 변경이 없어
   되돌리기가 YAML 편집 하나다.

⑤ **완료 조건** — `locale()` 이 `league_labels()` 의 모든 리그(UCL·UEL 제외)
   에 대해 non-None · 검색어 언어와 `hl` 이 일치 · 기존 리그 미변경.

## 안 한 것

🔴 **UCL·UEL 은 그대로 뒀다.** 참가국이 섞여 어느 언어로 물을지가
   **갈림길**이다(ACL 은 종전에 en/SG 로 정해 뒀지만 그 근거도 문서에 없다).
   지시 없이 고르지 않는다 → `docs/DEFECTS.md` D58.

🔴 **현지 별칭표는 안 만들었다.** 에레디비시·리그앙 팀 별칭 약 60개는
   내가 지어낼 수 없다(ALI-1 규약). 로케일이 생겼으니 기사는 들어오지만,
   팀 이름 대조가 안 되면 `_mentions_team` 에서 걸러진다 — **다음 단위다.**
