# LE-4 — 엔진 2: 시초가 잔차 모델 (영향 지도 5문)

사용자 2026-09-22: **"시장과 떨어져야 한다 — 100% 공감"**
사용자 결정: sklearn `HistGradientBoosting` · **탈상관은 잔차 목표**(`y − p_market`).

## ⓪ 왜 이 설계가 "시장과 떨어지는" 것인가

```
보통 모델   목표 = 누가 이겼나        →  잘 맞히면 시장과 같아진다(둘 다 정답을 향한다)
이 모델     목표 = p_close − p_open   →  **시장이 틀린 만큼**만 점수가 된다
```
🔴 시장 확률을 그대로 맞히면 **0점**이다. 시장이 움직인 방향과 크기를 맞혀야
   점수가 난다. 구조상 시장 복사가 불가능하다 — 벌점이 아니라 **목표 자체**다.
   (사용자 결정: λ 벌점 대신 잔차 목표)

⚠️ 구조 카드(선발·결장·구장·날씨)는 **역사 자료에 없다.** 그래서 이 백테스트는
   "가격과 일정만으로 시장의 오차를 맞힐 수 있나"를 묻는다. 구조 정보의
   값어치는 실시간 축적분에서 따로 잰다(W5 뒤).

## ④ 무엇이 깨질 수 있나

- 🔴 **누설이 최대 위험.** `elo_diff` 는 그 경기 **이전까지**만 리플레이해야
  한다. 전 시즌을 미리 피팅한 Elo 를 쓰면 미래를 본다. 계약이 잠근다.
- 🔴 **과적합.** 11,738경기 · 피처 7개면 쉽게 외운다. walk-forward 로만 재고,
  **검증 창 밖 성적은 보고하지 않는다.**
- ⚠️ 기준선을 못 이기면 **"엔진 2 비활성"으로 적는다.** 좋아 보이는 설정을
  찾아 헤매지 않는다 — 그건 검증 창을 학습에 쓰는 것이다.
- ⚠️ sklearn 만 쓴다. CatBoost 는 LE-6 비교에서만(사용자 결정).
