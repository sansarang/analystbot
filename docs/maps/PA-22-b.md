# PA-22-b — 위생 검사를 만들어 놓고 아무도 안 부른다

## 왜

PA-22 가 `margin_ok`·`devig_ok`·`placeholder_suspect` 를 만들었는데 **호출부가
0건**이었다 — 오늘만 여덟 번 본 그 병이다(analyze·gate.select·U9·U10·
book_gap·예산·확증·구속).

재현 실측:
```
마진 0(합 100.0%) 배당 → 게이트 '시장 과대' · gap -22.46
```
**실제 북에는 없는 값으로 괴리를 쟀다.** 그 게이트는 거짓이고, 거짓 게이트가
딥서치 대상을 정하고 가설을 세운다.

## ① 이 함수/상태를 읽는 곳 **전부**

```
market_edge.margin_ok / devig_ok / placeholder_suspect   ← PA-22 가 만든 것
market_edge.MARGIN_MIN_PCT / MAX / DEVIG_TOL             ← 문턱 원본
pick_ledger.record_prior:847                             ← 거는 곳
  ├ implied_probs(base["odds"])   ← 그 앞에 margin_ok
  ├ devig_ok(cand)                ← 그 뒤에
  └ placeholder_suspect(...)      ← 같은 슬레이트 비교
gate.classify(pri, mkt, sport)    ← mkt=None 이면 보드 고정을 돌려준다
db/schema.sql placeholder_suspect BOOLEAN   ← 신규 칸
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **막히면 "시장 없음"이다.** 확률을 지어내지 않는다 — `gate.classify` 에
  None 을 주면 그쪽이 보드 고정을 돌려준다(판정 규칙은 원본이 정한다).
- 🔴 **정상 배당을 막으면 전 경기가 보드 고정이 된다.** PA-22 에서 채택
  범위로 실측했고 **523/523 통과 · 폐기 0건**이다. 계약이 정상 마진을 잰다.
- 🔴 **자리표는 폐기가 아니라 표시다.** 우연히 같을 가능성이 0은 아니고,
  판단은 원장을 보는 사람이 한다. 계약이 "표시해도 게이트는 돈다"를 잰다.
- 🔴 **자리표 검사가 터져도 게이트는 돈다** — 측정 장치가 판정을 죽이면 안 된다.
- 🔴 **문턱을 손으로 적지 않는다.** `market_edge` 상수가 원본이다.
- ⚠️ 자리표 비교는 **홈 확률 한 값**으로 한다. 원장에 3-way 가 아니라
  `p_market`(홈)만 있기 때문이다 — SEA@ATH 사례는 이것으로 잡힌다.
- ⚠️ 새 칸은 NULL 허용 — 기존 행은 그대로다.

## ③ 되돌리기

커밋 1개 revert. 검사 세 줄과 자리표 블록이 빠지면 종전처럼 모든 배당이
게이트로 간다. 칸은 NULL 허용이라 남겨도 무해하다.

## ④ 측정

①과 **같은 명령**이 통과한다(마진 0 → 보드 고정 · gap None). 배포 뒤
`[gate] … 배당 마진이 범위 밖` 로그가 **안 나오는 것**이 정상이다(실측
폐기율 0). 나오면 그 경기 배당을 봐야 한다.

## ⑤ 계약

