# PA-22 — 시장 확률 위생 검사가 없다 (지시문 2단계)

## 왜

지시문 2단계:
> 시장 확률: `p_mkt` 합이 **100±0.5** 아니면 폐기하고 `market_missing=True`.
> 동일 값 중복 검사: 같은 팀 조합의 다른 경기가 소수점까지 같은 확률이면
> `placeholder_suspect=True` (어제 SEA@ATH 40.9/59.1 두 번).

🔴 **숫자를 그대로 걸면 배당이 전부 사라진다.** 실측 2026-09-17(48h · h2h
묶음 523개):
```
합 100±0.5 안: 0 · 밖: 523
내재확률 합(%) 최소 101.5 · 중앙 105.1 · 최대 109.0
```
우리가 저장하는 것은 **배당 원값**이라 합이 마진만큼 100 을 넘는 것이
**정상**이다(중앙 마진 5.1%). 오히려 100.0 이면 마진 0이라 비정상이다.
디빅은 `implied_probs` 가 나중에 한다 — 즉 지시문의 검사 자리가 우리
구조에서는 **한 단계 뒤**다.

→ **사용자 결정 2026-09-17**: 원값은 마진 범위 · 디빅 후 합 100±0.5, 두 단계.

## ① 이 함수/상태를 읽는 곳 **전부**

```
market_edge.implied_probs        ← 디빅 원본. 이미 합을 1 로 맞춘다(안 건드린다)
(신규) market_edge.margin_pct / margin_ok    ← 원값 마진
(신규) market_edge.devig_ok                  ← 지시문 100±0.5 자리
(신규) market_edge.placeholder_suspect       ← 동일 확률 중복
MARGIN_MIN_PCT / MARGIN_MAX_PCT / DEVIG_TOL  ← 문턱 원본(여기 한 곳)
```
⚠️ **이 단위는 함수만 만든다.** 어디에도 걸지 않는다 — 거는 자리(수집·게이트)는
   다음 단위다. 먼저 폐기율을 재고 거는 것이 순서다.

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **아직 아무것도 안 막는다.** 호출부가 없으므로 이번 배포로 동작이
  바뀌지 않는다. 그게 의도다 — 실측 없이 필터를 걸면 "조용한 0"이 난다.
- 🔴 **채택한 범위로 다시 재니 523/523 통과 · 폐기 0건**이다. 반대 위험이
  실측으로 0이다.
- 🔴 **마진 0 은 막는다.** 실제 북에는 없는 값이라 만들어진 확률이거나
  자리표다. 하한을 100.5 로 둔 이유다.
- 🔴 **`placeholder_suspect` 는 폐기하지 않는다. 표시만 한다** — 우연히
  같을 가능성이 0은 아니고, 판단은 원장을 보는 사람이 한다.
- 🔴 **한쪽 배당만으로는 못 잰다**(`None`). 한쪽으로 디빅하면 마진이 안 빠져
  확률이 부푼다 — `implied_probs` 와 같은 규칙이다.
- ⚠️ 상한 115% 는 실측 최대(109.0)에 여유를 둔 값이다. 근거가 실측이므로
  더 좁히려면 다시 재야 한다.

## ③ 되돌리기

커밋 1개 revert. 함수 넷과 상수 셋이 빠진다. 호출부가 없으므로 다른 곳에
영향이 없다.

## ④ 측정

①과 **같은 명령**이 통과한다. 그리고 운영 48h 배당으로
`묶음 523 · 통과 523 (100.0%) · 마진낮음 0 · 마진높음 0` 를 확인했다.
