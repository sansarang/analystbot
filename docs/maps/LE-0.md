## ⚠️ 이 단계에서 미리 적어 두는 것 — 사용자 답 1번의 해석

지시문 1번의 도메인 칸이 **빈 채로 왔다**(`<도메인 — 사용자가 채움>`), 그리고
같은 문단이 이렇게 못박고 있다:

> "봇이 그 사이트에 접속하는 것은 사용자가 robots·약관·합법성을 확인한 뒤
> 따로 지시할 때만."

그리고 "사이트 이름은 너가 알아서 정해라".

🔴 **그래서 내가 정하는 것은 "내부 식별자"이고 "접속할 사이트"가 아니다.**
   실제 베팅 사이트를 골라 긁기 시작하는 것은 위 문장이 명시로 금지한 것이다.

| 무엇 | 값 | 근거 |
|---|---|---|
| 원장의 북 이름 | **`user_site`** | 지시문 LE-1-1 원문 `book="user_site"` |
| 도메인 설정 칸 | `learning.slow_book.user_site_domain` — **기본값 없음(null)** | 채우는 것은 사용자 |
| 수집 경로 | **캡처 파서**(`tools/manual_odds.py` 재사용) | 지시문 1번 "캡처 파서 경로를 기본으로" |
| 네트워크 접근 | **없음.** 도메인이 채워져도 자동 접속 코드를 만들지 않는다 | 위 인용 |

⚠️ LE-0 2번의 답은 따라서 "**도메인 미지정 — 자동 수집 판정 불가 · 캡처 파서
   경로로 간다**"이고, robots·약관 실측은 **사용자가 도메인을 주고 접속을
   지시할 때** 한다. 지금 임의의 사이트를 골라 robots 를 받으러 나가지 않는다.
