# W3-1 영향 지도 — 결과 소스와 finals 잡 배선

## 0. 재현 (실측 2026-09-21)

최근 30일 축구 종료 경기:

```
J1 리그   0/11      K리그1  0/14
ACL엘리트 0/10      덴마크  0/8        ← 전건 `scheduled`
(리그앙 13/15 · 에레디비시 11/15 · 라리가 56/63 은 정상)
```

원인은 **두 가지**다.

| 리그 | 무엇이 없나 |
|---|---|
| `j1` · `kleague1` · `denmark` | `fd_names` **없음** · `fotmob_contains` **없음** → 결과 소스가 아예 없다 |
| `acl` | `fotmob_contains` 는 있다. 그런데 **finals 잡이 FotMob 경로를 부르지 않는다** |

`upsert_slate`(FMR-1 이 점수까지 쓰게 만든 함수)는 **일정 프리페치에서만**
불린다(`pipeline.py:1457`). 그때는 경기가 안 끝났으므로 점수가 없고,
끝난 뒤 다시 받는 경로가 **없다.** 그래서 FMR-1 을 배포하고도 D06b 가 그대로다.

## 1. FotMob 리그 이름 — 실측 (하루치 목록 3일분)

```
KOR  'K-League 1'                       2부는 'K League 2'  (하이픈이 다르다)
JPN  'J. League'                        2·3부는 'J. League 2' · 'J. League 3'
DEN  'Superligaen'                      (1./2./3. Division · A-Liga 는 하위)
INT  'AFC Champions League Elite'       (기존 값 그대로)
```

🔴 **`upsert_slate` 은 `fotmob_contains` 를 부분 문자열로 고른다.**

```python
if needle not in (r.get("league") or ""): continue
```

`'J. League'` 를 그대로 넣으면 `'J. League 2'`·`'J. League 3'` 가 **전부 J1 으로
적재된다** — 실측 기준 하루 9+8경기. 이름을 넣는 것만으로 결함이 된다.

## 2. 영향 지도 5문

**① 어디를 고치나.**

| 파일 | 무엇 |
|---|---|
| `app/leagues.py` | `result_source`(`fd`\|`fotmob`) · `fotmob_league`(**정확 일치** 이름) |
| `app/collectors/fotmob.py` | `league_matches(name, league_key)` — 고르는 규칙을 **한 곳**에 두고 `upsert_slate` 이 그것을 쓴다 |
| `app/scheduler.py` | `ingest_fotmob_finals()` + `finals_job` 에서 호출 |

**② 새 수집기·새 테이블을 만드나.** 만들지 않는다. `upsert_slate` 은 이미
점수·상태를 쓴다(FMR-1). 없는 것은 **끝난 뒤 부르는 사람**뿐이다.

**③ 규칙은 어디에 한 번만 두나.**
- 리그를 고르는 규칙 → `fotmob.league_matches` 하나. `upsert_slate` 이 그것을
  부르고, 점검기·백필도 같은 함수를 쓴다.
- 날짜 기준 → **UTC**(W2 에서 실측으로 확인). `ingest_fotmob_finals` 이 그렇게 잡는다.

**④ 무엇이 깨질 수 있나.**
- 🔴 **하위 리그 오적재**가 최대 위험이다(위 §1). `fotmob_league` 가 있으면
  **정확 일치**로 고르고, 없으면 종전 `fotmob_contains` 그대로 간다 —
  ACL 의 동작은 한 글자도 바뀌지 않는다.
- ⚠️ 적재가 **덮어쓰지 않는다**(`coalesce`) — football-data 가 먼저 넣은
  점수는 남고 차이는 `conflict` 로그로 나온다(FMR-1 규약 그대로).
- ⚠️ 한 리그가 터져도 나머지는 돈다(기존 finals 규약과 같다). 실패는 조용히
  삼키지 않고 반환값·로그에 남긴다.

**⑤ 틀렸을 때 알려줄 테스트.** `tests/test_w3_result_source.py` —
2·3부 분리 · ACL 불변 · 결과 소스 존재 · fd 우선 · finals 배선 · UTC 날짜 ·
2일치 · 한 리그 실패 격리.
