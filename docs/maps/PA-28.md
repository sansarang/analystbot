# PA-28 — 변수별 채점이 없다 (지시문 10단계)

## 왜

지시문 10단계는 변수 하나하나에 "delta 방향이 결과와 맞았는가"를 묻는다.
전제는 PA-23(`adj_evidence`)·PA-24(`p_base`)로 갖춰졌는데 **채점하는 쪽이
없다.** `report.by_axis` 는 **결정축(상위 2개)** 으로만 묶어서, `이동연전`
처럼 늘 3등인 변수는 **영영 채점되지 않는다.**

`prob.py` 는 이미 결정을 적어 놓았다(결정 B · 1차 결정 6):
> "변수별 100건 이상 쌓이고 **평균 CLV 부호가 조정 방향과 같으면 1.0,
>  반대면 0** 으로 — 변수 단위로 개별 조정한다. 판단은 사용자가 한다."

그 100 도, 부호 비교도 **코드에 없다. 주석으로만 있다.**

## 갈림길 — 딥서치했다 (→ docs/FORKS.md F-4)

**무엇으로 채점하나: 적중률인가 CLV 인가.**
자료가 한쪽으로 모인다 — CLV 다.
- "CLV 는 단기 승률보다 장기 수익성을 더 잘 예측한다"(ThePowerRank · SharpFootball)
- "여러 베팅에 **걸쳐 합산되므로** 개별 사건에 덜 흔들린다"(Bet2Invest)
  → 통계는 **평균 CLV**. 건별 부호 일치율은 **참고로만** 둔다.
- 이 저장소 실측도 같다: 판정 확률 AUC 0.5122(판별력 없음) · 시장 0.6421.

적중률은 함께 내되 **판정 근거로 쓰지 않는다.**

## ① 이 함수/상태를 읽는 곳 **전부**

```
report.by_variable      ← 새 함수 (순수 함수 — 파일 규약)
report.toward_pick      ← 부호를 픽 기준으로 돌린다
report.VAR_MIN_N        ← config/rules.yaml `report.var_min_n` 이 원본
report.KEEP/DROP/THIN   ← 제안 문구
pick_ledger.adj_pp      ← 입력(변수→%p). **안 건드린다**
pick_ledger.adj_evidence ← 입력(PA-23). 출처 집계에만 쓴다
pick_ledger.clv         ← 입력. 부호 규약은 `clv_pp` 가 원본
prob.ADJ_SHRINK         ← 🔴 **안 건드린다.** 표 크기는 사용자 결정이다
report.by_variable 호출부 ← **0건**. `report.py` 규약이 "사람이 부른다"이다
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **읽기만 한다.** 순수 함수이고 DB·HTTP 를 안 부른다(파일 규약).
  `prob.ADJ_SHRINK` 도 `ADJ_RULES` 도 **안 바꾼다** — 제안만 낸다.
- 🔴 **부호를 픽 기준으로 돌린다.** `adj_pp` 는 홈 기준, CLV 는 우리가 고른
  쪽 기준이다. 안 돌리면 **원정 픽에서 부호가 통째로 뒤집힌다.** 계약이 잰다.
- 🔴 **픽을 모르면 None 이다.** 0 으로 읽으면 "조정 없음"과 "모름"이 같아진다.
- 🔴 **변수가 발생한 행만 센다.** 안 나온 경기를 0 으로 세면 모든 변수가
  "거의 0"으로 수렴한다.
- 🔴 **표본이 모자라면 판단하지 않는다**(`표본 부족`). 적은 표본으로 변수를
  끄는 쪽이 켜 두는 쪽보다 위험하다 — 끈 변수는 다시 켜 볼 기회가 없다.
- 🔴 **문턱 100 을 손으로 안 적는다.** `config/rules.yaml` 이 원본이다.
- ⚠️ `report.py` 를 **부르는 운영 코드는 0건**이고 이번에도 안 만들었다.
  그게 이 파일의 규약이다("사람이 부른다"). 원장에서 행을 뽑아 이 함수에
  넣는 도구는 **아직 없다** — 지시받지 않았다.

## ③ 되돌리기

커밋 1개 revert. 새 함수 둘과 상수 넷, rules.yaml 한 줄이 빠진다.

## ④ 측정

①과 **같은 명령**이 통과한다. 실측:
```
홈 픽 · 이동연전 −1.0 · CLV +3.0/+1.0
  → n 2 · 평균_기여 −1.0 · 평균_CLV +2.0 · 부호_일치율 0.0
    · 표본_충분 False · 제안 "표본 부족"
표본 100건(조정 방향과 CLV 부호 같음) → 제안 "유지"
표본 100건(부호 반대)                 → 제안 "끄기 검토"
원정 픽 · 홈에 −2%p → 평균_기여 **+2.0** (부호가 돌았다)
```
