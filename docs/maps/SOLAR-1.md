
네 언어 모두 **홈/원정 귀속이 정확**했고 `xi_status` 를 `predicted` 로

⑨ 첫 사이클이다 — 합성 기사만으로 "된다"고 적지 않는다.

## 2. 영향 지도 5문

**① 어디를 고치나.**

| 파일 | 무엇 |
|---|---|
| `app/config.py` | `solar_api_key` |
| `app/llm/provider.py` | `_KIND_TO_CLASS["solar"]`(OpenAI 호환) · `_DEFAULT_BASE` · 키 매핑 · 기본 모델 |

**② 새 클래스를 만드나.** 만들지 않는다. Solar 는 **OpenAI 호환**이라
`OpenAICompatProvider` 를 그대로 쓴다(groq·deepseek·xai 와 같은 길).

**③ 무료/유료 분류.** 🔴 `FREE_PROVIDERS` 에 **넣지 않는다.** 넣으면 기존
토큰 상한(`PAID_LLM_ALLOWED`·`is_paid_provider`)이 이 경로를 그냥 통과시킨다.
유료로 두면 이미 있는 가드가 그대로 걸린다.

**④ 무엇이 깨질 수 있나.**
- ⚠️ **사슬을 바꾸지 않는다.** 이 커밋은 공급자를 **고를 수 있게만** 한다.
  `FORM_CHAIN`·`JUDGE_CHAIN` 은 운영 환경변수이고, 실제 전환은 실측 뒤 별도로.
- ⚠️ 키가 없으면 크래시하지 않는다(절대 규칙 3) — 계약이 잠근다.
- ⚠️ `wiring_first` 의 "새 LLM 공급자를 붙이지 않는다"에 걸리지만,
  **사용자가 이름을 대고 지시**했다. 그 사실을 커밋에 적는다.

**⑤ 틀렸을 때 알려줄 테스트.** `tests/test_solar_provider.py` — 등록·주소·
모델명(전부 실측값) · 키 설정 · **유료 분류** · 사슬 선택 · 키 부재 무크래시.

## 4. 전환과 상한 (사용자 지시 2026-09-21 "전부다 solar로 가라" · "상한을 걸어라")

### 바꾼 것 — 환경변수만, 코드 변경 0

| 변수 | 전 | 후 |
|---|---|---|
| `JUDGE_CHAIN` · `FORM_CHAIN` | `gemini/gemini-3.5-flash-lite,groq/openai/gpt-oss-120b` | **`solar/solar-pro4`**,gemini,groq |
| `PAID_LLM_ALLOWED` | `0` | **`1`** |
| `NARRATOR_PROVIDER` · `_MODEL` | `groq` · (없음) | **`solar` · `solar-pro4`** |
| `INTERPRETER_PROVIDER` · `INTENT_PROVIDER` | `groq` | **`solar`** |
| `TOKEN_CAP_DAILY` | `0` (미설정) | **`500000`** |

🔴 **`PAID_LLM_ALLOWED=1` 이 없으면 solar 는 사슬에서 그냥 걸러진다.**
   solar 를 유료로 분류했기 때문이다(`💸 유료 후보 제외` 로그).
⚠️ gemini·groq 는 **뒤에 폴백으로 남겼다.** solar 가 죽어도 카드가 완전히
   멈추지 않게 하기 위함이고, 1순위가 solar 이므로 평소엔 타지 않는다.

### 상한 500,000 은 어떻게 나왔나 (실측 단가 × 이미 있는 하드 상한)

```
⑤ 추출   1,086 토큰/콜   (실측 · 프롬프트 1,741자 · 입력 807 + 출력 279)
⑫ 서술     326 토큰/콜   (실측 · 프롬프트 469자)

추출   llm.daily_call_cap = 200 콜  × 1,086          = 217,200
서술   오늘 경기 31 × 재시도 2 = 62콜 × 326×3(여유)  =  60,636
판정·봇 여유                                          =  93,000
                                                 합계 ≈ 371,000
```

→ 실측 합계의 **약 1.35배**인 500,000 으로 둔다. 근거 둘:
- 추출은 이미 **콜 수**로 하드 상한이 걸려 있다(200콜) — 그 경로는 폭주할 수 없다.
- groq 무료 TPD 가 **200,000** 이었고 09-20 에 하루 만에 소진됐다. 그 2.5배다.

⚠️ **미검증 사전값이다.** 일주일 실사용을 보고 고친다. 경고선은
   `PAID_WARN_RATIO=0.8` → **400,000** 에서 알림이 뜬다.
⚠️ 이 상한은 **공급자별**로 적용된다(`spent_today` 가 provider 별 키).
   `cap_for` 가 provider 를 가르지 않으므로 groq·gemini 에도 같은 값이 걸린다.
