# DS-1 — 딥서치 런타임 (영향 지도 5문)

사용자 지시 2026-09-21: "가로 진행"(DS-1 먼저) · "체인은 bing으로"

## ① 무엇이 없나 — 실측

```
grep -rl "robotparser|RobotFileParser|can_fetch"  app/ tools/   → **0건**
```
🔴 이 저장소에는 robots 를 검사하는 코드가 **한 줄도 없다.** [3] 감사는 임시
스크립트로 했고, 그것도 처음엔 stdlib 를 써서 **틀린 결론**을 냈다.
수집기 20여 개가 각자 요청을 보내고 누가 무엇을 얼마나 치는지 집계가 없다.

| 파일 | 무엇 |

| `config/deepsearch.yaml` | **값의 원본** — 동시성·간격·상한·서킷·robots·UA·검색 체인 |

**기존 코드 수정 0.** 이 단계는 **새 경로를 만들 뿐** 기존 수집기를 옮기지 않는다
— 옮기는 것은 DS-4a 의 어댑터 작업이고, 한 번에 하면 되돌릴 수 없다.

## ③ 🔴 stdlib 을 안 쓰는 이유 (사본이 아니라 버그 회피)

`urllib.robotparser` 는 `*`·`$` 를 해석하지 않는다. 그래서
`Disallow: /api/*` 를 문자 그대로 읽고 `/api/data/…` 를 **허용**이라 답한다.
이 버그로 내가 FotMob 을 "robots 명시 허용 — 유일하다"고 **오보했다**
(DS-0 → [3] 에서 정정). 구글 규격으로 직접 맞춘다:
`*`=임의 문자열 · `$`=끝 · **최장일치 우선** · 동률이면 Allow ·
**이름 블록이 있으면 `*` 를 무시한다**(news.google.com 이 `ClaudeBot` 을
이름으로 지목해 전면 거부하는 것이 실측이다).

## ④ 사본이 생기나

🔴 **안 생기게 했다.** 숫자·문구는 전부 `config/deepsearch.yaml` 하나에서 온다.
계약 `test_값은_config_에서_온다` 가 코드에 리터럴을 박는 것을 잠근다.

⚠️ `source_gate` 와 역할이 다르다 — 그쪽은 **사람이 끈 스위치**(정책),
   이쪽은 **robots 가 말하는 사실**(기계). 둘을 합치지 않는다.

## ⑤ 기존 경로를 건드리나

- **0건.** 수집기·스케줄러·판정 어디도 아직 이 런타임을 부르지 않는다.
- 기존 수집기의 UA 위장은 **그대로 둔다**(사용자 지시 "위장 거부 끄지 마라").
  이 런타임이 **자기 요청에** 쓰는 UA 만 식별 가능한 것으로 한다.
- ⚠️ 그래서 지금은 "만들어 놓고 안 이음" 상태다. **의도한 것이다** —
  지시문 순서가 DS-1 다음에 DS-2·DS-2a 이고, 이을 자리가 거기다.
  이 사실을 숨기지 않고 적는다.

## ⑥ 틀렸을 때 누가 알려주나
