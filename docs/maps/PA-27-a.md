# PA-27-a — 재판정이 기존 가감을 지운다. 결장인데 확률이 올라간다

## 왜

PA-27(딥서치 결과를 판정으로 돌려보내기)의 **전제를 확인하다 나왔다.**
`rejudge.reweigh` 실측 2026-09-17:

```
입력 adj={'주전결장': -1.5} · p_code=0.55
  diff 없음      → adj_after={'주전결장': -1.5}  p=0.55     ✅
  홈 결장 1명    → adj_after={}                 p=0.5575   🔴 확률이 **올라간다**
  원정 결장 1명  → adj_after={}                 p=0.5575   🔴 같은 값
  홈 복귀 1명    → adj_after={'라인업복귀:home': 2.25}  p=0.5687  ✅
```

지점은 한 줄이다:
```python
merged = {**base_adj, **add}
kept, dropped = A.drop_small(merged)      # ← 여기
```
`drop_small` 은 **각 변수를 개별로** 보고 `|1.5| < 2.0` 이라 **기존
`주전결장` 까지** 버린다. 그러면 확률이 시장으로 되돌아가고, **결장자를
확인했는데 홈이 유리해지는 거꾸로 된 신호**가 나간다.

🔴 **기존 가감에 이 규칙을 걸면 안 된다.** `ADJ_RULES` 의 기본 delta 는
   `-1.0`·`-1.5` 로 **전부 문턱(2.0) 아래**다 — 걸면 설계된 조정 대부분이
   지워진다. U8 의 "contrib < 2%p 제외"는 **per-player 기여**에 거는 규칙이지
   기존 adj 를 소급해 거르는 규칙이 아니다.
   (실제로 `drop_small` 은 `rejudge` 에서만 불린다 — 본 경로는 안 쓴다.)

## ① 이 함수/상태를 읽는 곳 **전부**

```
rejudge.reweigh                  ← 고치는 곳(:86)
  ├ adjust.drop_small            ← 유일한 호출부다. 규칙 원본은 adjust
  ├ adjust.contrib_out / contrib_return
  └ prob.p_code / _market_of
adjust.MIN_CONTRIB_PP (2.0)      ← 문턱 원본. 여기서 다시 적지 않는다
rejudge.reweigh 호출부            ← **0건**(PA-27 이 이을 예정)
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **잡음 제외를 없애는 것이 아니다.** **새로 더한 기여**에는 그대로 건다 —
  계약이 작은 복귀(0.02%p)가 여전히 빠지는지 잰다.
- 🔴 **기존 가감은 손대지 않는다.** 이미 판정에 반영된 값을 재판정이 소급해
  지우면, 라인업과 무관한 이유로 확률이 바뀐다.
- 🔴 **부호는 홈 기준 그대로다.** 홈 결장 −, 원정 결장 +, 복귀는 반대.
  계약이 네 경우를 다 잰다.
- 🔴 **diff 가 없으면 아무것도 안 바꾼다**(종전 동작).
- ⚠️ 호출부가 0건이라 **이번 수정으로 운영 동작이 바뀌지 않는다.**
  PA-27 이 이을 때 비로소 돈다.
- ⚠️ 한 명 결장(1.5%p)은 여전히 잡음으로 빠진다 — 두 명(3.0%p)부터 반영된다.
  그것이 U8 의 뜻이다. 같은 축을 합산할지는 **별건**이다(PA-27-b 후보).

종전으로 돌아간다.

