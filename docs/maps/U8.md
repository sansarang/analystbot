# U8 — 가중·결정축. 결장을 **이름 수**가 아니라 **중요도**로 센다

## 왜

```
재현 8건:
  importance() 가 없다 — U6 가 시장가치를 저장했는데 쓰는 곳이 없다
  결장 기여(−Σ importance×1.5, 상한 −6) 함수가 없다
  복귀 가중(×1.5)이 없다
  ADJ_DEFS 에 핵심결장·직전대패가 없다(9종이어야 한다)
  contrib < 2%p 를 빼는 규칙이 없다 — 잡음이 결정축에 낀다
  main_axis/counter_axis 를 코드가 고르는 함수가 없다
  원장에 adj_dropped 칸이 없다
```
지금은 주전 3명 결장과 후보 3명 결장이 **같은 −3** 이다. 그리고 `main_axis` 를
**미배선 `analyze`(LLM)** 가 채우게 돼 있다 — 코드가 정해야 한다.

## 공식 (지시문 3-2 그대로)

```
importance = 0.5·(최근10 선발/10) + 0.5·(시장가치 / (팀 선발11 총가치/11))
             ↑ lineup_history            ↑ U6 가 저장한 market_value
GK · 주장 · 득점1위 → 최소 1.0
출장 이력이 없으면 시장가치 단독(0.5 가중을 시장가치로 몰지 않고 그것만 쓴다)

결장 contrib = −Σ importance × 1.5   (상한 −6)
복귀 contrib = +Σ importance × 1.5 × 1.5
```

## ① 이 함수/상태를 읽는 곳 **전부**

```
(신규) adjust.importance · contrib_out · contrib_return · axes
adjust.ADJ_DEFS       ← adjust.attach (7종 → 9종)
prob.shrink_and_cap   ← p_code (contrib 제외는 그 **앞**이다)
main_axis/counter_axis ← 원장 칸(analyze.to_ledger 가 쓰려던 자리)
fotmob starters[].market_value · total_market_value  ← U6
lineup_history        ← 최근10 선발
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **`ADJ_SUM_CAP`(±6) 을 건드리지 않는다.** 결장 상한(−6)은 그 **안쪽**
  규칙이다. 둘을 섞으면 조정이 이중으로 잘린다.
- 🔴 **contrib 제외는 `shrink_and_cap` 앞이다.** 뒤에서 빼면 축소된 값으로
  2%p 를 재게 되어 기준이 달라진다.
- 🔴 출장 이력이 없을 때 **0 으로 읽으면 안 된다** — 신입·이적생이 전부
  중요도 0.5 가 된다. 시장가치 단독으로 간다.
- 🔴 팀 총가치가 0/None 이면 나눗셈이 터진다. 그때는 **출장률 단독**이고,
  둘 다 없으면 `importance = 1.0`(중립)이다 — 지어내지 않는다.
- ⚠️ `counter_axis` 는 **반대 방향 최대 1개**다. 같은 방향에서 2·3위를
  고르면 "반대 근거"가 아니라 "약한 같은 근거"가 된다.

## ③ 되돌리기

커밋 1개 revert + `ALTER TABLE pick_ledger DROP COLUMN adj_dropped`.
`ADJ_DEFS` 두 항목은 값만 늘린 것이라 되돌려도 기존 7종이 그대로 돈다.
