# PA-18 — 구속 하락이 기사로만 쓰이고 가감이 아니다 (D2 야구)

## 왜

지시문 Phase D2 원문:
> 야구: 선발 최근 3등판 평균 구속이 시즌 평균 대비 **−1.0mph 이상**이면
> `velo_drop` → 그 팀 **−2%p**(변수 대장 사전값).
> 이 값들은 **코드 가감**에만. LLM 서술엔 `notes` 로 한 줄.

`statcast_velo.velocity_trend` 는 `delta_mph` 를 정확히 낸다(전제 확인:
`{'last': 95.4, 'prior_avg': 96.55, 'delta_mph': -1.15}`, 문턱 1.0mph).
그런데 SAT-8 이 그것을 **문장으로 바꿔 기사로만** 넣고 **숫자는 버렸다.**
`ADJ_RULES["baseball"]` 에 `velo_drop` 이 없어 확률을 못 움직였다.

## ① 이 함수/상태를 읽는 곳 **전부**

```
statcast_velo.velocity_trend / VELO_DELTA_MIN  ← 계산·문턱 원본
satellite._mlb_velocity_articles (SAT-8)       ← 이미 계산한다. 숫자를 버렸다
(신규) satellite._write_velo / read_velo / _velo_key
satellite.gather                               ← jg["_redis"] 로 핸들을 싣는다
adjust.attach                                  ← 읽어서 jg["velo_drop"] 세팅
prob.ADJ_RULES["baseball"]["구속하락"]           ← (velo_drop, -2.0, -2.0)
models/features.sp_velo_drop                   ← ML 피처. **안 건드린다**(다른 것)
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **판정 경로에서 HTTP 를 안 켠다.** 위성이 이미 잰 값을 redis 에서 읽는다.
  Savant 를 판정 중에 치면 느리고 실패한다 — 계약이 그것을 잰다.
- 🔴 **통로는 Redis 다**(사용자 결정). 구속은 하루 지나면 무의미해 TTL 로
  사는 값이라 원장·스키마를 안 늘린다.
- 🔴 **홈 기준 부호다** — `drop_h - drop_a`. `out_starters`·`bullpen_b2b` 와
  같은 규약이고, 규칙 계수가 음수(−2.0)라 양수면 홈에 불리가 된다.
- 🔴 **오른 것은 신호가 아니다.** D2 는 하락만 말한다 — `<= -1.0mph` 만 센다.
- 🔴 **값이 없으면 미계산이다.** 0 으로 채우면 "떨어지지 않았다"가 된다.
- 🔴 **문턱을 손으로 적지 않는다.** `statcast_velo.VELO_DELTA_MIN` 이 원본.
- ⚠️ 기사(SAT-8 출력)는 **그대로 둔다** — 서술이 한 줄로 쓰는 재료다.
- ⚠️ `models/features.sp_velo_drop` 은 ML 피처이고 이것과 별개다. 안 건드렸다.

## ③ 되돌리기

커밋 1개 revert. `ADJ_RULES` 항목·redis 저장 3함수·`adjust` 블록이 빠지면
종전처럼 기사만 남는다. 스키마 변경이 없다.

## ④ 측정

①과 **같은 명령**이 통과한다. 배포 뒤 MLB 슬레이트에서 `[scout] 구속 기록`
로그와 원장 `adj_pp` 에 `구속하락` 이 찍히는 원문.
