# D1-3 — soft_proxy (마진 최대 북) + pinnacle_gap 채우기. 사용자 지시

## 왜

D1-2 뒤 북별 값은 들어왔지만 **`pinnacle_gap` 이 3경기 모두 NULL** 이었다 —
사설(soft) 쪽 값이 없어서다. ESPN 축구는 우리 IP 에서 **403**(실측:
`site.api.espn.com` ita.1·esp.1·eng.1 전부 Access Denied).

사용자 지시: 같은 스냅샷 안에서 `highestPayout` **최소** id 를 `soft_proxy`
로 쓴다(마진이 가장 넓은 북 = 가장 사설스러운 값). 요청 증가 0.

재현:
```
PYTHONPATH=. .venv/bin/python <scratchpad>/repro_d13.py
  → sharp_id: 851 · soft_id: None → 🔴 soft_proxy 가 없다
```

## ① 이 함수/상태를 읽는 곳 **전부**

```
app/collectors/oddsportal.py  parse_books · to_rows (정의) · 축구·야구 fetch
app/engine/book_gap.py        pinnacle_gap (SOFT_BOOK 상수)
tests/test_book_gap.py        계약
```

## ② 만드는/바꾸는 상태

| 상태 | 성격 |
|---|---|
| `odds_snapshots` `book='soft_proxy'` | 행이 는다(기존 `sharp_proxy` 와 같은 방식) |
| `parse_books` 반환 `soft_id` | 칸 하나 |

새 컬럼·새 요청 없다.

🔴 **`sharp_id == soft_id` 면 둘 다 세우지 않는다**(사용자 지시 — 같은 북을
   양쪽에 놓으면 gap 이 늘 0이다). 활성 북 3 미만이면 둘 다 None.

## ③ 리그·종목·경로 분기가 생기는가

생기지 않는다. 야구도 같은 파서를 쓴다.

## ④ 실패하면 "시끄럽게" 실패하는가

- 둘 중 하나라도 없으면 `book_gap.pinnacle_gap` 이 **NULL** 을 돌려준다.
  평균으로 대체하지 않는다(문서 "하지 말 것").
- 수집 로그의 `북별 N경기(샤프대용 M)` 줄에 soft 도 함께 찍는다.

## ⑤ 시스템에 이미 있는 사실을 다시 적고 있지 않은가

- 최소 북 수(`SHARP_MIN_BOOKS`)·위치 대응·값 검증은 D1-1/D1-2 것 그대로.
- 디빅은 `market_edge.implied_probs` 원본.
