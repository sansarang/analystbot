# PA-19 — 판정이 같으면 부수 기록이 통째로 건너뛰어진다

## 왜

`pick_ledger.record_analysis` 의 `unchanged` 분기:
```python
if existing is not None and _same_judgement(row, existing):
    await _fill_market(conn, existing["id"], row)
    stats["unchanged"] += 1
    continue          # ← 여기서 끊긴다
```
그 아래에 있던 것이 전부 안 돈다 — `record_clv` · `record_move`(흐름) ·
`record_prior`(사전값·게이트·가설) · `record_book_gap`(D1) ·
`record_confirm_and_analysis`(확인·구조·분석).

🔴 **실측 2026-09-16 17:48 ACLE 2경기**: `[v3]` 판정이 두 번 났는데 원장은
```
judged_at 06:16UTC 그대로 · 사전값 None · 게이트 None · need 0
```
축구는 같은 승자가 반복돼 **영원히 unchanged** 라, 티어를 채우고(PA-7)
길을 열어도(PA-6·PA-13) 값이 안 찼다. **오늘 축구가 안 되던 진짜 이유다.**

🔴 이 값들은 **판정이 같아도 시간이 지나면 달라진다** — 배당은 나중에 오고,
   라인업은 T-60 에 뜨고, 위성 추출은 다음 사이클에 붙는다. 주석이 시장
   (`_fill_market`)에 대해서는 그것을 알고 예외를 뒀는데 나머지 다섯은 안 뒀다.

## ① 이 함수/상태를 읽는 곳 **전부**

```
record_analysis  unchanged 분기(:304) · 삽입/재판정 분기
  └ (신규) _record_side_effects  ← 둘 다 이것을 부른다(사본 금지)
       record_clv        ← clv_at 을 줄 때만(판정 시각 전용)
       record_move       ← 흐름 · market_flow (PA-16)
       record_book_gap   ← D1 (PA-14)
       record_prior      ← 사전값·게이트·가설 (PA-6·PA-13·PA-15)
       record_confirm_and_analysis ← 확인·구조·분석 (U7·U12·PA-17)
_same_judgement / _SIG_FIELDS   ← 판정 동일 판단. **안 건드린다**
_fill_market                    ← 시장 채우기. 그대로 둔다
```

## ② 깨뜨릴 수 있는 기존 동작

- 🔴 **이력 행을 늘리지 않는다.** `unchanged` 는 그대로 `unchanged` 다 —
  판정이 같으면 새 최종 행을 만들지 않는다(LED-1 규약). 계약이 잰다.
- 🔴 **CLV 는 판정이 바뀔 때만 찍는다.** "판정 시각 배당"이라 그 시각이
  이미 지났다 — 매 회차 덮어쓰면 거짓이 된다. `clv_at` 을 줄 때만 돈다.
- 🔴 **부수 기록은 한 곳이다.** 두 분기가 같은 함수를 부른다. 두 곳에 적으면
  한쪽만 늘어나고, 그게 이 저장소가 여덟 번 겪은 병이다.
- 🔴 **하나가 터져도 나머지는 돈다.** 각각을 따로 감싼다.
- 🔴 **판정을 건드리지 않는다.** 전부 저장 전용 — INSERT·is_final·
  predicted_side·p_home 을 안 쓴다. 계약이 잰다.
- ⚠️ **호출이 늘어난다.** 종전에는 판정이 바뀐 경기에서만 돌던 것이 매 회차
  돈다. 대부분 DB 읽기라 싸지만, `record_confirm_and_analysis` 안의
  `analyze` 는 LLM 이다 — **게이트 대상(시장 과대·가치 의심)만** 돌고
  PA-15 예산이 그 앞을 막으므로 폭발하지 않는다. 첫 사이클에서 `[quota]` 확인.

## ③ 되돌리기

커밋 1개 revert. `unchanged` 분기가 다시 `continue` 하고, 삽입 분기가 개별
호출로 돌아간다. 스키마 변경 없음.

## ④ 측정

①과 **같은 명령**이 통과한다(부수 기록 4건 호출). 배포 뒤 ACLE·KBO 에서
판정이 안 바뀐 회차에도 `[gate]`·`[hypothesis]`·`[move]`·`[book-gap]` 로그가
찍히고 원장 칸이 차는 원문.
