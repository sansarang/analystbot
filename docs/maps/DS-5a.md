# DS-5a — 재순위로 LLM 입력 줄이기 (영향 지도 5문)

사용자 지시 2026-09-21: "순서대로 해라" (내 제안 4순위 = 새는 양동이 막기)

## ① 무엇이 틀렸나 — 실측한 "전"

운영 캐시에서 그대로 내려받았다(2026-09-21, `game=Valencia CF`):

```
Real Sociedad@Valencia CF   기사 14건 · 본문 9,177자
                            → 창 6,000자 (WINDOW_BUDGET **상한에 딱 걸림**)
                            → 프롬프트 7,101자 · 블록 12
```

🔴 **그 6,000자에 무엇이 들어 있나:**
```
"'피카츄'가 등장한다. 참여 시설은 ▲영국 런던 과학박물관 ▲프랑스 툴루즈…"   1,200자
"전망되고 있다. 경기후 이강인의 SNS에서도 레알 마드리드 팬들로 추정되는…"   1,200자
```
발렌시아–레알소시에다드 경기에 **피카츄 기사와 이강인 악플 기사**가 입력의
40%를 차지한다. 추출이 0건인 것이 이상하지 않다.

⚠️ 지시문 픽스처는 "09-20 K리그 2경기(무고사·대전 로테이션)"인데 **그 경기들은
   캐시에 기사가 0건**이었다(축구 12경기 중 기사가 있는 것은 이 한 경기뿐).
   지시문이 말한 바로 그 상황(**기사 14건**)이 여기 있어 이것으로 바꿔 썼다.
   **바꾼 사실을 숨기지 않는다.**

## ③ 사본이 생기나

- 키워드: `config/evidence_lexicon.yaml` 이 원본이다. `satellite._lexicon()` 이
  이미 그것을 읽으므로 **그 함수를 부른다** — 목록을 다시 적지 않는다.
- `k` 와 모델 스위치: `config/deepsearch.yaml` 하나.
- ⚠️ `_windows`(±300자 창)와 **역할이 다르다.** 그쪽은 팀 이름 주변을 자르고,
  이쪽은 **문단을 질문과의 관련도로 줄 세운다.** 둘을 합치지 않는다.

## ④ (c) 재순위 모델은 **기본 꺼짐**

지시문 DS-5a 2: "(a)(b)만으로도 동작해야 한다 · 외부 API 금지 · 메모리 실측 후
사용자 승인." 그래서 스위치만 두고 **구현하지 않았다** — 안 쓸 수도 있는 것을
미리 만드는 것이 이 저장소가 반복해 온 실수다.
계약 `test_rerank_works_without_model` 이 기본값이 꺼짐임을 잠근다.
