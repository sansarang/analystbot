## 2. 지은 것

```
⑤-b1 선수 능력치(새 단계)
  targets()  교체 짝 + 핵심 선수만 고른다(상한 전체 6명 · 한 팀 3명)
  fetch()    기존 `net.get` 으로 선수 페이지 → `fotmob.traits_of`
  said_of()  백분위 → **강점/보통/약점 글자**(수는 여기서 멈춘다)
     ▼
⑤-b2 전략 전문가 둘이 그 글자로 **가설**을 세운다
     ▼
⑤-b3 충돌이면 판정 → 맞으면 변수가 움직인다(어제 지은 그 통로 그대로)
```

| 파일 | 한 일 |
|---|---|
| `app/collect/fotmob.py` | `player_url()` · `traits_of()` · `FLANKS`/`WINGS` 옆에 **선수 번호(`pid`)를 안 버린다** |
| `app/core/schema.py` | `Player.pid` **칸을 더했다**(이름 바꾸기·빼기 금지 규율) |
| `app/core/adapt.py` | 그 번호를 `XI.lineup` 까지 싣는다 |
| **`app/core/ability.py`**(새) | 대상 고르기 · 받기 · **글자로 옮기기** |
| `config/ability.yaml`(새) | 강점·약점 문턱 **둘뿐**(0.70 / 0.30) |
| `app/core/strategy_llm.py` | `ability=` 재료 + 프롬프트 규칙(대체 가설·묶음 함정·**수 금지**) |
| `app/core/pipeline.py` · `tools/run_collect.py` | ⑤-b2 **앞**에 배선 |

### 🔴 잠금 넷(계약 17개 · `test_v30_2_ability.py` · 절제 11/11 빨강)
① **수는 안 넘긴다** — 모델이 받는 것은 `강점/보통/약점` 뿐이다(계약이 글에
   `0.8`·`80%` 가 **한 글자도 없는지** 센다). 문턱은 `config/` 가 든다.
② **대상을 고른다** — 한 명이 2.09초다. 22명이면 46초 → 교체 짝 + 핵심 선수만,
   상한 둘(전체 6 · 팀별 3) · 카드 상한이 바닥이면 **그 자리에서 멈춘다**.
③ **이름으로 찾지 않는다** — 열쇠는 `pid` 다(동명이인·표기 변형).
④ **못 받은 것은 이름으로** 남긴다 — 번호 없음 / 못 받았다 / 능력치 빈 칸 /
   상한을 **갈라서** 적는다.

⚠️ **갈래를 새로 만들지 않았다.** 능력치는 ⑤-b2 의 **재료**이고 변수는 기존
   갈래가 낸다 — 그래서 `config/variable_routing.yaml` 을 **안 건드렸다**.

```
- 대상 5명 / 자리 5곳 · ⬜ `L10`·`L11`·`L12` — 한 팀 상한 3명을 넘겼다
  `Julián Carranza`   [other forwards]        공중볼 강점 · 수비 행동 강점 · 득점 강점
  `Matías Espíndola`  [other forwards]        찬스 창출 강점 · 공중볼 약점 · 수비 행동 약점
  `Kaiky Naves`       [other center-backs]    수비 행동 강점 · 공중볼 약점
  `Duk`               [att midfielders/wingers] 공중볼 강점 · 나머지 보통
  `Luís Esteves`      [other midfielders]     찬스 창출 강점 · 슈팅 강점 · 수비 행동 약점
```
🔴 **비교 묶음이 선수마다 다르다**(forwards / center-backs / wingers /
midfielders) — 출처가 고른 그대로다. 🔴 **수가 한 글자도 안 나갔다.**

🔴🔴 **모델이 그 글자를 썼다** — solar 의 충돌 주장:
> *"Atlas는 4-2-2-2로 중원 2명이 버티고 Luís Esteves가 **강점**을 보여 …"*

그리고 ⑤-b2 가 대체를 제대로 읽었다:
> `SL1` *"홈은 CB **Kaiky Naves가 빠지고 대체 없이** 수비 자리 가치까지 떨어졌고…"*

### 다. 🔴 곁가지 — 어제 고친 `측면 집중` 이 **처음으로 수를 냈다**
```
Necaxa 측면(왼·오른) 선발 4명 ↔ Atlas 4명  → 차이가 2명 미만이라 안 가린다
```

글에서 사라졌다** — 사람이 보면 *"측면을 아예 못 쟀다"* 로 읽힌다(또 §4 그 병).
