운영에서 2단 의심을 **제거했다.** 판정은 **봇 확률**로 돌아간다(확신 구간 + 문턱).
여기 남은 것은 **되만들 수 없는 측정**이다 — 코드는 git 역사에 있다
(`9605dd57` 바로 앞까지).

## 왜 걷었나 — 재서 나온 셋

1. **역배 줄은 숫자놀이였다.** 여섯 칸이 전부 같은 81칸 격자를 다르게 더한 것이다.
   `강팀 미승 60.8%` = `더블찬스 1X 60.8%` = `핸디 +0.5 60.8%` — **같은 수**다.
   독립된 수는 홈·무·원정 셋뿐이다.
2. **J1(시장 괴리)은 시장을 베끼는 것이었다.** 봇이 시장과 10%p 이상 엇갈린
   76경기에서 봇 적중 **30.3%**, 안 엇갈린 1,091경기에서 **51.0%** — 엇갈릴
   때마다 시장이 이겼다. 그것을 의심으로 쓰면 남는 픽은 **전부 시장과 같은 쪽**
   이다. 북메이커를 베껴 적고 *"의심을 통과했다"* 고 쓰는 것이다.
3. **H1(순위 동기)은 오늘 쓸 대회에서 쟨 적이 없다.** 리그에서는 12개 중 10에서
   서지만(`h1_borrow.log`), **컵 표본이 0**이고 J1·KL1 은 개별로 ⬜ 다. 게다가
   컵 경기는 디비전을 넘나들어(J1 ↔ J2·J3·KL1·태국) 승점/경기 **자가 다르다**.

🔴 즉 **봇 자기 것으로 검증된 의심이 0개**였다. 44개를 재서 42개가 탈락하고,
   남은 둘 중 하나는 시장이고 하나는 쓸 데가 없었다.

## 🔴 걷어도 살아 있는 측정 둘

1. **봇 성적표는 단조롭다** — 승무패에서 봇이 42.5%→47.3%→52.1%→57.1%→63.7%
   라 한 구간의 실측이 **47.1%→56.1%→61.5%→70.0%→83.0%** 였다. 줄 세우기는
   작동하고 봇은 자기를 10~19%p **낮게** 말한다.
2. **핸디·언오버 확률에는 정보가 없다** — 봇이 41.9%라 한 칸 실측 56.7%,
   76.5%라 한 칸 실측 **51.0%**. 전부 51~57%로 뭉갠다(`ah_cause.log` AUC 0.511).
   🔴 **그래서 핸디·언오버를 칠 표 후보에서 빼는 규칙은 의심 단계와 무관하게
   유지한다** — 근거는 보정표가 아니라 이 실측이다.
