# 지시문: cc_collab_0925 — Claude Code ↔ 페이블 협업 환경 (훅·명령·에이전트·MCP·PR)

목적: 지시문·보고·export 가 **파일과 PR 로** 오가게 해서 복붙 왕복을 없애고, 규율(배포 창·발송 OFF·흐름 밖 픽 금지·갈림길 멈춤)을 **훅이 강제**하게 한다.
범위: `.claude/` 설정과 `docs/fable/` 폴더뿐. 봇 코드는 건드리지 않는다. 한 단계 한 커밋.

## CC-1 — 폴더 규약
```
docs/fable/
  inbox/      페이블 지시문(.md). 파일명 <날짜>_<이름>.md. 사용자가 넣는다.
  done/       실행 완료된 지시문(이동).
  reports/    실행 보고서. <지시문이름>_report.md — 아래 REPORT 형식.
  questions/  갈림길 질문. <날짜>_<주제>.md — 사용자가 페이블에 올린다.
  answers/    페이블 답. 사용자가 넣는다.
  exports/    페이블 요청 자료(json+md).
```
REPORT 형식(고정): `# <지시문> · 커밋 <해시들> · 배포 <시각|미배포>` / `## 완료 조건 원문` / `## 전/후 표` / `## pytest 마지막 20줄` / `## 고쳐 쓴 기존 테스트(목록·사유)` / `## 남은 것`.
계약 테스트 `tests/meta/test_fable_report_format.py`: reports/ 의 모든 파일이 위 5절을 가진다.

## CC-2 — 훅 (`.claude/settings.json`)
PreToolUse(Bash) → `guard.sh` · PostToolUse(Bash) → `after_commit.sh` · Stop → `on_stop.sh`.

`guard.sh` — 표준입력의 tool_input.command 를 읽어:
- `tools/deploy.sh`·`railway up` 이 포함되고 KST 시각이 17:00~22:00 이면 **exit 2**("슬레이트 창 배포 금지").
- `railway run`·`railway shell`·`ssh` 로 컨테이너를 직접 만지는 명령이면 exit 2("컨테이너 직접 수정 금지").
- `PIPELINE_V14_SEND=true` 또는 `pipeline_v14_send` 를 켜는 명령이면 exit 2("발송은 사용자만").
- `git push --force`·`git reset --hard origin` 이면 exit 2.
- 그 외 exit 0. 거부 사유는 stderr 로.

`after_commit.sh` — 명령이 `git commit` 을 포함했으면 `git log -1 --oneline` 과 `pytest -q 2>&1 | tail -20` 을 `docs/fable/reports/_last_commit.md` 에 덮어쓴다. 테스트 실패면 stderr 로 경고(막지는 않는다).

`on_stop.sh` — 세션이 멈출 때 `docs/fable/questions/` 에 오늘 날짜 파일이 없고, 마지막 어시스턴트 메시지에 "어느 쪽으로 갈까요"·"지시가 필요" 문구가 있으면 그 메시지를 `questions/<날짜>_auto.md` 로 저장한다.

훅 테스트: `tests/meta/test_hooks.py` — guard 에 위 명령 문자열을 넣어 exit 코드가 2 인지(시각은 환경변수 `FAKE_KST_HOUR` 로 주입).

## CC-5 — MCP
`.mcp.json` 에 `github` · `postgres_ro`.
- 토큰·URL 은 환경변수로만. **읽기 전용 DB 계정**을 따로 만든다(쓰기 권한 0). 파일에 값을 적지 않는다.
- github MCP 로 작업은 브랜치+PR 단위: `fable/<지시문이름>`. PR 본문 = 보고서.
- 구글 드라이브: Claude Code 에는 붙이지 않는다. 심볼릭 링크로 푼다.
