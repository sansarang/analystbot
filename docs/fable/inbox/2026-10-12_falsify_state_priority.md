# 🔴🔴 수정 지시서 — 감독 의도 · 경기 흐름 스크립트 · 반증 우선 (배선 위치 포함)

> 사용자 지시 2026-10-12 — **원문 그대로**(옮겨 적으며 고치지 않는다)

━━ 원칙 ━━
행동(오늘 XI·실측 골 시간)은 상성·시뮬로 들어가 확률을 만든다.
말·동기(감독 발언·일정 의미)는 검증(V3·V4)으로만 간다 — 확률 경로 금지(C1).
반증은 등급만 바꾼다(C2) — 단 무너진 조건이 라인업·결장 사실이면 상성부터 다시 돈다(F1).
작업 순서: 3(반증) → 2(상태별 득점률) → 1(우선순위 지수). 단계마다 계약·테스트 먼저 → 구현 → 초록 → 커밋 → 한 줄 보고.
모듈 이름·줄 번호는 지금 코드에서 실제로 확인해 보고에 적는다(아래 이름이 다르면 실제 이름을 따른다).

━━ 0. 새 칸의 위치 (목표 흐름 ①~⑯ 기준, ★ = 이번에 추가) ━━
 ② S0 경기 확정
 ③ S1 딥서치·구조 사실 ─── ★2a 상태별 득점률 표 로드(팀별)
                        └─ ★1a 시즌 최강 XI 가치 로드(팀별)
 ④ 깃발(turnover·r)
 ⑤ 추출·변수 → ⑥ 배치 ─── ★1d 감독 발언 → V4 · 다음 경기 일정 → V3 (확률 경로 없음)
 ⑦ 전략 판정 ─────────── ★1b 경기 우선순위 지수 계산 → 전략 판정 입력
 ⑧ 상성 재료 ─────────── ★1c 우선순위 지수 → 축0 재료 · ★2b 상태별 배율 → TeamRead
 ⑨ 상성 판정(MatchupReport)
 ⑩ 가설 세우기 ────────── ★3a 무너뜨릴 조건 목록(코드 생성)
 ⑪ 확률(λ → 분 단위 시뮬) ─ ★2c 매 분 스코어 상태별 배율 적용
 ⑫ 검증(V1~V7)
 ★⑫b 반증 딥서치 ──────── ★3b 조건별 질의 → 결과 표 → ★3c 무너진 조건이 라인업·결장 사실이면 ④로 1회 되돌림
 ⑬ 시나리오(표시용)
 ⑭ 보드 판정 ──────────── ★3d 간다/조건부/접는다 판정
 ⑮ 최종 평 ────────────── ★ 우선순위 지수·상태 스크립트·반증 표를 사실 묶음(FactBundle)에 추가
 ⑯ 카드 ──────────────── ★ 1겹 한 줄씩 · 📖자세히 전문

━━ 3. 반증 우선 (먼저 한다) ━━

[3a] 위치: ⑩ 가설 세우기 직후, ⑪ 확률 앞. 모듈: 가설 세우기 모듈 안에 함수 build_break_conditions 추가.
 입력: MatchupReport(우위 팀·축별 근거·꺼진 무기) + VariableSet + 라인업 상태(확정/보도/예상) + 우선순위 지수(1이 서기 전엔 빈칸).
 출력: BreakCondition 목록 — {id, 가설 id, 종류, 대상 팀·선수 id, 확인 방법(구조 사실/질의), 상태=미확인}.
 종류(코드만 만든다, LLM 추가·삭제 금지):
   K1 우위 팀 핵심 공격 선수(공격 기여 상위 2) 결장·벤치
   K2 우위 팀 무기 꺼짐(⑧에서 꺼진 무기)
   K3 V5 맞대결 반대 방향
   K4 라인업 미확정(확정 XI 아님)
   K5 우위 팀 우선순위 지수 낮음(1 이후, 문턱은 백필 적합 전 🔴 표시)
   K6 열세 팀 핵심 복귀(returning 변수)
 C3 유지: 이 함수는 S3 숫자를 보지 않는다.

[3b] 위치: ⑫ 검증 다음 새 단계 ⑫b. 새 모듈 s5b_falsify(이름은 기존 규칙에 맞춘다). pipeline.py에서 ⑫ 호출 직후·⑬ 앞에서 조건 없이 부른다(재생 모드 포함 — 재생 땐 저장된 결과 사용).
 하는 일: 조건마다 반증 질의를 ③ 딥서치와 같은 검색·신원·날짜 문을 그대로 써서 돌린다(새 검색기 만들지 않는다).
   질의: 팀·선수 현지어+영어 별칭(신원표) × 종류별 단어(결장·부상·로테이션·복귀·선발).
   구조 사실로 확인 가능한 것(K2·K3·K4)은 질의 없이 기존 사실로 판정.
 결과: 각 조건 상태 = 확인-무너짐 / 확인-무너짐 없음 / 미확인 · 출처·시각·근거 강도(hard/soft).
 로그: 자기 줄 "[s5b] 반증 — 조건 n · 질의 m · 무너짐 a · 없음 b · 미확인 c" (점검표 증거, 다른 단계와 겹치면 계약 실패).

[3c] 되돌림: ⑫b에서 새로 확인된 무너짐이 라인업·결장 사실(K1·K6)이면 그 사실을 VariableSet에 넣고 ④부터 재실행(F1 경로).
 루프 상한 1회 — 두 번째는 표시만. 카드 머리에 "🔁 반증으로 재계산 — 바뀐 것: 상성·확률·등급(전→후)".

[3d] 위치: ⑭ 보드 판정. 모듈: 등급 판정(s7_judge / compare.grade_step 중 실제 등급 정하는 곳).
 판정 칸 = 기존 등급 계산 결과 위에 반증 규칙을 얹는다:
   모든 조건 "확인-무너짐 없음" → 간다
   "미확인" 하나 이상, hard 무너짐 없음 → 조건부 · 미확인 조건을 방아쇠로 자동 등록
   hard 무너짐 1개 이상 → 접는다(등급 없음)
   soft 무너짐만 → 한 단계↓
 확률 불변(C2). 시장(V6)은 이 판정에 안 들어간다(C12).

━━ 2. 경기 흐름 스크립트 = 상태별 득점률 ━━

[2-오프라인] 적합 도구: tools/fit_state_rates.py(새로). data/state_rates/<league>.yaml에 저장.
 원천: 이미 받는 fotmob 리그 경기 골 시간(백필 두 시즌, 킥오프 전 자료만, 누설 금지).
 팀마다 상태(앞섬/동점/뒤짐)별 분당 득점률·실점률 ÷ 그 팀 평균 → 배율. 리그 평균 쪽으로 수축(표본 분 수 가중).
 리그 단위 배율(동점 후반 강도 포함 — 무승부 보정 지시의 2번과 같은 표로 합친다).
 표본 부족 팀 = 리그 배율 + 🔴.

[2a] 위치: ③ 구조 사실 수집. 팀별 상태 배율을 facts에 싣는다(없으면 리그값·🔴).
[2b] 위치: ⑧ 상성 재료. TeamRead에 state_mult {lead:{for,against}, level:{…}, trail:{…}} 필드로 싣는다.
 MatchupReport 축3 근거에 "리드 후 내려앉음/뒤지면 무너짐" 같은 관찰 줄을 적는다(확률은 ⑪에서만 반영 — 축3 합산에 또 더하지 않는다).
[2c] 위치: ⑪ 분 단위 시뮬 루프 안. 매 분 현재 스코어로 각 팀 상태를 정하고 λ분당 × 그 상태 배율.
 기존 축3 시간대 배율과 한 표로 합친다 — 같은 효과를 두 번 곱하면 계약 실패.
 주변분포 보정: 상태 배율 적용 뒤에도 팀 기대 득점 평균이 λ에서 ±2% 안(정규화).
 하류 자동 반영: ⑬ 시나리오·⑭ 보드 생존·오버 1.5/2.5/3.5는 이 분포를 그대로 쓴다(따로 손대지 않는다).

━━ 1. 감독 의도 = 경기 우선순위 지수 ━━

[1a] 위치: ③ 구조 사실. 팀별 시즌 최강 XI 가치(신원표 id 기준, 시즌 출전 시간 상위 11명을 포지션 틀에 맞춘 가치 합)를 싣는다.
 신원표(라인업 신원 통일 지시)가 서기 전엔 계산하지 않는다 — 빈칸·🔴.
[1b] 위치: ⑦ 전략 판정, 판정 함수 앞. 우선순위 지수 = 오늘 XI 가치 합 ÷ 최강 XI 가치 합(0~1+).
 전략 판정 입력에 넣는다(로테이션·체력 관리 판정의 근거 숫자). LLM 판정이 지수와 반대면 ④ 검사처럼 버리고 코드 판정.
[1c] 위치: ⑧ 상성 재료 축0. 축0은 이미 오늘 XI 가치를 쓰므로 지수를 축0 값에 또 곱하지 않는다(이중 반영 금지).
 지수는 축0 근거 줄과 K5 반증 조건 입력으로만 쓴다. 백필에서 축0만으로 설명 안 되는 추가 효과가 실측될 때만 별도 계수 검토(보고 후 결정).
[1d] 위치: ⑥ 배치. 감독 발언 → V4, 다음 경기 일정(컵·ACL·결승) → V3.
 ⑫ 검증에서 "말·일정 ↔ 행동(우선순위 지수)" 일치 여부를 적는다. 예: "다음 경기 결승(V3) — 오늘 지수 0.71로 아꼈다(행동 일치)".
 확률 경로 없음(C1·C7).

━━ 카드 위치 (⑯) ━━
 1겹: 상성 줄 아래 "🎯 우선순위 홈 0.94 · 원정 0.71" · 확률 줄 아래 "📜 스크립트 — 리드 후 홈 내려앉음(실점률 ×0.8)" · 결론 줄에 "반증 6조건: 무너짐 0 · 미확인 1 → 조건부(방아쇠: K4 확정 XI)".
 📖자세히: 반증 표 전문(조건·질의·결과·출처·시각), 상태 배율 표, 우선순위 지수 계산(최강 XI vs 오늘 XI 명단).
 ⑮ 최종 평 FactBundle에 세 항목 id로 추가(BRK:·STATE:·PRI:) — 검열 카탈로그에도 등록(없는 근거 오탐 방지).

━━ 계약·돌연변이 ━━
 B1 "간다"는 조건 목록 전부에 확인 결과가 있을 때만. B2 LLM이 조건 목록을 바꾸면 실패. B3 반증 단계 전후 S3 해시 같다(재실행 경로 제외).
 B4 반증 재실행 최대 1회. S1 상태 배율과 축3 배율이 같은 효과를 이중으로 곱하면 실패. S2 상태 배율 적용 후 팀 평균 득점이 λ ±2%.
 P1 우선순위 지수를 축0에 곱하면 실패. P2 V3·V4가 λ·확률 경로에 나타나면 실패.
 돌연변이: 반증 단계 건너뛰기 / 미확인인데 "간다" / 상태 배율 두 번 곱하기 / 지수 축0 이중 반영 → 전부 빨강.
