# 검증 지시 — 10-14 새벽 챔피언십 6경기 · 축이 방향을 못 바꾼 원인 (측정만 · 확률 경로·계수 변경 금지)

> 사용자 지시 2026-10-14(밤 일곱째) · 원문 그대로

배경
- 운영 M1 · M1만(축 0) · 상성만(홈 배율 0) 방향 비교에서 운영 M1은 6경기 전부 홈을 골랐다(적중 1/6).
- 축이 홈 배율을 이긴 경기가 0이다. 결과는 원정 승 4 · 무 1 · 홈 승 1.
- 질문은 셋이다: (가) 축 값이 틀렸나(버그·결측) (나) 축은 맞는데 힘이 약했나(가중·β) (다) 홈 배율이 과했나(팀별 홈 효과).

1. 경기별 분해표 (6경기 전부 · 카드 재료 그대로)
- 축0~축3: 홈 원값 · 원정 원값 · 차 · 가중 · 기여(%p) · ⬜ 여부와 사유
- 축 종합 · β 0.25 → λ 이동(홈/원정)
- 홈 배율: 리그 ×1.120 · 팀별 홈 효과(원값 · 표본 n · 수축 가중 · 최종 배율) · 원정 몫 ×0.880
- 최종 λ 에서 축 몫 vs 홈 배율 몫 비교: "방향을 정한 것" 한 줄

2. (가) 축 값 점검 — 버그·결측
- 부호: 6경기 전부 (홈 − 원정) 부호가 카드 설명과 맞는지. 예: 스완지 축1 +0.671 이 원정 쪽으로 들어갔는지.
- 결측: 울브스 폼 ⬜ → 축1 이 0 으로 들어갔나, 빠졌나. ⬜ 가 0 으로 바뀌어 원정 우위를 지운 경우를 전부 찾는다.
- 축0: 확정 XI 기준인지 · 가치 없는 선수(신규 영입·임대)가 0 으로 들어가 축0 을 깎았는지 · 강등팀(울브스·번리) PL 시절 가치가 반영됐는지.
- 축1: 표본 기간(이번 시즌만? 지난 시즌 이월?) · 운 요소 골 제거가 맞게 됐는지(웨스트 브롬 8골 제거 근거) · 9경기 시즌 초 표본 수축 여부.
- 축2: 6경기 전부 차 ≈ 0 이었다 → 계산이 실제로 도는지 · 6지표 원값 출력 · 백필 전체에서 축2 차의 분포(중앙값·10~90 분위). 거의 항상 0 이면 🔴 "사실상 꺼짐".
- 축3: 번리 "홈 리드 후 막판 실점 3연속"이 축3·리드 유지력에 들어갔는지. 안 들어갔으면 왜인지.

3. (나) 힘 점검 — 가중·β
- 경기별 "방향이 뒤집히려면 필요한 β"(축 종합이 홈 배율 몫을 넘는 β) 계산.
- 어제 6경기 축 종합 크기를 백필 분포와 비교 — 유난히 작았나, 평소도 이 정도인가.
- 백필에서 운영 M1 과 M1만의 방향이 갈린 경기 수 · 비율. 0% 에 가깝다면 축은 방향을 거의 못 바꾸는 구조다.
- 그 갈린 경기들에서만 방향 적중: 운영 M1 vs M1만 vs 상성만.

4. (다) 홈 배율 점검 — 팀별 홈 효과
- 카디프·밀월 ×1.295 처럼 큰 팀별 홈 효과: 원값 · 표본 n · 수축 전후.
- 시즌 초(홈 4~5경기) 표본으로 만든 팀별 홈 효과가 다음 홈 경기 결과를 맞히는지 — 백필에서 "팀별 홈 효과 상위 20% 팀" 홈 승률 예측 vs 실측.
- 리그 홈 이점 ×1.120 이 그 시즌 실측 홈 승률·홈 득점 몫과 맞는지(시즌별).

5. 하지 말 것
- β·가중·홈 배율 값을 바꾸지 않는다. 어제 6경기로 계수 판단 금지.
- 고칠 것이 버그(부호·결측·0 대입)면 고치되, 고친 판은 백필 규칙 v2+(d) 판정 후에만 운영에 들어간다.

보고
- 1번 분해표(6경기) → 2번 버그·결측 목록(🔴/🟡/✅) → 3번 β 역산표 + 백필 방향 갈림 비율·적중 → 4번 팀별 홈 효과 보정표.
- 맨 끝에 원인 한 줄: (가)·(나)·(다) 중 무엇이 주원인인지와 근거 수치.
