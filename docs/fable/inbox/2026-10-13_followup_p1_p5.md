# 🔴🔴 후속 지시 — P1 검증·V리그 · P5 보드 경로 · P0 자동화

> 사용자 지시 2026-10-13(밤) — **원문 그대로**(옮겨 적으며 고치지 않는다)

1. P1 오프셋 검증 (판정 전에 먼저)
- 외부 순위와 순위 상관: UEFA 국가 계수(5시즌) · AFC 클럽 대회 순위 vs 우리 오프셋 → 스피어만 ρ 보고. ρ < 0.6 이면 적합 방식부터 의심.
- 원인 점검: (1) 수축 K=20 이 맞대결 수 대비 너무 세서 전부 0으로 끌려갔나 — K = 5/10/20 세 판 비교
               (2) 국내 리그 Elo 척도가 리그마다 달라(평균 1500 고정) 오프셋이 그 차를 다 떠안는가
               (3) 대륙 대회 표본이 상위 팀 위주라 생기는 치우침
- 사우디·J1·PD·BL1 네 리그의 맞대결 상대 리그별 승무패표를 같이 낸다.
- 카드의 🌐 표시 줄은 ρ ≥ 0.6 확인 전까지 🟡 "검증 전" 꼬리표.

2. P1 판정 (대륙 대회 백필)
- ACLE·ACL2·UCL 최근 3시즌 교차 판 재생 → 오프셋 넣은 판 vs 안 넣은 판 · 규칙 v2+(d).
- 통과하면 대륙 대회 확률 경로에 넣고, 탈락이면 표시만 유지.

3. V리그 등 미산출 리그 (꽁안–가시마 같은 경기)
- 표본 확장: ACL2 5시즌 + ASEAN 클럽 챔피언십(쇼피컵) 교차 경기 + AFC컵(과거) 포함.
- 그래도 맞대결 < 10 이면 이웃 리그 경유값(태국·말레이시아 등 ASEAN 리그와의 경기로 연결) + 🟡. ⬜ 로 두지 않는다(P1 원 지시 조항).

4. P5 보드 경로 (배당 피드 키 없어도 된다)
- 수동 입력: `board add <경기id>` 에 붙여넣기 형식(승무패 3개 · 핸디 줄·배당 2개 · 오버언더 줄·배당 2개) → var/board/<날짜>.yaml.
- 캡처 이미지 입력은 §6-5 추출기(숫자 판독만 · 판단 없음)로. 판독 결과를 사용자 확인용으로 카드에 그대로 찍는다.
- 입력되면 해당 카드 재실행: 마진 제거 시장 확률 나란히 · 차이 ≥10%p 🔴 시장 괴리 + ⬜ 입력 목록 · ⬜ 걸린 괴리 줄 결론 상한 "접는다".

5. P0 자동화
- 지금은 --run 수동이다. 스케줄러를 상주시켜 T−24h / T−3h / XI 단계를 사람 없이 돈다(launchd 또는 봇 프로세스 안 타이머). 단계마다 텔레그램으로 카드 발송.
- XI 단계 트리거: fotmob 라인업 폴링 5분 간격(T−90분부터) → 뜨는 즉시 ⑲.

6. P3 규칙 고정
- 감독은 경기 페이지 isCoach 를 우선 원천으로 한다(팀 페이지 이력 행 금지). 둘이 다르면 경기 페이지 채택 + 🟡 기록. 계약 테스트 추가.

7. 오늘 ACL 채점
- 교토–랏차부리·포항–조호르·상하이–대전·부리람–베이징·꽁안–가시마·이스트 벵골–알쇼르타 결과를 score_cards 에 기록. 사후 카드(상하이–대전)는 적중 기록에서 뺀다.
- 꽁안–가시마·부리람–베이징은 "시장 괴리" 사례로 따로 표시(괴리 방향 vs 결과).

보고: 1번 ρ·K 비교표 → 2번 판정표 → 3번 V리그 오프셋 → 4·5번 동작 실측(보드 1건 입력 → 재실행 카드) → 7번 채점표.
