# 상성 중심 확률 엔진 지시서 (전문 재작성 — 변수 체계 포함)

🔴 **사용자 지시 2026-10-10(여섯째).** 받은 글을 **그대로** 둔 것이다 — 옮겨 적으며
고치지 않는다(CLAUDE.md: *"지시문은 파일로 넣는다. 옮겨 적지 않는다"*).

🔴🔴 이 문서는 **확률 경로의 정본**이다 — 앞 지시서들의 *"③ 변수가 로그 오즈를 민다"*
경로를 **대체한다**(§2 지우거나 옮길 것).

0. 목적과 원칙
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
질문은 하나다: "이 팀이 오늘 이 라인업으로 이 상대를 이길 수 있나".
 P1. 확률의 출처는 상성 하나다. 상성(오늘 XI 기준 네 축)이 기대 득점을 정하고, 시뮬레이션이 그것을 승무패·오버로 바꾼다.
 P2. 변수는 버리지 않는다. 지금까지 만든 변수(기사 변수 R, 구조 변수 S, 해석 규칙 변수 IR)는 모두 살아 있고,
     각 변수는 성격에 따라 세 자리 중 하나 이상에 배치된다 — ① 상성 축의 입력 ② 검증 출처 ③ 가설의 근거.
     확률에 닿는 길은 ①(상성 축을 통해, 적합된 크기로)뿐이다. 변수가 로그 오즈를 직접 미는 옛 경로는 없앤다.
 P3. 상성 밖 정보(동기·일정·감독 발언·Elo 기준·맞대결·시장)는 확률을 움직이지 않는다. 상성 결론과 같은 방향인지 검증하고,
     반대면 이유를 드러내고 등급만 조정한다.
 P4. 상성 → 확률의 크기는 과거 경기로 적합한다. 적합 전에는 "🔴 임시"를 숫자 옆에 단다.
 P5. LLM은 확률을 만들지도 바꾸지도 않는다. 변수 추출·가설·전략 판정·평 문장만 쓴다.
 P6. 사용자가 물은 경기 하나만. 최종 확률은 확정(또는 2매체 보도) XI에서만, 예상 XI는 "잠정".
범위: 축구. 묻지 말고 끝까지. 단계마다 계약·테스트 먼저 → 구현 → 초록 → 커밋 → 한 줄 보고.

V-1 생성 (기존 그대로)

V-2 사실 검증 (기존 s5 그대로, 하나도 빼지 않는다)
 - 출처 등급·출처 수 → 근거 가능 / 근거 불가(context_only).
 - 팀 귀속: 선수 명단 대조(same_person·name_key)로 강제, 애매하면 근거 불가.
 - 중복 금지: 같은 사실 여러 기사 → 하나로 묶고 출처 수만 올림. 감독·로테이션 주제 묶기.
 - 유형–내용 일치 검사(부진 문장을 fatigue로 단 것 등 버림), "정보 없음" 문장 버림.
 - 선발 제외 해석: 시즌 선발 비율 30% 미만 선수는 결장 변수 아님(교체 운용).
 - 득점 방향(goals up/down) 꼬리표: 리그 기준 대비로 코드가 단다.
 - 무게표(hard/soft·유형별 무게)는 유지한다 — 다만 이제 무게는 확률을 직접 밀지 않고, ①상성 축 안에서의 표본 신뢰도, ②검증에서 "반대의 크기", ③가설 근거 순위에 쓰인다.

S2. 상성 판정 (코드 — 입력은 FactBundle + VariableSet의 ①배치 변수)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
각 축은 홈 관점·원정 관점 값, 우위 쪽, 강도, 근거 변수 id를 낸다.
 축0 오늘 XI 전력
  - 선수 가치 합(오늘 XI vs 상대 오늘 XI, 로그), 결장·복귀 변수 반영(빠진·들어온 선수 가치), 호흡(오늘 선발끼리 함께 선발로 뛴 경기 수 평균).
 축1 보정 폼
  - 최근 10경기 득점·실점(가능하면 xG·xGA)을 상대 전력으로 보정. 약팀 상대 대승 깎고 강팀 상대 결과 올림.
  - 운 요소 할인(자책골·PK·초저 xG 득점), IR04 회귀 보정.
  - squad_turnover: 과거 경기 가중 = 그 경기 선발 중 오늘 명단에 있는 비율 r.
 축2 전술 상성
  - 스타일 6축(빌드업·압박·역습·크로스·세트피스·수비 블록, 리그 백분위)을 오늘 XI 변화·lineup_intent로 조정.
  - 규칙 T1~T8 두 방향 판정. 결장 변수로 무기 꺼짐, 복귀 변수로 무기 켜짐, 교체 운용 선수 = 후반 무기.
  - 피로 변수는 T2(압박 감쇠)로만, 적합된 경우에만.
  - 전략 판정(LLM 1회, 근거 2개 이상, 수치와 반대면 버림): 공격 위주·수비 위주·역습·로테이션·선수단 교체·실험·평소 그대로.
    coach_intent 변수는 확정 XI와 일치할 때만 판정 근거로.
 축3 골 내용 상성
  - 시간대·경로·리드 유지력·추격력(분모 함께), 규칙 T9~T13 상대 약점 매칭. 해당 유형 골 5개 미만 = 관찰만.
  - venue_record(hard)는 여기서 해당 구장/원정 경기만 따로 집계.
  - squad_turnover 팀은 r 가중.
 종합 판정: 축별 우위·강도를 적합된 비중으로 합쳐 {상성 우위 팀, 강도: 강·중·약·없음}.
 산출: MatchupReport(축별 값·우위·근거 변수 id·발동 규칙·꺼진/후반 무기·전략 판정·종합 판정).

 3-1 기대 득점:
   log λ홈 = 리그 평균 득점(로그) + 홈 이점(리그 실측) + 대회 유형 상수 + β·(축0~축3의 홈 공격 vs 원정 수비 특징)
   log λ원정 = 리그 평균 + 대회 유형 상수 + β·(원정 공격 vs 홈 수비 특징)
   입력은 MatchupReport뿐. Elo·동기·일정(T2 경유 제외)·감독 발언·맞대결·시장·LLM 문장은 금지.
 3-2 시간대·경기 상태: 축3 시간대 비중으로 λ를 구간 분할, 리드 유지력·추격력으로 상태별 배율.
 3-3 시뮬레이션: 분 단위(또는 같은 구조 해석 계산) + 저득점 보정 → 스코어 분포 →
   승무패, 오버 1.5/2.5/3.5(보드 기준선이 다르면 그 기준선도), 무득점 확률, 시간대 득점, 선제골 팀 승률, 예상 스코어 상위.
 3-4 축별 기여 분해(리그 평균 대비): 축0 x %p · 축1 y · 축2 z · 축3 w — 합 = 리그 평균 대비 변화.
   그리고 축마다 그 기여를 만든 변수 id 상위 3개.
 3-5 적합(tools/fit_matchup_model.py 신규)
   - 자료: 백필(K리그1·J1 두 시즌부터). 각 과거 경기에서 S1·S1V·S2를 "그 경기 킥오프 전 시각"으로 재현해 특징을 만들고 스코어를 정답으로.
   - 적합 대상: β(축별·특징별), 축 종합 비중, 운 요소 할인율, r 가중 형태, 호흡 효과, 시간대·상태 배율, 대회 유형 상수, 저득점 보정.
   - 누설 금지: 경기 m 특징에 m 자신·이후 자료가 들어가면 실패.
   - 시간순 분할. 보고: 로그 손실·브라이어·보정표(승무패·오버 1.5/2.5/3.5), Elo 기준 모델과 비교, 축별 기여 비중.
   - 채택: 검증 구간 로그 손실이 Elo 기준 모델 이하면 "적합 모드". 미달이면 결과 보고 + "임시 모드" 유지(사용자 판단).
 3-6 임시 모드: λ = 리그 평균 × 홈 이점 × exp(임시 계수 × 표준화된 축 차). 임시 계수는 config 한 곳·근거 주석·카드에 🔴 임시.
   리그 자료 부족(이번 시즌 30경기 미만)이면 "기준 약함".
