# 최종 평(마지막 단계) 지시서 — 코드가 낸 사실만으로 전술 전문가처럼 승부를 판정하는 글

🔴 **사용자 지시 2026-10-10(넷째).** 받은 글을 **그대로** 둔 것이다 — 옮겨 적으며
고치지 않는다(CLAUDE.md: *"지시문은 파일로 넣는다. 옮겨 적지 않는다"*).

---

목적: 카드의 마지막 단계. 코드가 만든 사실 묶음만 보고 LLM이 한 편의 평을 쓴다 —
"누가 빠지고 누가 들어와서 → 어느 자리·측면이 강해지고 약해졌고 → 그래서 골이 어디서 나고 어디서 막히고 → 그래서 어느 팀이 이긴다".
LLM은 새 사실·새 숫자를 만들지 않는다. 확률도 바꾸지 않는다(확률은 앞 단계가 이미 정했다). 평의 결론은 최종 확률과 같은 방향이어야 한다.
묻지 말고 끝까지.

━━ 1. 사실 묶음 (코드가 만든다, LLM 입력의 전부) ━━
각 항목에 id를 붙인다. 없는 칸은 "없음"으로 넣고 LLM에게 그 칸에 대해 말하지 말라고 한다.
1-1 라인업 변화(자리·측면 단위)
 - 평소 XI 대비 자리별: 빠진 선수 → 들어온 선수, 포지션 세부(GK·CB·LB·RB·LWB·RWB·DM·CM·AM·LW·RW·ST)와 측면(왼/중앙/오른).
 - 들어온 선수와 빠진 선수의 비교 수치: 수비수는 경합 승률·태클·가로채기·공중볼, 공격수·윙어는 90분당 득점·도움·드리블·크로스·슈팅,
   시즌 출장 시간(경험), 나이(어린 선수 첫 선발 여부).
 - 측면 판정(코드): 예) "왼쪽 수비: 주전 LB(경합 승률 상위) → 대체 LB(첫 선발, 경합 승률 하위) — 약화".
1-2 측면별 공격·수비 지표(있는 리그만)
 - 팀 공격 방향 비중(왼/중앙/오른) — fotmob 경기 통계에 있으면. 없으면 오늘 XI 측면별 공격 선수의 기여 합으로 근사(근사 표시).
 - 팀 실점 방향(어느 측면에서 기회를 허용했나) — 있으면.
 - 측면 맞대결(코드): "A 오른쪽 공격(오른쪽 윙어 드리블 상위) ↔ B 왼쪽 수비(오늘 약화)" 같은 대응을 자동으로 짝짓는다.
1-3 골 내용(축3): 최근 10경기 득점·실점 유형(필드골·역습·세트피스·PK·자책골)과 시간대, 선제골 후 결과, 운 요소 비중.
 - "필드골 0 — 최근 5경기 득점이 전부 세트피스·PK" 같은 문장은 코드가 사실로 만든다(LLM이 세지 않는다).
1-4 전략·스타일: 팀 전략 판정(수비 위주·공격 위주·로테이션 등)과 근거, 스타일 6축 백분위, 발동 규칙 T1~T13과 효과.
1-5 동기·일정: 순위·경우의 수 상태(게이트 통과 시), 감독 발언(새 사실), 휴식일·직전 대회·이동.
1-6 결장·복귀·새 사실(72시간) 목록.
1-7 확률: 최종 승무패·오버 1.5/2.5/3.5, 잠정→최종 변화와 축별 기여(폼·전술·골 내용), 예상 스코어 상위 3개(묶인 분포에서).

━━ 2. LLM 1회 — 구조화 출력 ━━
출력 칸:
 - verdict: 이길 팀(또는 "무승부 쪽"·"반반") — 최종 확률의 방향과 같아야 한다.
 - key_points: 3~5개. 각각 {주장, 메커니즘(어디서·어떻게), 근거 id 2개 이상}.
   예) 주장 "부천은 오늘 골을 넣기 어렵다" / 메커니즘 "최근 5경기 득점 4골 중 필드골 0, 세트피스 득점 주역 성예건 벤치, 3백 전환으로 공격 숫자 감소" / 근거 [G3, L5, S2]
   예) 주장 "강원은 오른쪽으로 공격할 것이다" / 메커니즘 "부천 왼쪽 수비가 주전 대신 첫 선발 선수, 강원 오른쪽 윙어 김대원 시즌 16골" / 근거 [L2, P7, M1]
 - flow: 전반·후반 흐름 각 한 문장(골 시간대·체력·교체 카드 근거).
 - decisive_moment: 승부처 하나(예: "60분 이후 페리어 투입", "세트피스").
 - flip_condition: 결론을 뒤집을 조건 하나(예: "부천이 먼저 세트피스로 넣으면 3백으로 잠근다").
 - one_line: 카드 헤드라인 아래에 들어갈 한 줄 요약.
프롬프트 원칙: 축구 전문가의 말투로, 측면·자리·골 경로를 구체적으로. 사실 묶음에 없는 선수·숫자·사건은 쓰지 않는다. 
 "기세", "정신력" 같은 근거 없는 말은 사실 id가 없으면 쓰지 않는다.

━━ 3. 검열 (기존 총평 검열에 추가) ━━
 (q) 근거: key_points마다 근거 id 2개 이상, 전부 사실 묶음에 있는 id.
 (r) 수치: 문장 속 숫자·선수 이름이 근거 항목과 글자 그대로 맞는다.
 (s) 측면·자리 주장: "왼쪽이 약하다"류 문장은 1-1·1-2의 측면 판정 id가 있어야 한다. 근사 지표면 "근사"라고 써야 한다.
 (t) 골 경로 주장: "필드골이 없다"류는 1-3 사실 id 필수.
 (u) 방향: verdict·one_line·flow가 최종 확률 방향과 같다. 반반이면 한쪽 승리를 단정하지 않는다.
 (v) 운 요소: 자책골·PK로 만든 득점을 "득점력"의 근거로 쓰지 않는다.
 위반 → 재작성 1회 → 또 위반이면 코드 템플릿 평(사실 묶음 상위 근거 셋 + 확률 방향).

━━ 4. 카드 ━━
1겹 맨 끝, 보드 판정 위에:
🧑‍🏫 최종 평 — {verdict}
 {one_line}
 · {key_point 1: 주장 — 메커니즘}
 · {key_point 2}
 · {key_point 3}
 📈 흐름: {전반} / {후반}   ⏱ 승부처: {decisive_moment}
 🔄 뒤집히는 조건: {flip_condition}
긴 카드(/디버그): key_point마다 근거 id와 원 사실, 검열 결과.

━━ 5. 검수 ━━
백필 재현(as-of 킥오프 50분 전)으로 강원–부천 · 인천–포항 · 가시와–고베 · 가시마–감바 · 대전–전북의 최종 평 전문.
경기마다 꼭 나와야 할 것(사실 묶음에 있으면):
 - 강원–부천: 부천 3백 전환·성예건·가브리엘 벤치 → 부천 득점 경로 감소 / 강원 복귀 수비 2명
 - 인천–포항: 무고사 복귀 선발·페리어 후반 카드 / 포항 득점력 하위
 - 가시와–고베: 세가와 후반 카드(결장 아님)·골키퍼 교체 / 고베 최정예·최소 실점
 - 가시마–감바: 가시마 공격 3명·수비 실점 많음 / 감바 7경기 무승
 - 대전–전북: 양 팀 센터백 경고 누적 대체 — 어느 쪽 중앙이 더 약해졌는지 비교
그리고 측면 지표가 없는 리그에서 "왼쪽/오른쪽" 주장이 나오지 않는지(근사 표시 없이 나오면 실패).

금지: 사실 묶음 밖의 사실·숫자 / 평으로 확률 바꾸기 / 근거 없는 감성어 / 시장을 근거로 쓰기 / EV·금액 / git stash·checkout·restore·reset.
