# AnalystBot — 경기 찾기·라인업·뉴스 지시서 (재작성)

🔴 **사용자 지시 2026-10-10.** 이 파일은 받은 글을 **그대로** 둔 것이다 —
옮겨 적으며 고치지 않는다(CLAUDE.md: *"지시문은 파일로 넣는다. 옮겨 적지 않는다"*).

---

전제: 자동 분석이 아니다. 사용자가 경기를 물으면 그 경기 하나만 찾아서 분석한다. 묻지 않은 경기는 돌리지 않는다.
원칙 셋: ① 물은 경기는 반드시 찾는다(못 찾으면 사용자에게 한 번 물어서라도 찾는다 — 추측해서 다른 경기를 붙이지 않는다)
         ② 라인업은 확정 XI까지 받는다 ③ 새 뉴스(72시간)는 판단에 반드시 들어간다.
묻지 말고 끝까지. robots·약관이 막은 출처, 관찰하지 않은 엔드포인트 추측, git stash·checkout·restore·reset 금지.

━━ 1. 경기 찾기 (findgame) — 물은 경기 하나 ━━
입력: 사용자 문장(팀 이름 한국어·영어·현지어 아무거나, 날짜·리그 있으면 같이) + 보드 캡처가 있으면 보드.
1-1 후보 만들기 (순서대로, 찾으면 멈춘다)
 ① 보드가 있으면 보드의 날짜·시각·두 팀·리그 표기를 먼저 읽는다(이게 가장 정확한 단서다).
 ② fotmob 팀 색인(sitemap, robots 허용) → 두 팀 후보 id → 각 팀 일정 HTML에서 날짜 창(오늘~+3일, 보드 시각이 있으면 ±3시간) 안 경기.
 ③ fotmob 리그 페이지(자동 등록 리그 포함)의 일정 HTML.
 ④ ESPN 경기 HTML(robots 허용 경로만).
 ⑤ 리그 공식 사이트(K리그 관찰된 XHR, J리그 jleague.jp — 관찰 후 적은 것만).
1-2 이름 대조: 정규화 함수 하나(same_team). 방향 있는 대조, 리그 id·나라·날짜로 좁힌 자리에서만 느슨한 대조.
     "Super League"처럼 리그 이름이 여러 나라에 걸리면 이름으로 고르지 않는다 — 리그 id로만.
1-3 결과
 - 후보 1개 → 진행.
 - 후보 2개 이상 → 텔레그램 버튼으로 고르게 한다(리그·날짜·시각을 붙여서). 고르기 전에 분석하지 않는다.
 - 0개인데 보드가 있다 → 보드로 경기를 만든다(source=user_board): 대회명은 보드 표기 그대로, 공식 일정 출처 없음 표시, 분석은 그대로 진행.
 - 0개이고 보드도 없다 → "경기를 못 찾았다 — 시도한 출처: … / 가까운 후보: …(최대 3개)" + "보드 캡처나 날짜·시각·리그를 보내 달라".
   사용자가 다시 주면 그걸로 1-1부터.
 - 이미 킥오프 지남 → "이미 시작한 경기 — 예측 아님"(등급 없음). 결과가 나왔으면 결과를 보여 준다.
1-4 리그 자동 등록: 찾은 경기의 리그 id로 data/leagues_auto/{key}.json에 쓴다(출처·확인일·나라·언어·팀 목록 출처 필수, 없으면 등록 실패).
     config/leagues.yaml(수동)은 기준 모델·분할 규칙이 필요한 리그만. "수동 선언으로 테스트 우회" 금지 계약은 유지.
1-5 언어: 나라 FIFA 코드 → data/fifa_to_iso.yaml(공개 목록, 출처·확인일 머리에) → ISO → CLDR 언어. 잉글랜드·스코틀랜드·웨일스·북아일랜드는 en.
     검색은 그 나라 언어 + 영어(+ 상대 팀 나라 언어).

━━ 2. 라인업 — 확정 XI까지 ━━
2-1 출처 사다리(리그별 config/lineup_sources.yaml, robots·확인일 기록):
 ① fotmob 경기 페이지(선발·벤치·포메이션) ② ESPN 경기 HTML ③ 리그 공식(K리그 XHR 관찰분, J리그 jleague.jp 관찰 후)
 ④ 기사 추출: "[현장라인업] {홈} {원정}", "[K리그1 라인업]", "スタメン発表 {팀}", "{팀} starting XI", "11 ตัวจริง {팀}", "首发 {팀}" 등 —
    두 매체 이상 일치하면 confirmed, 하나면 reported.
 구단 SNS는 공식 API가 주는 주소를 카드에 링크로만 보여 준다(자동 수집 안 함).
2-2 상태 표시: 카드 머리 "📋 라인업 {확정|보도|예상|없음} · 출처 · HH:MM". 못 받으면 "사다리에서 무엇을 돌았고 무엇이 막혔는지" 한 줄.
2-3 확정 전 처리: 등급은 "잠정", 결론 줄 "⏳ 라인업 전 — 잠정 판단 · 라인업 예정 HH:MM".
     카드에 버튼 [🔔 라인업 나오면 다시 분석] — 사용자가 누른 경기만 그 시각부터 5분 간격으로 사다리를 돌고,
     확정되면 재분석해서 원래 메시지를 고쳐 쓴다("🔁 확정 XI 반영 — 바뀐 것 …"). 누르지 않으면 돌지 않는다(자동 분석 아님).
     [🔄 재분석] 버튼은 지금처럼 즉시 한 번.
2-4 선발 해석 규칙:
 - "선발 제외"를 결장으로 읽기 전에 그 선수의 시즌 선발 비율을 본다. 30% 미만이면 결장 아님(교체 운용 — 예: 가시와 세가와, 전 경기 교체 7골).
 - 복귀 선수(부상·병역·대표팀)가 선발이면 returning 변수, 벤치면 "복귀했지만 벤치" 사실로만.
 - 직전 경기 대비 바뀐 자리 수, 휴식일, 직전 경기가 어떤 대회였는지(리그·컵·대륙 대회) — 로테이션·피로 판단 재료.

━━ 3. 뉴스 — 72시간 새 사실 ━━
3-1 하위 과제 F(경기 하나에 대해서만): 팀마다, 킥오프 기준 72시간 안, 현지어+영어.
 개념 낱말(search_words.yaml): 복귀·합류·전역·부상·결장·출전 정지·경고 누적·대표팀 차출·로테이션·기자회견·감독 발언·징크스·원정 강세·
 직전 대회 일정(컵·대륙 대회) / 復帰・合流・離脱・欠場・出場停止・会見・スタメン / return·injured·suspended·ruled out·press conference /
 กลับมา·บาดเจ็บ·แบน / 复出·伤停·停赛·首发 / regresa·lesionado·suspendido.
 고정 출처: 구단 공식 뉴스, 리그 공식 프리뷰(kleague.com 프리뷰·jleague.jp 見どころ 등 관찰된 것), 경기 페이지의 결장 명단.
3-2 추출 유형: returning, squad_boost, absence/suspension, coach_quote(감독 의도), venue_record(특정 구장·원정 기록 — 경기 목록으로 검증되면 hard),
 schedule_load(직전 경기 날짜·대회·이동 — 예: 라차부리 10/7 쇼피컵 → 이틀 휴식), stakes(순위·강등·컷).
3-3 버림 규칙:
 - premature_result: 기사 시각 < 킥오프인데 최종 스코어를 말하면 버린다(소후 가짜 결과 기사).
 - 팀 귀속은 명단 대조(same_person)로 강제, 애매하면 근거 불가.
 - 같은 사실 여러 기사 → 하나로 묶고 출처 수만 올린다.
3-4 카드 블록 "🆕 새 사실(72시간)": 항목 한 줄 + 출처·날짜 + 변수 번호. 0건이면 "새 사실 0건 — 검색 n회·문서 m건"과 운영자 알림.
3-5 판단 반영: 새 사실 변수는 일반 변수와 같은 무게표로 ③ 이동·시나리오 driver에 들어간다.
 카드 이유 문단에 새 사실이 하나라도 있으면 최소 한 문장은 새 사실을 쓴다(검열 항목 추가).

━━ 4. 시간 기준 ━━
- 모든 창(경기 찾기·72시간·라인업 상태·"이미 시작")은 현재 시각 기준. 테스트용 --as-of "YYYY-MM-DDTHH:MMZ"를 붙이면 그 시각 기준(재현 모드).

━━ 5. 인수 — 이 목록이 다 통과해야 끝 ━━
A. 찾기 (as-of = 킥오프 2시간 전, 질문은 한국어로):
 우니온–데펜사 이 후스티시아 / 라이언 시티–공안 하노이 / 강원–부천 / 대전–전북 / 가시마–감바 / 가시와–고베 /
 라차부리–수코타이 / 선전–허난 / 모레이렌스–질 비센트 / 카자흐스탄–페로 제도
 + 보드 기반: 터키컵 예실유르트–겔레첵, 세리에D 테라누오바–프라토, 애들레이드 시티–유나이티드(클럽 친선)
 기준: 13/13 경기 확정(또는 버튼 선택 후 확정). 다른 경기를 붙인 사고 0건.
B. 라인업: 위 경기 중 확정 XI가 있었던 것(강원·인천·가시마·가시와·대전)은 as-of = 킥오프 50분 전에 "확정"으로 나와야 한다. 출처 기록 포함.
C. 새 사실: 아래가 카드 🆕 블록에 나와야 한다(80% 이상).
 강원 — 황문기·김이석 병역 복귀, 이기혁·이승원·신민하 아시안게임 금메달 복귀 / 부천 — 올 시즌 강원전 1승 1무, 강릉 3-0
 가시와 — 세가와 전 경기 교체 출전 7골(선발 제외 = 결장 아님) / 가시마 — 리그 4경기 무승, 나흘 뒤 하노이 ACL 원정
 라차부리 — 10/7 쇼피컵 공안 호찌민전, 이틀 휴식 / 수코타이 — 원정 13경기 12패
 선전 — 웨슬리·오우수·벤코비치·샤다룽 복귀, 다이웨이쥔 최근 3경기 2골 1도움 / 허난 — 7경기 무승 2골, 나자리우 결장
 인천 — 무고사 복귀 선발·김건희 아시안게임 복귀, 페리어 벤치
D. 가짜 결과 기사(소후 "선전 1-0 허난")가 premature_result로 버려지는지.
