# 공격형 검증 지시 v2 — 봇 결론을 변수별로 공격해 좁힌다 (전체)
(앞 지시 ①~④ 판정·반영 판 위에서 · 코드 판정 · LLM 없음)

> 사용자 지시 2026-10-14(밤 아홉째) · 원문 그대로 — 아래 §0~§7 과 보고 순서

0. 원칙
- 봇 결론(방향 · 줄 · 확률)이 공격 대상이다. 결론을 받치는 변수를 큰 순으로 하나씩 공격한다.
- 공격 결과: 버팀(근거 확인 · 남김) / 깨짐(결론에서 빼고 기여 0 으로 재계산) / 반격(결론 반대쪽 변수가 새로 확인됨 · 반대쪽에 더함).
- 깨진 변수를 빼고 재계산한 "살아남은 결론"만 출력한다. 원래 결론과 나란히.
- 변수는 무궁무진하다 → 모든 변수는 3단 등급으로 관리한다:
  [확정] 백필에서 효과가 측정된 변수 — 깨짐 판정에 쓴다
  [관찰] 데이터는 있으나 효과 미측정 — 카드에 표시만, 판정 안 함
  [가설] 데이터 미확보 — 수집 목록에만
- [관찰]→[확정] 승격은 백필 측정(효과 크기 · 시즌 교차 확인)으로만. 효과 없으면 강등·제거.

1. 공격 대상 정리 (경기마다)
- 원래 결론 · 봇 확률 · 받치는 변수 목록(기여 %p 큰 순) · 각 변수의 등급.

2. 변수 공격 목록
【A. 전력 · 체급】 A1 Elo 차 [확정] · A2 축0 선수 가치 [확정] · A3 스쿼드 깊이 [관찰] · A4 이적·임대 직후 [가설]
【B. 폼 · 운】 B1 축1 폼 [확정] · B2 xG 차이 [관찰→우선 측정] · B3 운 요소 골 [확정·T12] · B4 골키퍼 선방 과대 [관찰] · B5 연승·연패 [관찰]
【C. 장소 · 이동】 C1 리그 홈 이점 [확정] · C2 팀별 홈 효과 [확정·③ 반영판] · C3 이동 거리 [관찰→우선 측정] · C4 중립 경기 [확정·CC3] · C5 관중 규모·무관중 [관찰] · C6 인조잔디·고지대·구장 크기 [가설]

【E. 라인업 · 결장】 E1 확정 XI 핵심 빠짐 [확정] · E2 결장 사다리 원천 등급 [확정] · E3 포지션 구멍 [관찰] · E4 예상 XI 판 [확정]
【F. 경기 흐름】 F1 리드 유지력 [확정·① 부호 수정판] · F2 추격력 [확정] · F3 막판 득실 시간대 [관찰] · F4 교체 영향 [관찰] · F5 세트피스 의존도 [관찰]

(각 항의 공격 방식·문턱은 원문 그대로 — 지시 본문 참조)

3. 공격 후 재계산
- 깨진 변수 제거 · 반격 변수 추가 → 같은 시뮬 함수로 λ · 승무패 · 줄 확률 재산출.
- 경기표: 원래 결론 / 깨짐(번호 · 사유 · 뺀 %p) / 반격(번호 · 더한 %p) / 살아남은 변수 / 살아남은 결론 / 판정(살아남음 · 약해짐 · 무너짐).
- 결론 한 줄: "이 결론은 [변수 번호] 몇 개에 걸려 있다".

4. 출력
- 단폴: 살아남은 결론 · 줄 확률 ≥ 문턱 · 경기당 1줄.
- 다폴: 다리 문턱 이상 · 2폴/3폴 · 같은 경기 금지 · 다리 전부 같은 방향 금지 · 같은 리그·킥오프 최대 2.
- 줄마다 보드 배당 기록(계기판 · 판정 미사용).
- 살아남은 결론 없으면 "오늘 단폴 없음 / 다폴 없음".

5. 변수 측정 순서 (백필 · 시즌 교차 · 누설 금지)
- 1차: C3 이동 거리 · D1 휴식일 · B2 xG 차이 · D4 로테이션 · F1 리드 유지력(부호 수정판) · K1 무 편차.
- 2차: G1·G2 · H1 · C5 · I1 · F5.
- 3차(수집부터): C6 · D5 · D6 · H3 · H4 · J2.
- 변수마다: 해당 경기 수 · 결론 적중률(변수 걸림 vs 안 걸림) · 차이 95% 구간 · 시즌별 안정성. 차이가 구간상 0 을 포함하면 [관찰] 유지.

6. 공격 자체 검증
- 공격별: 깨짐 판정이 실제로 틀린 결론을 가려냈나. 효과 없는 공격 제거.
- 문턱 곡선: 단폴·다리 문턱별 적중률 · 하루 출력 수.
- 손잡이 수 제한: [확정] 변수만 판정에 쓰고, 문턱은 시즌 교차로만 고른다.

7. 어제(10-14) 챔피언십 6경기 재시험 — 문턱 고정 후
- 경기마다 3번 표. 확인할 것: 울브스(A2·B1 ⬜·J1) · 번리(F1·K1) · 카디프·밀월·렉섬(C2 · 카디프 B1) · 밀월(C2 뒤 스완지 · B2 반격) · 브리스톨(B4).
- 살아남은 결론으로 뽑은 단폴·다폴 vs 실제 결과.
