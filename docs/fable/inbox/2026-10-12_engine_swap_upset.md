━━ 0. 배경 · 원칙 ━━
배경: 444경기 백필에서 새 구조(Elo 바닥 + 축0·축1)가 Elo만을 이겼다.
실사고(10-11): 광주 4-3 울산(광주 28경기 무승 · 3주 휴식 후 홈 · 울산 2연패), 가와사키 1-2 나고야(가와사키 주전 2명 부상 · 직전 컵 일정 · 나고야 교체 선수 결승골).
시장·봇 모두 강팀을 봤다. 봇은 과거 성적으로 판단했고 경기 직전 상태를 몰랐다. 축구에서 흔한 경우다.

목표: 적중률. 경기 직전 상태와 이변 신호 가운데 예측력이 확인된 것은 확률(λ)에 넣는다. 확인 안 된 것만 경고로 남긴다.

원칙
- 새 구조의 뼈대(바닥 점수 → 보정 → λ → 격자·시뮬)는 유지. 그 안의 부품을 후보로 시험해 나은 것만 교체·추가.
- 확률을 바꾸는 단계: ③ 구조 사실 · ④ 깃발 · ⑦ 변수 배치 · ⑧ 신원 검문 · ⑪ 상성 재료 · ⑬ 상성 판정 · ⑯ 확률 · ⑲ 되돌림.
  등급만 바꾸는 단계: ㉑ 보드 판정 · ㉒ 반증 판정. 표시: ㉓ 카드. 나머지(⑭⑮⑰⑱⑳㉔)는 동결 — 입력 이름이 바뀌는 곳만 따라 고친다.
- 모든 변경은 "후보 판"으로 먼저. 운영 확률은 현 probfloor 그대로 두고 백필 판정을 통과한 판만 승격.
- 모든 계수·학습률·문턱은 날짜 판(walk-forward): data/<표>/<league>/<as_of>.yaml. 로더는 as_of 이전 최신 판만. 손값 금지(없으면 🔴 + 확률 미산출).
- 과거 자료는 전부 fotmob.before_as_of 를 지난다(L1). 현재 상태 입구(시즌 누계·결장 명단·명부)는 재현에서 경기 단위 재합산만(L2).
- 확률에 들어가는 건 실측·백필로 이득이 확인된 숫자만. 확인할 수 없는 것(기사·사유·동기)은 등급·표시로만. LLM 판단 금지.
- 실사고 두 경기에 맞추려고 계수·문턱을 고치지 않는다. 적합은 백필 전체로만.
- 단계마다: 계약·테스트 먼저 → 구현 → 초록 → 커밋 → 한 줄 보고. 묻지 말고 끝까지. 결과 보고 전 판정 규칙을 바꾸지 않는다.

━━ 4. 확률 변환 (⑬ → ⑯ · app/core/probfloor.py) ━━
손값 β 삭제. 식(후보 항은 채택된 것만 남는다 — 미채택 항은 식에 없음):
   log λ홈  = b0 + h + b1·diff·(1 − c3·pb_home) + b2·pdiff + c1·restΔ + c2·loadΔ + c5·cupΔ + c4·absΔ + c6·form3Δ
   log λ원정 = b0     − b1·diff·(1 − c3·pb_home) − b2·pdiff − c1·restΔ − c2·loadΔ − c5·cupΔ − c4·absΔ − c6·form3Δ
   (모든 Δ 는 홈 − 원정. benchΔ 는 λ 식이 아니라 ⑯ 시뮬 60분 이후 배율 — 8절)
그 위에 Dixon-Coles ρ(리그별) → 스코어 격자 → 승무패·오버·핸디·BTTS·역배·보호 줄 전부 같은 격자에서.
[적합] tools/fit_probfloor.py --league --as-of --terms <채택 목록> — 시간 감쇠 가중 포아송 최대우도, 모든 계수 동시 적합 → data/probfloor/
   h 는 기존 홈 이점 실측 판과 비교 기록(따로 곱하지 않는다).
[배선]
   ⑬ matchup.report → Covariates 생성(모든 후보 항 계산, adopted 플래그로 식 포함 여부 결정).
   ⑯ probfloor.compute(Covariates, 판) → λ. probmodel.run 은 이 λ로만 시뮬. 상태 배율(앞섬·동점·뒤짐)·benchΔ 는 시뮬 안에서만, 팀 평균 득점 λ ±2% 정규화.

   F3 일정 부하·직전 컵      → loadΔ(c2) · cupΔ(c5)

   벤치                     → benchΔ(d1, 8절)
[적합 순서 — 전진 선택] 기준 = 3·4·5·6절 채택 조합.
   한 항씩 추가 → 로그 손실 구간상 이득이면 채택 → 다음 항은 채택된 식 위에서 비교. 순서: restΔ → loadΔ·cupΔ → pb_home(c3) → absΔ → form3Δ → benchΔ.
   항마다 그룹 효과도 보고: 그 신호가 켜진 경기들의 방향 적중률·로그 손실(후보/기준).
계약 S1: 채택 판정 없이 항이 λ에 들어가면 실패. S2: 같은 신호가 λ 식과 경고 점수에 동시에 들어가면 실패.

━━ 10. 이변 경고 — 확률로 못 간 신호만 (⑳ · app/core/upset.py · 확률 불변) ━━
대상: 9절 미채택 신호 + 확률로 넣을 수 없는 신호
   F6 약한 강팀(강팀 승 < 50%) · F8 정보 공백(InfoQ ≤ 2, 13절) · F9 고분산(λ합 상위 q 분위) · 9절 미채택 항
[적합] tools/fit_upset.py --league --as-of — 로지스틱: 강팀 미승 ~ (1 − p_강팀) + 남은 신호 → 신호별 추가 기여·구간.
   구간이 0을 품는 신호는 제외(표시 "검증 안 됨"). S = Σ 채택 계수 · 신호값.
   등급: 🟡 S ≥ 상위 30% 분위 · 🔴 S ≥ 상위 10% 분위 → data/upset_model/
[검증표 — 필수] 등급별: 경기 수 · 예측 강팀 승률 평균 · 실제 강팀 승률 · 차이 구간 · 약팀 +1.5 실제 생존 · 약팀 더블찬스 실제 적중.
   🔴 의 실제 강팀 승률이 예측보다 구간상 낮을 때만 운영 🔴 켬. 아니면 🟡 "참고"만.
⚠️ 9절에서 확률로 간 신호가 많을수록 경고는 줄어드는 게 정상이다(확률이 이미 담았으니까).
계약 U3: 경고가 확률·λ·생존에 닿으면 실패. U5: 검증표 미통과 등급이 운영 경고로 켜지면 실패.
