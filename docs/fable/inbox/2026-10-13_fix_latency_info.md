# 🔴🔴 수정 지시 — 정보 부족·지연 해소 (오늘 ACL 6경기 사고 기준 · 우선순위 순)

> 사용자 지시 2026-10-13(밤) — **원문 그대로**(옮겨 적으며 고치지 않는다)

진단(오늘 실측)
- 늦다: 상하이–대전 카드가 킥오프 뒤에 나왔다("이미 시작한 경기"). 세 카드 실행에 2h17m.
- 리그 간 전력이 없다: 꽁안–가시마는 시장과 29%p 차이가 났다(J1 1위 vs V리그). 리그 오프셋·Elo 미산출 → 축0 + 홈 이점만으로 섰다.
- 대회 이력이 없다: 부리람 ACL 홈 강세(중국 팀 상대 2전 2승 무실점·2시즌 연속 8강)를 봇이 몰랐다(S03 ⬜).
- 과거 경기를 못 받는다: 꽁안은 축1·축2·축3 전부 미산출(등록 리그 밖 팀).
- 신원이 낡았다: 베이징 감독 Montgomery(카드) vs Amarelle(fotmob).
- 검색이 막혔다: 꽁안전은 신원 불일치 412건(도박 사이트) · 문서 1건.

P0 — 시간 (오늘부터)
- 사전 실행: 경기 확정되면 T−24h 기본 카드(XI 없이) → T−3h 갱신(결장·검색) → 확정 XI 뜨면 즉시 ⑲(T−60~45분). 기본 카드는 킥오프 3시간 전까지 반드시 나와 있어야 한다.
- 캐시: 팀 과거 경기·대회 일정·순위표·신원표는 하루 1회 미리 받아 둔다. 카드 실행 때는 새로 받는 건 XI·결장·72시간 기사만.
- 시간 상한: 카드 1장 15분. 넘는 단계는 ⬜ + 사유로 넘기고 카드를 낸다. 킥오프가 지난 카드는 "사후 기록용"으로만 저장.
- 슬레이트 스케줄러: 그날 대상 경기 전부를 킥오프 순으로 큐에 올리고 각 단계 시각을 카드 머리에 찍는다(T−24h/T−3h/XI 확정 판 각각).

P1 — 리그 간 전력 (대륙 대회 핵심)
- 등록 리그 밖 팀도 국내 리그 과거 경기를 받는다(fotmob 팀 페이지 · 리그 id 자동 등록 · kind=domestic_league). 꽁안(V리그)·부리람(T1)·조호르·상하이·베이징·이스트 벵골·알쇼르타 리그 우선.
- 리그 오프셋 적합(§5-3 앞당김): ACL Elite·ACL2 최근 3시즌 교차 리그 경기 + 각 국내 리그 Elo로 리그별 오프셋을 적합(수축 · 표본 수 표기). 리그 쌍 표본 < 10 이면 이웃 리그 경유 값 + 🟡.
- 판정: 대륙 대회 백필(교차 판)에서 오프셋 넣은 판 vs 안 넣은 판을 규칙 v2+(d)로 판정. 통과 전에는 카드에 "리그 간 전력 차(표시만)" 줄로만 낸다 — 확률 경로에 안 넣는다.

P2 — 대회 이력 칸 (S03 채우기)
- 대륙 대회 카드에 팀별 "이 대회 직전 2시즌 홈/원정 승무패·득실" · "상대 리그 팀 상대 성적" · "최고 성적(16강·8강 등)" 줄 추가. 원천: 대회 일정 표(fotmob) + AFC 공식 경기 결과.
- 국내 리그 팀도 같은 칸: 홈/원정 직전 시즌 성적.

P3 — 신원 신선도
- 감독·주장·핵심 선수 신원표를 하루 1회 fotmob 팀 페이지와 대조. 다르면 🔴 "신원 불일치" + 최신 쪽 채택 + 변경일 기록. 감독 부임일 작업(6번)과 묶는다.

P4 — 검색 (언어·원천)
- 현지어 질의 필수: 팀 국가 언어(vi·th·zh·ar·ja·ko·hi·en)로 팀명 현지 표기 + "선발·부상·결장·기자회견".
- 차단 목록: 도박·카지노·배팅 사이트 도메인 패턴(nổ hũ·casino·bet·slot 등)은 s3 전에 버린다 — 신원 단계까지 오지 않게.
- S등급 원천 추가: AFC 공식 경기 프리뷰·사전 기자회견 페이지(the-afc.com) · 구단 공식 사이트·SNS. 대회 기구 공시는 결장·징계 S등급.
- 리그별 A등급 목록 확정: 각 국가 통신사·스포츠지 2곳 이상.
- 목표: 카드당 문서 ≥ 5건 · 신원 불일치 비율 < 30%. 미달이면 InfoQ 감점 + 카드 머리에 표시.

P5 — 시장 괴리 진단 (LLM 없음 · 표시만)
- 보드가 있으면 마진 제거 확률을 우리 확률과 나란히(사용자 규칙 10-06). 결론·등급은 우리 확률로만.
- 차이 ≥ 10%p 줄은 🔴 "시장 괴리" + 그 경기에서 ⬜ 인 입력 목록(리그 오프셋·대회 이력·축1~3·Elo·XI 판 등)을 자동으로 붙인다.
- ⬜ 입력이 하나라도 걸린 괴리 줄은 결론 상한 "접는다"(우리가 모르는 정보로 생긴 차이일 수 있으므로). ⬜ 없이 생긴 괴리만 조건부까지 허용.
- 경기 후 score_cards에 괴리 줄 결과를 따로 쌓는다(괴리 ≥10%p 에서 우리 vs 시장 적중률).

보고

- P1 리그 오프셋 적합표(리그·표본·오프셋·수축) + 판정표.
