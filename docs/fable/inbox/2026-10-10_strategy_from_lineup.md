# 확정 라인업 전략 분석 → 승률 재계산 지시서

🔴 **사용자 지시 2026-10-10(둘째).** 받은 글을 **그대로** 둔 것이다 — 옮겨 적으며
고치지 않는다(CLAUDE.md: *"지시문은 파일로 넣는다. 옮겨 적지 않는다"*).

---

목적: 라인업이 확정되면 "감독이 오늘 무엇을 하려는가(전략)"를 분석하고, 그 결과로 승무패·언더오버 확률을 다시 계산한다.
라인업 전 확률은 "잠정", 확정 라인업 반영 확률이 "최종"이다. 사용자가 물은 경기 하나에만(🔄 재분석 또는 🔔 라인업 알림을 누른 경기).
계수는 과거 자료로 적합한다 — 감으로 정한 숫자는 "임시값" 표시. robots 허용 경로만. 묻지 말고 끝까지.

━━ 1. 언제 돈다 ━━
- 라인업 상태가 확정(또는 두 매체 이상 보도)일 때만. 예상 XI로는 전략을 추론하지 않는다("확정 XI 전 — 전략 분석 없음").
- 돌면: s2(XI) → §2~§4 → s5~s7 재계산 → 원래 카드 메시지를 고쳐 쓰고 "🔁 확정 XI 반영 — 바뀐 것"을 맨 위에.

━━ 2. 오늘 명단에서 전략 읽기 (코드 + LLM 1회) ━━
2-1 사실(코드, 평소 XI = 최근 5경기 선발 빈도 상위 11명과 비교)
 - 포메이션 변화(예: 4백→3백), 자리별 교체(포지션 세부 GK·CB·FB/WB·DM·CM·AM·W·ST), 공격수 수·수비 자원 수 증감
 - 핵심 선수 선발/벤치/명단 제외 — 단, 시즌 선발 비율 30% 미만 선수의 벤치는 "평소 운용"(가시와 세가와)
 - 복귀 선수 선발 여부(부상·병역·대표팀 — 새 사실 72시간과 연결)
 - 바뀐 자리 수(로테이션 규모), 직전 경기 날짜·대회(체력 관리 이유가 있는지)
 - 선수 단위 공격·수비 기여 합(시즌 90분당 득점·도움·슈팅 / 태클·가로채기·클리어, 출장 적으면 포지션 평균으로 수축):
   오늘 XI vs 평소 XI 변화율 ΔA(공격)·ΔD(수비)
2-2 전략 판정(LLM 1회, 구조화 출력 — 입력은 2-1 사실 + 동기 상태 + 감독 발언(새 사실) + 상대 XI 사실):
 팀마다 strategy ∈ {공격 위주, 수비 위주(잠그기), 역습, 로테이션·체력 관리, 실험, 평소 그대로} + 근거 사실 id 2개 이상 + 한 줄 이유.
 코드 검사: 판정이 2-1 수치와 반대면 버린다(예: ΔA −15%·3백 전환인데 "공격 위주" → 위반). 근거 없는 판정 금지.
2-3 맞대결 판정(코드): 두 팀 전략 조합으로 경기 양상 표시 — 공격 vs 잠그기 / 둘 다 잠그기 / 둘 다 공격 / 한쪽 로테이션.

━━ 3. 확률에 반영 ━━
3-1 전력 변화(②, 이미 있음): 오늘 XI 선수 가치 → 승무패 이동. 계수 없는 리그는 ③ 무게표로(앞 지시).
3-2 전략 변수(③에 새 유형 strategy_intent):
 - 승무패: 잠그기 → 그 팀 패 확률↓·무승부↑ / 공격 위주 → 그 팀 승·패 둘 다↑(무승부↓) / 로테이션 → 그 팀 승↓ / 실험 → 무승부·변동성↑.
 - 총골: ΔA·ΔD와 2-3 조합으로 두 팀 λ를 움직인다(총골 모델 지시서의 λ 배율).
 - 이동량: 과거 자료로 적합 — "그 리그에서 평소 대비 ΔA가 −10% 이상인 명단을 낸 경기의 득점·결과 변화", "3백 전환 원정 경기의 실점·무승부율" 등.
   유형별 표본·계수·검증 수치를 config/strategy_effects.yaml에. 적합 못 한 유형은 임시값 + 카드 표시. 경기당 총 이동 상한은 기존 ±0.5 로그 오즈·λ ±15%.
3-3 감독 패턴(있으면): 같은 감독이 같은 조건(홈/원정·상대 강약·동기)에서 비슷한 전략을 쓴 과거 경기의 결과·총골을 근거로 함께 보인다
 (표본 5경기 미만이면 표시만, 확률은 안 움직임).

━━ 4. 카드 ━━
1겹에 새 블록(확정 XI일 때만):
🧠 라인업 전략
 {홈}: {전략} — {근거 한 줄: 예 "4백→3백, 득점자 둘 제외, 공격 −14%"}
 {원정}: {전략} — {근거 한 줄}
 양상: {예: 원정 잠그기 vs 홈 공격}
📊 확률 변화   잠정 → 최종
 {홈} 승  nn% → nn%   무 nn% → nn%   {원정} 승 nn% → nn%
 오버 1.5 / 2.5 / 3.5  nn→nn · nn→nn · nn→nn
- 헤드라인·이유 문단·예상 스코어·보드 판정은 최종 확률로 다시 만든다. 이유 문단에 전략 문장 최소 1개(검열 항목 추가).
- 긴 카드: 자리별 비교표, ΔA·ΔD 계산, 적용된 전략 변수와 이동량, 감독 패턴 표.

━━ 5. 검수 (as-of = 킥오프 50분 전, 확정 XI 녹화) ━━
경기마다 기대하는 판정이 나와야 하고, 잠정→최종 확률 변화를 보고:
 - 강원–부천: 강원 "평소 그대로 + 수비 복귀 2명(황문기·신민하), 중원 복귀 선수 벤치" / 부천 "수비 위주 — 4백→3백, 강릉 3-0 득점자 성예건·가브리엘 제외"
   → 부천 승↓·무↑, 총골↓
 - 인천–포항: 인천 "공격 — 무고사 복귀 선발, 페리어 벤치(후반 카드)", 김건희 복귀 / 포항 "평소 그대로(3백, 기성용 중원)"
 - 가시와–고베: 가시와 "평소 그대로 — 세가와 벤치는 평소 운용, 골키퍼 교체" / 고베 "최정예" (세가와를 결장으로 읽으면 실패)
 - 가시마–감바: 가시마 "공격 위주 — 세아라·스즈키·요시다 3명, ACL 원정 앞두고도 로테이션 없음" / 감바 "제바리 벤치"
 - 대전–전북: 양 팀 센터백 경고 누적 대체 자원 — "수비 재편"
보고: 경기마다 2-1 사실표, 전략 판정과 근거 id, 검사 결과, 적용 변수·이동량, 잠정→최종 확률, 1겹 카드 전문.
계약: 예상 XI로 전략 판정 금지 / 수치와 반대인 판정 버림 / 교체 전문 선수 벤치를 결장·약화로 읽지 않음 / 전략 문장이 최종 확률과 같은 방향.

금지: 전략을 이야기로만 쓰고 확률 미반영 / 적합 없는 계수를 표시 없이 사용 / 시장으로 확률 움직이기 / EV·금액 / git stash·checkout·restore·reset.
