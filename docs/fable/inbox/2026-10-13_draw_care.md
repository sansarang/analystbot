# 🔴🔴 수정 지시 — 확률 요약 블록 간소화 + 무승부 신중 처리

> 사용자 지시 2026-10-13(밤) — **원문 그대로**(옮겨 적으며 고치지 않는다)

1. 확률 요약 블록 (카드 맨 위 · 표 3개 → 아래 형식)
- 승무패: 홈 / 무 / 원정 % — 한 줄.
- 핸디: 홈 기준 한 줄만 — −2.5 / −1.5 / −0.5 / +0.5 / +1.5 / +2.5.
  원정 줄은 지운다(원정 +x = 100 − 홈 −x). 표 밑에 "원정 = 100 − 홈 반대 줄" 한 줄.
- 오버/언더: 두 팀 합계 오버 한 줄만 — 0.5 / 1.5 / 2.5 / 3.5 / 4.5. 언더 줄 지움(언더 = 100 − 오버).
- 역배: 약팀 승 % · 강팀 미승 %(= 무 + 약팀 승) — 한 줄.
- 블록 끝에 무승부 신뢰 표시 한 줄(아래 2-④).
- 다른 단계(⑯·⑱)의 중복 표는 그대로 두되, 요약 블록은 위 네 줄 + 무 표시만.

2. 무승부 신중 처리 (확률 경로 변경은 판정 규칙 v2+(d) 통과 전 금지 — 먼저 측정)
① 무 보정 측정 — 0-0 포함 백필 전 표본(2,582경기 + 리그별)
   - 구간별(무 예측 0~20 / 20~25 / 25~30 / 30%+) 예측 평균 vs 실측 무승부율 · 경기 수.
   - λ 합 구간별(< 2.2 / 2.2~2.8 / > 2.8) · 두 팀 λ 차 구간별(|Δλ| < 0.3 / 0.3~0.7 / > 0.7) 같은 표.
   - 리그별(J1·K1·챔피언십·MLS·세리에A·PL) 같은 표. 대륙 대회는 표본 붙는 대로.
② 무와 엮인 줄 실측 — 같은 표본에서 강팀 미승 · ±0.5 핸디 · 오버 1.5/2.5 · 0-0 · 1-1 예측 vs 실측.
③ 후보 시험 (ρ 는 폐기 상태 — 다시 쓰지 않는다)
   - D1: 구간별 무 보정(교차 판 적합 · 시즌 밖 검증) — 늘린 무 몫은 승·패에서 비례로 뺀다.
   - D2: 저득점 칸(0-0·1-1) 질량 보정 — 스코어 격자에서 직접.
   - 판정 = 규칙 v2 (a)(b)(c)(d) + 무 구간 보정 오차(예측−실측) 절댓값 감소. 둘 다 탈락이면 경로 그대로.
④ 카드 표시 (측정 결과 나오는 즉시 · 확률 값은 안 바꾼다)
   - 무 % 옆에 "백필 실측: 이 구간 예측 x% → 실측 y% (n경기)".
   - 편차 ≥ 3%p 이면 🟡 "무 과소/과대 구간" — 그 경기의 강팀 미승·±0.5 핸디·오버 1.5 줄에도 같은 표시.
   - 결론이 무에 걸린 줄(강팀 미승·DNB·+0.5)이면 방아쇠에 "무 구간 편차" 한 줄.
