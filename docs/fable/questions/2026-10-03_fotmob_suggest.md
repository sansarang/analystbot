## ⚠️ robots — 내가 멈춘 자리

```
www.fotmob.com/robots.txt      User-agent: *  Allow: /  🔴 Disallow: /api/*
apigw.fotmob.com/robots.txt    **404**(파일이 없다)
```

🔴 두 가지가 부딪친다:
- `apigw.fotmob.com` 은 **다른 호스트**이고 robots 가 없다. 이 저장소의 규약은
  *"robots 못 읽었다 — 허용으로 본다"* 이고 `app/net.py` 가 그렇게 돈다.
- 그런데 `www.fotmob.com` 은 **자기 API 경로를 막고 있다**. 같은 회사의 API 를
  다른 호스트에서 부르는 것이 그 뜻을 따르는 것인지 **나는 단정할 수 없다.**

⚠️ **긁는 것이 아니다** — 공개 자동완성 엔드포인트를 **질문 하나당 한 번** 부르고
   캐시한다. 프록시·UA 위장은 없고 UA 는 봇이라고 밝힌다(절대규칙 3).
🔴 이 저장소는 이미 `www.fotmob.com` 의 **경기 페이지**를 열고 있다(사용자 승인 아래).
   자동완성은 그 페이지를 **찾기 위한** 것이고 여는 양을 **줄인다**(엉뚱한 페이지를
   덜 연다 — 실측: 열기 예산 6건을 다른 팀 경기에 태우던 것이 사라진다).
