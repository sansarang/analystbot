# 갈림길 — **ESPN 을 소스로 쓰나** (2026-10-01)

## 사실 (실측)

```
www.espn.com/robots.txt
  User-agent: anthropic-ai     Disallow: /        ← 앤트로픽 크롤러를 이름으로 거부
  User-agent: GPTBot           Disallow: /
  User-agent: CCBot            Disallow: /
  ...
  User-agent: *                (관리·박스스코어·로그인 등 개별 경로만 거부)

우리 UA = "AnalystBot/3.0 (sports analysis; contact via telegram)"
→ `*` 규칙이 적용되고, 기사·일정 경로는 **허용**이다.
→ `app/net.py` 의 robotparser 가 실제로 **허용으로 판정했다**(녹음 로그).
```

## ✅ **닫혔다 — 사용자 지시 2026-10-03**

> espn 소스로 쓰고 , ① 무게를 확률로 둘지 근거와 곱할지(A/B/C) 이거는 딥서치 해서 찾아라..

🔴 **답: 쓴다.** `www.espn.com` 을 소스 지도에 넣는다.

| 무엇 | 어떻게 |
|---|---|
| `www.espn.com` | ✅ **쓴다** — robots `*` 규칙이 허용하고 UA 를 숨기지 않는다 |
| `site.api.espn.com` | ❌ 그대로 **안 쓴다** — robots 가 Access Denied 다(허가 확인 불가) |
| 🔴 **배당** | ESPN 경기 페이지 HTML 에 `Open/ML/Total/Spread` 가 들어 있다. 절대규칙 6 대로 **판정 경로·카드에 넣지 않는다** — 파서가 그 칸을 **읽지 않는다**(계약이 막는다) |

⚠️ 기동 시 `mark_dead` 를 넣지 않는다 — 그것이 "안 쓴다" 의 처방이었다.

## 〔지난 판〕 내 해석 (사용자 확정 대기였다)

**쓸 수 있다.** 근거:

- 절대규칙 3 이 금지한 것은 *"프록시·UA 위장"* 이고, 우리는 **이름을 숨기지 않는다.**
- `anthropic-ai` 는 앤트로픽의 학습·크롤링 봇이다. 이 봇은 **사용자 본인의 분석
  도구**이고 다른 주체다 — 같은 이름을 쓰면 오히려 거짓이다.
- ESPN 의 `*` 규칙이 우리를 허용한다. robots 는 그렇게 읽는 것이다.

⚠️ **반대 해석도 가능하다**: ESPN 은 "AI 봇은 오지 마라"는 뜻을 여럿 나열했고,
   목록에 없는 새 이름으로 들어가는 것은 그 뜻을 피하는 것이다.

🔴 **규칙 해석은 사용자가 정한다**(지시 2026-09-30). 한 줄만 답해 주면 된다.

| 답 | 무엇을 한다 |
|---|---|
| **쓴다** | 그대로 둔다(코드가 이미 그렇다) |
| **안 쓴다** | `app/net.py` 의 기동 시 `mark_dead("www.espn.com", "사용자 지시")` |

## 🔴 `site.api.espn.com` 은 **이미 안 쓴다**

robots.txt 자리가 **Access Denied** 로 답한다 — 허가를 확인할 수 없다.
우리 규약의 *"읽을 수 없으면 허용"* 은 robots 가 **없는** 경우를 뜻하고,
**거부로 답하는** 자리는 아니다.
