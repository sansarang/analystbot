## 🔴 사용자 물음 *"뭘쌓는데???"* — **그 물음이 구멍을 찾았다**

전 판 원장은 `{market, hit}` 둘만 쌓았다. 그러면 **쌓아 봐야 아무것도 못 묻는다.**
`survive.grade` 가 결과 확률을 계산해 놓고 **버리고** 있었다.

### 원장 한 줄 — 지금 쌓는 것 (실측)

```
result_score          3-2
result_probability    0.038028        ← 🔴 그때 이 결과에 준 확률
covered               true            ← 결과를 그렸나
realized_scenario_id  D               ← 어느 시나리오였나
card_verdicts_result  홈 승   none 생존 0.5132 맞음 true
                      오버 2.5 none 생존 0.4236 맞음 true
                      언더 2.5 none 생존 0.5764 맞음 false
                      원정 승 none 생존 0.1833 맞음 false
시나리오별           A 0.184/근거 4.6 · B 0.093/2.2 · C 0.132/0.4 · D 0.111/0.4 · E 0.092/0.3
```

🔴 **격자 64칸은 저장하지 않는다** — `λ`(2.14 / 1.079) 두 수를 적고 채점이 그것으로
**다시 만든다**. 계약이 *"되살린 격자가 같은가"* 를 본다.

### 그래서 N 줄이 쌓이면 **물을 수 있는 것**

| 물음 | 어느 칸으로 |
|---|---|
| 등급이 뜻이 있나 — *"낸다"가 "소액"보다 더 맞나* | `card_verdicts_result.verdict` × `hit` |
| 생존 수가 교정돼 있나 — *0.8 이라 한 것이 80% 맞나* | `survival` × `hit` |
| 확률이 교정돼 있나 — *0.11 이라 한 것이 11% 나나* | `result_probability` 의 분포 |
| **시나리오를 아예 안 그린 비율** | `covered = false` 의 비율 |
| 어느 시나리오가 실제로 나나 — 난타전 규칙이 값어치가 있나 | `realized_scenario_id` 분포 |
| 예측을 **안 한** 경기는 몇 건인가 | 채점이 `건너뜀` 으로 센다(원장에 줄이 없다) |
| **λ 보정 계수** (결장이 득점을 얼마나 깎나) | `lam_home/away` × `result_score` |

⚠️ **아직 못 묻는 것**: `missed_variables`(경기 후 드러난 미수집 변수)는 **비어 있다** —
경기 후 분석이 필요하고 자동으로 채울 길이 없다. 비운 채로 둔다(지어내지 않는다).
