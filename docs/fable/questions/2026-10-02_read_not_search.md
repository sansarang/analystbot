# 🔴🔴 **핵심은 "검색"이 아니라 "읽기"다** — 사용자 진단 2026-10-02

## 사용자 원문 (요지)

> 내가 찾는 방식과 봇이 찾는 방식은 근본적으로 다르다. … "심층"인 이유는 **읽고,
> 틀린 걸 버리고, 각도를 바꿔 다시 찾는 반복**에 있다. 한국어로 쳐서 손흥민이 나오면
> 나는 그게 남자팀이라는 걸 **읽고 바로 버린다**.

> 마지막 줄이 반복 오류의 직접 원인이다. **리그별 예외를 덧댄다** — 영어 기본값으로
> USL을 고치자 한국이 깨졌다. 언어 순서를 바꾸자 약칭이 거꾸로 붙었다. 한국어로 찾게
> 하자 남자 경기를 물어왔다.

> 니생각대로 해라...대신에 나는 내가 경기예측을 하라고 했을때 **12단계가 완벽하게만
> 돌아가면 된다**..

🔴 진단에 동의한다. 오늘 하루에 그 "덧대기" 패턴이 **세 번** 반복됐고 **세 번 다 내가
만들었다.**

## 🔴 내가 정한 순서 — 사용자 제안을 하나 바꿨다

사용자 제안: 1 추출기 → 2 재검색 루프 → 3 신원 판별 → 4 토너먼트 분리
**내가 정한 것: 1 추출기 → 3 신원 판별 → 2 재검색 루프 → 4 토너먼트**

근거는 오늘 측정이다. 재검색 루프는 **더 많이 찾는다.** 신원이 먼저 서지 않으면
**더 많이 틀린 것을 찾는다** — 한국어로 찾게 한 순간 손흥민이 들어온 것이 그 예다.
루프를 먼저 켜면 그 사고가 **빨라진다.**
그리고 1 과 3 은 사실 같은 것이다: 신원을 내용으로 가리는 재료가 **추출 결과**다.

## ✅ 1단계 — 추출기는 **짓는 게 아니라 잇는 것**이었다

```
app/extract.py   L1 결장 · L2 인용·의도 · L3 순위·동기   — 이미 있었다
app/llm.py       세 스키마 · 본문 대조 · 거절 기록        — 이미 있었다
```

`NOT_WIRED` 에 *"측정 전에 붙이는 것은 추측이다"* 로 미뤄 뒀고, **그 조건이 채워졌다** —
여자 아시안게임에서 변수 4개가 전부 산문에 있었는데 가져온 것은 0건이었다.

### 이은 자리 — §19-b-5 가 지목한 **정확히 그 줄**

```
본문을 연다 → 규칙 파서 → 0건이면 → 🔴 L1~L3 → 그래도 0건이면 사유를 남긴다
```

⚠️ 규칙 파서가 성공하면 **부르지 않는다**(비싸고 틀린다). 본문이 400자 미만이면
부르지 않는다 — 두 문장을 주면 7B 급은 **없는 것을 만들어 낸다.**

### 🔴 그리고 **읽기가 처음엔 안 됐다** — 실측이 프롬프트를 고쳤다

```
1차:  player_name = '결장' · '징계' · '차출'     ← 프롬프트의 낱말을 베꼈다
      진짜 답(장슬기)은 놓쳤다
2차:  player_name = '장슬기' · basis = suspension  ✅
```

고친 것 둘 — **둘 다 필요했다**:
| 무엇 | 왜 |
|---|---|
| 프롬프트에서 열거를 빼고 **보기**를 줬다 | 7B 급은 열거를 보기로 읽는다 |
| 🔴 코드가 **사유 낱말을 이름 칸에서 막는다** | 프롬프트는 부탁이고 **코드가 집행**이다 |

L2 도 같은 꼴이었다: 인용은 맞게 뽑고 `evidence_sentence` 를 비워서 **맞는 발언이
버려졌다.** → L2 는 **인용이 곧 근거**로 본다(본문 대조는 그대로 돈다 · §12-c-6).

```
실측(같은 산문): L1 → 장슬기·suspension · L2 → "준결승 이후 시간이 짧지만…" · 신상우 감독
```

## ⚠️ L1~L3 가 사용자 목록을 **다 못 덮는다**

| 산문에서 얻은 것 | 추출기 |
|---|---|
| 결장·부상·망명·차출 | ✅ L1 |
| 감독 발언 | ✅ L2 |
| 순위·동기 | ✅ L3 |
| **맞대결 전적(43전 4승)** | ❌ 과제가 없다 |
| **휴식일**(준결승 → 3일) | ❌ 없다 |

🔴 §17-b 가 허용한 자리는 **L1~L6** 이다. 늘리는 것은 v4 를 넓히는 일이라
`home_field` 때와 같은 방식(선언 + 근거)으로 한다 — **2·3·4 를 끝낸 뒤**에 본다.
먼저 붙이면 또 "덧대기"가 된다.

## 경계 — 여기를 어기면 전부 무효다

```
🔴 허용: LLM 이 기사에서 **사실을 뽑는다**(선수명·인용·순위)
🔴 금지: LLM 이 "이건 남자팀이다"·"이 자료가 관련 있다" 를 **판정한다**
         → 판정은 코드가 한다. 재검색 신호(관련 0건)도 **추출 결과 수**로 센다
```
계약이 §17-c 다섯 칸(`direction`·`weight`·`strength`·`survival`·`verdict`)을 추출기
코드에서 금지한다(D46 대로 독스트링 제외).
