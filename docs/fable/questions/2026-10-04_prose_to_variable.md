```

  → 추출도 0건 — **산문에 그 사실이 없다**(['L2'])
  → 열었는데 사실 0건(검증거부·파서)
```

### 보이는 하위 원인 둘

**(a) 🔴 세포당 LLM 60초가 열기 20건을 못 당한다.** 한 세포 추적에서
`🔴 LLM 시간 소진 — L2 를 부르지 않았다(60/60초)` 가 **열 번 넘게** 나온다 —
즉 연 페이지 대부분이 **추출기를 한 번도 못 봤다.** 전체 **39회**.

**(b) ⚠️ BM25 가 4,629자를 559자로 줄인다.** 발언은 그 6문단 밖에 있을 수 있다.
`readtext.TOP_PARAS = 6` 은 *"입력이 짧아야 8B 가 정확하다"* 는 사용자 지시에서
온 수인데, **기자회견 기사에는 발언이 여러 문단에 흩어져 있다.**

### ✅ 인용 검증은 **제 일을 했다**

```
추출 L2: 원문 문장이 없다 — {'type': '로테이션_땜질', 'speaker': '**Alex McLeish**'}
```
🔴 Alex McLeish 는 **옛 스코틀랜드 감독**이다 — 모델이 위키 역사 문서에서 이름을
끌어왔고, §12-c-6 인용 대조가 그것을 **거부했다.** 거짓 변수가 안 생겼다.
