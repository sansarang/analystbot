# 갈림길 — 단계 3 게이트를 **"부분 재현 4건"으로 충족**으로 볼 것인가 (2026-09-30)

## 무엇이 갈렸나

v4 §9 단계 3 게이트 원문:

> **게이트 테스트**: v3 §19-g 7건 카세트 재현 + 라이브 재현 + 카오스(1차 소스 dead)

§19-g 원문(부록 §19-g 마지막 문단):

> 일곱 건이 **실제 네트워크 없이 저장된 응답(cassette)으로 재현**되고, 그다음
> 카세트 없이 라이브로 같은 결과가 나와야 단계 통과.

그리고 §13-3:

> **한 단계 안에서도 항목을 건너뛰지 않는다.** 각 단계의 완료 조건은 "전부"다.
> 하나라도 "나중에"로 미루면 **미완료**로 보고한다.

🔴 **7건이 전부 돌지만 넷은 "부분 재현"이다.** 그것을 충족으로 볼지는 §13-3 이
사용자 판정으로 넘기는 자리다 — 리뷰어도 *"부분 재현을 완료로 인정하는 판정은
사용자 몫"* 이라고 올렸다.

## 왜 부분인가 — **자료가 없다. 지어낼 수 없다.**

2026-09-27 페이지는 **다시 녹음할 수 없다.** 저장소에 남은 그날 실측 응답은
**3건**뿐이다:

```
tests/fixtures/2026-09-27/searx_sb.json         ← §19-g-2 소프트뱅크
tests/fixtures/2026-09-27/searx_hiroshima.json  ← §19-g-3 히로시마
tests/fixtures/2026-09-27/searx_astros.json     ← §19-g-5 휴스턴
```

나머지 4건(K리그 일정·카라스코·김건희·라이브 스코어)의 **원본 응답은 없다.**
