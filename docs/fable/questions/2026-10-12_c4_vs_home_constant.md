# 🔴 갈림길 — C4(상성 우위 = 확률 방향)와 **λ 상수**가 부딪친다

**언제**: 2026-10-12 · 지시 2-b(원정 배율 실측)를 넣은 직후.

## 무엇이 부딪치나
원정 배율을 실측으로 걸자 **K리그1 은 홈 이점이 음수**로 나왔다:
```
league:KL1  home_share 1.1784  <  per_team 1.2216   → 홈 ×0.965 · 원정 ×1.035
```
그래서 축 우위가 작으면 **λ 상수가 그것을 뒤집는다**(실측 고정물):
```
축 종합 +0.107(home 우위) · λ 홈 1.288 < 원정 1.310 → 홈 36% < 원정 37%
```
C4 는 *"상성 우위 팀 = S3 확률이 더 높은 팀"* 이라고 적혀 있다 — 지금 구조에서는
**지킬 수 없다**(상수와 축이 서로 다른 말을 할 수 있다).

## 고를 수 있는 길
- **(a) C4 를 그대로 지킨다** — λ 상수(홈/원정 배율)를 **축 이동보다 약하게** 묶는다
  (새 계수: 상수 효과 상한). ⚠️ 실측을 깎는 것이다.
- **(b) C4 를 고친다** — *"상성 우위 = **축 기여** 방향"* 으로 읽고, 상수가 뒤집은
  경기는 카드가 **그 사실을 적는다**(지금 코드가 이미 할 수 있다).
- **(c) K리그1 홈 이점 실측을 다시 잰다** — 음수가 **측정 결함**일 수 있다
  (도구 주석: *"fotmob 이 중립 경기 표시를 안 준다"* · eloratings *"이긴 팀이 먼저
  적힌다"*). 그 뒤에 (a)·(b)를 다시 본다.

## ✅ 결정됨 — 사용자 2026-10-12

> C4를 **"상성 기여의 λ 이동 방향 = 상성 우위 팀 쪽"** 으로 바꾼다. 최종 확률이
> 반대면 카드에 **"상성 X 우위 · 홈 이점이 뒤집음(배율)"** 표시.

🔴 그렇게 넣었다: `ProbOut.move`(상수를 뺀 **상성이 민 방향**)를 계약이 센다 ·
   최종 확률이 반대면 `probmodel` 이 사유에 그 글자를 적는다.
⚠️ 그리고 **(c) 도 함께 했다** — K리그1 홈 이점을 **여러 시즌**으로 다시 쟀다
   (한 시즌 음수는 잡음이었다 · 아래 1번 결과).
