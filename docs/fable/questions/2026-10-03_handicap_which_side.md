## 실측 — 엘살바도르 vs 자메이카 (2026-10-03)

보드 블록이 핸디 1.5 를 **두 번** 냈다. 같은 기준선인데 **누가 favorite 인지 모르기
때문에** 양쪽 관점을 다 적은 것이다:

```
▸ 핸디 1.5    El Salvador -1.5  0.0667  │  Jamaica +1.5      0.9333
▸ 핸디 1.5    Jamaica -1.5      0.0667  │  El Salvador +1.5  0.9333
```
→ `Jamaica +1.5` 와 `El Salvador +1.5` 가 **둘 다 0.9333** 으로 `소액` 등급을 받고,
   미러 가드가 둘 다 거뒀다 → **■ 8 결론: 살아남는 마켓 없음.**

⚠️ 어제 콜롬비아 vs 파라과이에서 당신이 *"이거는 둘다 핸디잖아"* 라고 한 그 모양이
   **없어진 것이 아니라 침묵으로 바뀌었다.** 둘 다 내는 것보다는 낫지만, 0.9333 짜리
   줄이 손에 있는데 아무 말도 안 하는 것도 답은 아니다.

## 🔴 뿌리 — `our_board` 가 핸디를 **여덟 개** 만든다

```python
OUR_HANDICAPS = (-0.5, 0.5, -1.5, 1.5)
for ln in OUR_HANDICAPS:
    for team in (game.home, game.away):     # 4 × 2 = 8 개
```
🔴 실제 핸디 기준선은 **둘**(0.5 · 1.5)이고 각각 **마켓 하나**다 —
`El Salvador -1.5` 와 `Jamaica +1.5` 는 **같은 마켓의 두 쪽**이다.
여덟 개를 만들면 같은 마켓이 **favorite 을 바꿔** 두 번 생긴다.
