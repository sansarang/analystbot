# 막힘 — 새로 만든 `contract-reviewer` 를 이 세션에서 띄울 수 없다 (2026-09-29)

## 사실

`.claude/agents/contract-reviewer.md` 를 사용자 지시대로 **읽기 전용**으로 다시
만들었다(도구 `Read, Grep, Glob`). 계약 4건이 그것을 잠근다. 파일은 실재한다:

```
$ ls -la .claude/agents/
-rw-r--r--  contract-reviewer.md  5,941B  2026-09-29 22:20
$ head -4 .claude/agents/contract-reviewer.md
---
name: contract-reviewer
description: 커밋 전 불변식·규율 점검. 구현하지 않는다. PASS/FAIL 과 근거(파일:줄)만 낸다.
tools: Read, Grep, Glob
```

🔴 **그런데 띄우면 이렇게 답한다:**

```
Agent type 'contract-reviewer' not found.
Available agents: claude, claude-code-guide, Explore, general-purpose, Plan,
                  statusline-setup
```

두 번 시도했고 같았다. **에이전트 목록은 세션 시작 때 고정된다** — 이 세션에서
`.claude/agents/` 에 새로 넣은 것은 보이지 않는다.
(⚠️ 반대 방향은 반영됐다: 09-27 에 그 파일을 지웠을 때 "no longer available"
 알림이 왔다. 삭제는 알아채고 추가는 못 알아채는 것으로 보인다 — 실측.)

## 그래서 채우지 못한 것

v4 §11-5 는 완료 보고서에 **"리뷰어 PASS 원문"**을 요구하고 *"하나라도 빠지면
미완료"* 라 한다. 사용자 지시는 *"만든 뒤 단계 0·1 보고서를 소급 리뷰해 PASS
원문을 채운다. **단계 1 승인은 그 뒤.**"* 였다.

🔴 **그 칸을 채울 수 없다.** 그러면 §13-2 로 단계 2 에 못 간다.

⚠️ 대체로 `Explore`·`general-purpose` 를 쓸 수 있지만 **쓰지 않았다** —
   둘 다 `Bash` 를 갖는다. 사용자 지시가 *"Bash·Edit·Write 없음"* 이고, D69 는
   리뷰어가 트리에 쓸 수 있었기 때문에 난 사고다. **도구를 회수해 불가능하게
   만드는 것**이 그 계약의 요지이므로, 도구가 더 많은 에이전트로 대신하면
   그 결정을 무르는 것이다. 내가 정할 일이 아니다.
