# 🔴 갈림길 — **보드 없이 "간다/조건부/접는다"를 무엇으로 가르나**

> 물은 날 2026-10-13 · 사용자 답 **대기**

## 무엇이 막혔나

예측 지시 §0 은 *"배당·시장 확률 쓰지 않는다 … **결론은 봇 확률(%)만으로**"* 이고
§3 은 결론 줄에 **간다/조건부/접는다**를 요구한다. 그런데 운영 카드의 결론은

> ⏸ **보류 — 보드가 없다.** 평가할 마켓 줄이 없어 등급을 붙이지 않는다

다(세 카드 모두). 등급·결론이 **보드(마켓 줄)에 매여 있다** — v6 §7 의 규칙이고,
그 규칙은 *"평가할 줄이 없으면 등급을 안 붙인다"* 는 뜻이다.

🔴 **방향 줄은 고쳤다**(열이 우리뿐이면 그 열로 정한다 · 계약 DR1~DR3). 남은 것은
**간다/조건부/접는다 의 문턱**이고, 그것은 **규칙 선택**이라 내가 고르지 않는다
(CLAUDE.md: 묻는 곳은 하나다 — 사용자).

## 고를 수 있는 것

| | 규칙 | 뜻 |
|---|---|---|
| **(가)** | 확신 구간 **상위 30% 안** + 대회 상한 없음 → **간다** · 구간 안 + 상한 조건부 → **조건부** · 구간 **밖** → **접는다** | 구간표가 이미 측정값이다(문턱 44.8%) · 보드가 없어도 돈다 |
| **(나)** | 보드 없으면 **결론도 보류**(지금 그대로) · 방향·구간만 적는다 | 지시 §3 의 결론 칸이 늘 빈다 |
| **(다)** | 최고 확률 절대값으로 가른다(예: ≥55% 간다 · 45~55% 조건부 · <45% 접는다) | 손값 문턱이다 — 측정 근거가 없다 |

🔴 **내가 이번 보고에 쓴 것은 (가)** 다 — 요약표의 `접는다`(포항–조호르) ·
`조건부`(상하이–대전)가 그 규칙으로 나온 글자다. ⚠️ **카드 안에는 안 넣었다**
(규칙을 코드에 박기 전에 답을 받는다).
