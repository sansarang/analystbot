# 갈림길 — 봇이 **무엇으로 검색하나** (2026-09-27)

## 무엇이 갈렸나

§19-f: *"검색·페이지 열기는 인벤토리(§18-c)에 있는 무료 수단만. 유료 검색
API 0건."* 🔴 **그 무료 수단이 무엇인지 정해지지 않았다.**

§19-b 의 탐색 루프는 검색으로 시작한다("넓게 던진다"). 그런데 지금 봇에는
검색 수단이 **없다**. 그래서 §13 소스 중 **URL 로 직접 닫히는 것만** 돌아간다.

| 질문 | 검색이 필요한가 | 지금 |
|---|---|---|
| MLB 일정·예고 선발·순위·IL | ❌ statsapi 로 닫힌다 | ✅ **돌아간다** |
| NPB 일정·예고 선발·라이브·등록 명단 | ❌ npb.jp 로 닫힌다 | ✅ **돌아간다** |
| NPB 일일 公示(登録·抹消) | ⚠️ URL 미확인 | 🔴 막힘 |
| 확정 라인업 (西スポ·安芸の者·中日スポーツ…) | ✅ 필요 | 🔴 막힘 |
| 감독 인용·의도 (§6) | ✅ 필요 | 🔴 막힘 |
| 선발 최근 창 (팀 블로그·비트 기사) | ✅ 필요 | 🔴 막힘 |
| 반증 추적 (§7-5c) | ✅ 필요 | 🔴 막힘 |
| KBO·K리그·CPBL 전반 | ✅ 필요 | 🔴 막힘 |

⚠️ **막힌 것을 조용히 두지 않았다.** `app/net.Search` 는 구현이 없고, 그 포트를
쓰는 세포는 `unknown` 을 내며 사유에 **"검색 수단 미정"**을 적는다. 계약
`test_검색_수단이_없으면_그렇게_적는다` 가 그것을 잠근다.

## 갈래

| 갈래 | | 걸리는 것 |
|---|---|---|
| (a) **DuckDuckGo HTML** (`html.duckduckgo.com/html/`) | 키 없음·무료 | robots·약관을 읽어야 한다. 자동 조회를 금지하면 §14-12 위반이라 못 쓴다 |
| (b) **Bing/Brave/Google 무료 티어 API** | 안정적·robots 문제 없음 | 무료 한도가 있고 **키가 필요하다.** "유료 API 0건"의 경계가 무료 티어를 포함하는지 사용자 결정 |
| (c) **RSS·사이트맵만** — 매체별 피드를 직접 구독 | 검색이 아예 필요 없다 · robots 문제 없음 | 매체마다 피드를 찾아 등록해야 한다(§13 표를 피드 표로 바꾸는 일). 피드 없는 매체는 못 쓴다 |
| (d) **검색을 포기하고 URL 로 닫히는 리그만 운영** | 지금 상태 | MLB·NPB 만 돈다. KBO·K리그·CPBL 은 카드가 안 나온다 |

## 🔴 내 의견은 (c) + (b)

**(c) 가 규율과 가장 잘 맞는다** — §13-a 가 이미 매체를 **이름으로** 지목하고
있다. 검색으로 매체를 찾는 것이 아니라 **지목된 매체의 피드를 구독**하면
"넓게 던진다"가 필요 없어지고, robots 문제도 없고, 같은 검색어 반복 금지
규칙(§12-b)도 무의미해진다. 지연은 피드 주기가 정한다.

그래도 (b) 가 함께 필요하다 — **반증 추적(§7-5c)은 피드로 안 된다.** "카라스코
최근 등판" 같은 질문은 그 조건을 겨냥해 **찾아야** 한다. 그것만 검색 API 로
하고 나머지는 피드로 간다면 호출 수가 작아 무료 한도 안에 들어온다.

⚠️ **(a) 는 권하지 않는다.** DuckDuckGo HTML 엔드포인트는 약관·robots 확인 없이
쓰면 §14-12(우회 금지)에 걸린다. 확인 결과가 거부면 쓸 수 없고, 허용이어도
차단당하면 그날 전 리그가 죽는다.

## 답이 필요한 것

1. **무료 티어 키가 "유료 API 0건"에 걸리나?** 걸리지 않으면 (b) 를 반증 추적에
   쓸 수 있다.
2. **(c) 로 갈 때 §13 표를 피드 표로 바꾸는 작업을 승인하나?** 매체마다 피드
   URL 을 실측해야 한다 — §19-e 점수표가 그 결과를 쌓는다.
3. 그 전까지 **MLB·NPB 만 운영**하는 것이 맞나? (d) 를 임시로 받는다는 뜻이다.

## 곁가지 — NPB 일일 公示 URL

§13-a 가 "NPB 공시(登録・抹消)"를 지목하는데 그 URL 을 못 찾았다.
`npb.jp/announcement/2026/` 는 팀별 **등록 선수 명단**(7월 31일 기준)만 링크하고,
`announcement_MMDD.html` 은 404 였다(실측 2026-09-27).
🔴 추측해 붙이지 않았다 — `npb.collect.KOJI_URL_UNKNOWN` 에 그렇게 적혀 있다.
⚠️ 다만 팀별 명단 페이지의 `選手登録公示以降の動き` 절에서 **트레이드 전출**은
   잡힌다(실측 소프트뱅크 3명). 부상·말소는 그 절에 없다.
