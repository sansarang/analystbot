## ⚠️ 내가 멈춘 자리 — 그리고 사용자가 지시한 자리

thesportsdb robots 에 이 줄이 있다:

```
Content-Signal: ai-train=no, search=yes, ai-input=no
```

🔴 `ai-input=no` 는 **우리 용도를 직접 지목한다.** 절대규칙 3 의 뜻(사이트가 거부한
것은 안 한다)과 부딪치므로 **내가 고르지 않고 사용자에게 알렸다.**
→ 사용자가 **③** 으로 다시 지시했다. 그래서 쓴다. 그 경위를 여기 남긴다.

지키는 것:
- 🔴 **학습에 쓰지 않는다**(`ai-train=no`) — 이 저장소는 모델을 학습시키지 않는다.
- 🔴 **긁지 않는다** — 공개 API 엔드포인트만 부른다. 페이지 HTML 을 받지 않는다.
- 🔴 **키·카드가 없다** — 공개 테스트 키 `3`(§11-7 유료 API 0건 정의 안).
