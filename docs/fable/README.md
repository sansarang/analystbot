# 페이블 협업 폴더 — 규약

[CC-1 2026-09-25 지시문 `cc_collab_0925`]

지시문·보고·자료가 **파일로** 오간다. 채팅 복붙 왕복을 없애는 것이 목적이다.

| 폴더 | 무엇이 들어오나 | 누가 넣나 |
|---|---|---|
| `inbox/` | 페이블 지시문 `<날짜>_<이름>.md` | 사용자 |
| `done/` | 실행이 끝난 지시문 (이동) | Claude Code |
| `reports/` | 실행 보고서 `<지시문이름>_report.md` | Claude Code |
| `questions/` | 갈림길 질문 `<날짜>_<주제>.md` | Claude Code → 사용자가 페이블에 올린다 |
| `answers/` | 페이블의 답 | 사용자 |
| `exports/` | 페이블이 요청한 자료 (json + md) | Claude Code |

🔴 **지시문은 `inbox/` 에서만 받는다.** 채팅으로 온 지시문도 먼저 이 폴더에
   저장하고 `/fable-run` 으로 실행한다 — 맥락이 파일에 남아야 다음 세션이 읽는다.

🔴 **갈림길이면 멈춘다.** 두 갈래로 갈리면 고르지 않고 `questions/` 에 쓰고
   끝낸다(CLAUDE.md §2갈래). 추측으로 고른 것은 측정이 아니라 취향이다.

## 보고서 형식 — 다섯 절 고정

`reports/*.md` 는 **반드시** 아래 다섯 절을 가진다. 계약이 잠근다
(`tests/meta/test_fable_report_format.py`).

```markdown
# <지시문> · 커밋 <해시들> · 배포 <시각|미배포>

## 완료 조건 원문
지시문에서 "무엇이 되면 끝인가"를 **그대로 옮긴다.** 요약하지 않는다.

## 전/후 표
숫자로. 무엇이 몇에서 몇이 됐나.

## pytest 마지막 20줄
실제 출력. "통과했다"는 주장이 아니라 출력이다.

## 고쳐 쓴 기존 테스트(목록·사유)
없으면 "없음". 있으면 왜 옛 계약이 틀렸는지.

## 남은 것
안 한 것과 그 이유. 없으면 "없음".
```

⚠️ `_` 로 시작하는 파일(`_last_commit.md` 등)은 훅이 만드는 **초안 재료**라
   계약에서 뺀다 — 보고서가 아니다.

## 드라이브 공유

`exports/` 와 `reports/` 를 사용자의 드라이브 동기화 폴더에 심볼릭 링크하면
페이블(채팅)이 드라이브로 바로 읽는다. 폴더명은 사용자가 정해 페이블에 알린다.
🔴 Claude Code 에 구글 드라이브 MCP 를 붙이지 않는다.
