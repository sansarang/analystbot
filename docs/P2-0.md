# P2-0 — 축구 피처 적재가 09-14 에서 멈췄다. 원인은 **18일 묵은 차단기**다

## 판별 (지시 3: 휴식기인가 고장인가)

**고장이다.** 소스 양쪽 다 오늘 경기를 주는데 우리만 비어 있었다.
```
The Odds API  soccer_spain_la_liga → 이벤트 19건 (2026-09-15 15:0x KST 실측)
    2026-09-15T17:00Z Espanyol@Rayo Vallecano
    2026-09-15T18:00Z Valencia@Alavés
    2026-09-15T19:30Z Real Madrid@Elche CF
football-data.org  09-15~+2 → PD 7 · DED 1 · ELC 2 · BSA 1 · CLI 2
우리 DB  2026-09-15 축구 → 0경기 (가장 늦은 킥오프 09-14 19:00Z)
같은 창 kbo 8 · mlb 8 · npb 6 은 정상 → 스케줄러 자체는 산다
```

## 원인 — 차단기가 18일째 내려가 있었다

러너 로그가 그대로 말해줬다:
```
WARNING [pipeline] 축구 일정 소스 실패 — 배당(odds)
        (ACL엘리트 · J1 리그 · K리그1 · 덴마크 수페르리가):
        odds: deploy pre-trip: already OUT_OF_USAGE_CREDITS
INFO    [odds] snapshot skipped — 차단 중
```
`api_guard` 원장 원문:
```
odds  {"reason": "credit",
       "at": "2026-08-27T22:46:28.044978+00:00",     ← 18일 전
       "key_fp": "80e290a956ce870e",
       "detail": "deploy pre-trip: already OUT_OF_USAGE_CREDITS"}
football_data · anthropic · perplexity · grok · apifootball → 전부 null
```

🔴 **차단이 담당하는 리그가 곧 피해 범위다.** `_load_soccer_fixtures` 는
   football-data(EPL·라리가·세리에A·분데스리가)와 Odds 이벤트(나머지)를 나눠
   쓴다. 그래서 유럽 4리그는 살아 있었고 **J1·K리그1·덴마크·ACL 이 0건**이었다.
   09-14 이후 전부 0이 된 것은 유럽 리그가 A매치 휴식기에 든 것과 겹쳤기 때문이다
   — 두 가지가 같은 날 겹쳐 "축구 전체가 멈춘 것"처럼 보였다.

## 🔴 잔량은 있었다 — 해제 전 실측 (지시대로 원장에 남긴다)

```
GET /v4/sports/?apiKey=…&all=true      → 200 · x-requests-remaining: 476
GET /v4/sports/soccer_spain_la_liga/events → 200 · 이벤트 19건 · remaining 476
```
그리고 `block_info` 는 **키가 바뀌면 스스로 해제**한다(`api_guard.py:160`).
해제되지 않았다 = **지금 키가 2026-08-27 에 차단된 그 키다.**

→ 같은 키가 **잔량 476 을 들고 18일째 막혀 있었다.** 월 쿼터가 초기화됐는데
  차단기는 그것을 모른다. 이건 별개 결함이고 **P2-0-b** 로 등록한다.

## P2-0-b — 차단기 판정 로직 (등록만, 착수 전)

`api_guard` 의 차단은 **TTL 이 없다.** 설계 의도는 맞다(자동으로 풀면 잔액 없는
키로 계속 호출해 요금만 태운다 — `tools/unblock.py` 독스트링). 그러나:

- 해제 조건이 **키 교체 하나뿐**이다. 쿼터가 월 단위로 초기화되는 제공자에서는
  키를 안 바꾸는 한 영원히 막힌다.
- `W-ODDS-BLOCKED` 워치독이 알리게 돼 있으나(2026-09-02 에 붙였다) **18일 동안
  사람이 풀지 않았다** — 알림이 실제로 갔는지, 갔는데 묻혔는지 아직 모른다.

⚠️ 고칠 방향을 여기서 정하지 않는다. 최소한 재검증(예: 무료 `/v4/sports` 조회로
   `x-requests-remaining` 을 읽어 잔량이 있으면 해제 후보로 올림)이 후보지만,
   **지시받기 전에 구현하지 않는다.**

## 해제 (사용자 지시 2026-09-15)

`railway ssh … python -m tools.unblock --provider odds`
