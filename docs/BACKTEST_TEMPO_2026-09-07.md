## 1. 무엇을 쟀나

핸드오프가 빈칸으로 남긴 두 가지를 사용자가 확정해 주고 시작했다.

- **산출 형태**: `{홈 기대득점, 원정 기대득점, 우위, 격차, 합계}`
- **계산 축**: 선발/불펜 이닝 분할 × 타선 배율. **자료11 전면 제외.**

```
E(홈 득점) = p50(원정선발 이닝) × 원정선발 R/이닝
           + (9 − p50)         × 원정불펜 R/이닝
           × (홈 최근 3경기 평균 득점 / 리그평균 득점)
```

정의는 운영 구현을 그대로 가져왔다 — 손으로 다시 적지 않았다:
`quantiles`(비보간 p50) ← `app/engine/variable_ref.py`,
등판 창 10 · 얇은 선발 기준 3 · 불펜 창 3경기 ← `app/config.py`,
elo ← `app/models/team_elo.compute`.

**누수 방지**: 모든 피처는 `starts_at <` 그 경기 시작 시각. 리그평균과 elo 도
as-of 까지만 리플레이한다.

## 3. 관문 숫자 자체가 판별력이 없다

Wilson 95% 신뢰구간이다.

| 리그·창 | 판정가능 | 일치율 | 95% 구간 | 50% 포함 | 55% 포함 |
|---|---:|---:|---|:--:|:--:|
| kbo 전체 | 74 | 55.4% | [44.1%, 66.2%] | 예 | 예 |
| kbo 최근30 | 28 | 60.7% | [42.4%, 76.4%] | 예 | 예 |
| npb 전체 | 68 | 47.1% | [35.7%, 58.8%] | 예 | 예 |
| npb 최근30 | 30 | 50.0% | [33.2%, 66.8%] | 예 | 예 |
| mlb 전체 | 170 | 52.4% | [44.9%, 59.7%] | 예 | 예 |
| mlb 최근30 | 30 | 56.7% | [39.2%, 72.6%] | 예 | 예 |

**모든 창에서 구간이 50% 와 55% 를 동시에 포함한다.** 즉 이 계산기는
동전던지기와 구분되지 않고, **"30건 관문"은 통과/미달을 가를 수 없다** —
n=30 의 구간 폭이 ±17%p 다. 다음에 관문을 다시 세울 때는 표본을 리그당
최소 200건대로 잡거나, 방향 대신 오차(연속값)를 기준으로 삼아야 한다.

## 4. 왜 틀렸나 — 추론이 아니라 그 경기의 입력값

최악 사례 `2026-08-19 Kiwoom Heroes @ Lotte Giants` (예측 4.9−**40.4**, 실제 4−5):

| 축 | 값 | 표본 |
|---|---|---|
| 원정 선발 알칸타라 p50 이닝 | 4.0 | **이전 등판 1건** |
| 원정 선발 R/이닝 | 2.0 (= 18실점/9이닝 환산) | 같은 1건 |
| 원정 불펜 R/이닝 | 2.625 | 3경기 |
| 홈 타선 배율 | 1.91 | 3경기 (8·8·15득점) |

`(4.0 × 2.0 + 5.0 × 2.625) × 1.91 = 40.4`

**표본 1~3짜리 비율 셋을 곱했다.** 각 축의 잡음이 상쇄되지 않고 곱해져
분산이 폭발한다 — 예측 득점 sd 5.25 vs 실제 3.82 (KBO), 최대 예측 40.4점
(실제 최대 18점). 10점 초과 예측이 KBO 76경기 중 20건이다.

## 5. 절제 실험 — 수축을 넣으면 오차는 잡히지만 방향은 안 산다

이닝당 실점을 리그평균 쪽으로 수축(가상 이닝 k), 타선 배율을 1.0 쪽으로 수축.

| 변형 | KBO 일치율 / MAE | NPB 일치율 / MAE | MLB 일치율 / MAE |
|---|---|---|---|
| 확정 스펙 (수축 없음) | 55.4% / 4.40 | 47.1% / 2.91 | 52.4% / 3.49 |
| 타선만 수축 k=3 | **59.5%** / 3.91 | 45.6% / 2.77 | **54.1%** / 3.15 |
| 불펜만 수축 k=20이닝 | 51.4% / 3.97 | 41.2% / 2.84 | 51.2% / 3.27 |
| 선발만 수축 k=20이닝 | 50.0% / 4.12 | 38.2% / 2.59 | 48.8% / 3.21 |
| 세 축 전부 수축 | 51.4% / **3.27** | 38.2% / **2.30** | 48.8% / **2.65** |
| 전부 수축 + 선발 3등판 이상 | 66.7% / 3.78 (n=**19**) | 40.0% / 1.80 (n=**5**) | 52.2% / 2.81 (n=**23**) |
| *(참고) 리그평균 기준선* | — / 3.07 | — / 2.20 | — / 2.50 |

읽는 법:

- **수축은 오차만 고친다.** 세 축을 다 수축하면 MAE 가 리그평균 기준선에
  근접하는데(3.27 vs 3.07 등), 그건 좋아진 게 아니라 **예측이 상수로
  수렴한 것**이다 — 예측 sd 가 5.25 → 1.69 로 무너진다.
- **방향은 어떤 변형에서도 살아나지 않는다.** 수축을 넣을수록 오히려
  떨어진다(KBO 55.4→51.4, NPB 47.1→38.2, MLB 52.4→48.8).
- 마지막 줄(66.7%)은 **표본 19·5·23** 이다. 읽지 마라.
- NPB 는 모든 변형에서 50% 아래다. 다만 구간이 넓어 "역상관"이라고
  단정할 수 없다 — **모른다**가 맞다.

# 9. 총득점 재시험 (2026-09-07, 관문 선언 후 실행)

## 9-1. 실행 전에 고정한 관문

사용자 지시로 **결과를 보기 전에** 선언했고, 보고 후 옮기지 않았다.

| 항목 | 선언 내용 |
|---|---|
| 표본 | n=30 이 아니라 **채점 가능 전체** — KBO 76 · NPB 69 · MLB 170 |
| 채점 대상 | 예측 총득점(홈+원정 기대득점)의 **오버/언더 방향** |
| 선(line) | 경기별 **시장 totals 라인**(시작 직전 스냅샷의 북 중앙값) 있으면 그것, 없으면 as-of **리그 평균 총득점**. MLB 고정 9.5 는 부가 보고 |
| (a) | 방향 일치율의 **Wilson 95% 하한**이 세 기준선(항상 오버·항상 언더·리그평균선)을 **전부** 초과 |
| (b) | 총득점 MAE 가 **리그평균 상수** 기준선보다 개선 |
| 판정 | (a)·(b) **둘 다** 충족해야 총득점 마켓 한정 주입 검토 |
| 대상 스펙 | **확정 스펙(수축 없음)**. §5 수축 변형은 관문 선언 이전 공표값이라 정보로만 싣고 판정에 쓰지 않는다 |
| 푸시 규약 | 실제 총득점 == 선 → 방향 분모에서 제외. 예측 == 선 → 미적중 (우리·기준선에 같은 자) |

## 9-3. 어디서 무너졌나

- **(b) 는 사실상 전멸이다.** 총득점 MAE 가 "리그평균 총득점으로 찍기"보다
  세 리그 전부 나쁘다(7.02 vs 4.45 · 3.52 vs 3.06 · 4.92 vs 3.72). h2h 때와
  같은 원인 — §4 의 분산 폭발이 합계에도 그대로 실린다.
- **(a) 는 MLB 가 가장 근접했으나 '항상 언더'에 졌다.** 58.6%(하한 51.0%) 대
  항상언더 54.4%. 고정 9.5 선에서는 59.4%(하한 51.9%) 대 61.2% 로 **점추정
  자체가 진다.** 오버/언더는 리그 득점 환경이 라인보다 낮기만 해도 한쪽
  고정이 강해지는 마켓인데, 그 벽을 못 넘었다.
- **리그평균선 기준선(2.6%·2.9%·10.7%)은 읽지 마라.** 폴백 구간에서는 선이
  곧 리그평균이라 이 예측기가 구조적으로 선과 동률 → 미적중이 된다
  (KBO 71 · NPB 64 · MLB 134건). 이 기준선이 낮은 덕에 관문이 쉬워지는 것을
  이용하지 않았다 — (a) 는 그것 없이도 오버/언더 기준선에서 이미 미달이다.
- **시장 라인 부분집합(n=5·5·35)은 판별력이 없다.** KBO 80% 는 5경기다.
  NPB 가 (b) 통과로 찍혔지만 역시 5경기 — 판정 근거로 쓰지 않는다.
