# v1.1 분석 고도화 — 단계·규율 (개정 4판)

**적용 범위: 야구(KBO·NPB·MLB) + 축구(EPL·세리에A·라리가·프리메이라리가) 공통.**
축구는 2026-08-31 사용자 결정으로 실전 전환됐다. 각 단계는 종목 분기 없이
양쪽 판정 경로에 동일하게 구현한다. 종목 특성이 다른 곳만 [종목 매핑]으로
명시하고, 명시가 없으면 완전 공통이다.

목표 두 가지:
① 판정·서술을 수동 분석 수준으로 끌어올린다
② **모든 판정이 자동 기록·채점되게 하여, 규율(임계·상한·거부권)이 맞는지를
   시스템 스스로 데이터로 답하게 한다** ← 0단계가 최우선인 이유

## 진행 상황 (2026-08-31 기준)

| 단계 | 내용 | 상태 |
|---|---|---|
| **0** | 픽 레저·캘리브레이션 | **배포 완료** — 첫 채점 1건 실측 |
| **1** | 득점 지원(run_support) · NPB appearances · KBO WHIP | **배포 완료** · 라이브 검증 대기 |
| **2** | 직전 판정 입력 (재판정 델타) | **구현 완료 · 배포 대기**(내일 아침) |
| 3 | 뉴스 근거 원문 동봉 | 미착수 |
| 4 | 시장 괴리 분류 + 엣지픽 | 미착수 |
| 5 | 가치 게이트 | 미착수 (요약 카드만 조기 도입 완료) |
| 6 | 트리거형 딥서치 | 설계만 — [DEEPSEARCH_STAGE6.md](DEEPSEARCH_STAGE6.md) |

**한 단계의 검증이 끝나기 전에 다음 단계를 시작하지 않는다.**
각 단계는 독립 배포 가능해야 한다 — 문제가 생기면 그 단계만 되돌린다.
각 단계 배포 후 **최소 1슬레이트 관찰**하고 다음으로 넘어간다.

## 순서 근거

0이 최우선인 이유: **1~6의 효과는 전부 0의 채점표로만 증명된다.** 측정 장치
없이 고도화를 먼저 넣으면 "좋아졌는지"를 영원히 모른다.

그다음 1→2→3은 데이터·프롬프트만 만지는 저위험 단계, 4→5는 배당이라는 새
입력의 격리가 관건이라 묶어서, 6은 비용·외부 의존이 걸린 최고위험 단계라
마지막이다.

4단계의 엣지 **승격**(confirmed)은 6단계 딥서치가 관문이므로, 6단계 도입
전까지 엣지는 **candidate 표기까지만** — 검증 없는 엣지를 최상위 등급으로
내보내지 않는다.

## 공통 규칙

- 보고 형식: ① 수정 파일·diff 요약 ② 커밋 해시 ③ 테스트 결과 ④ 실측 증거
  ⑤ 다음 단계 진행 여부
- **테스트 실패 시 중단·보고. 테스트를 약화시켜 통과시키지 않는다.**
- 클리핑(야구 0.32–0.68)·확률 임계(58/63)·뉴스 상한(±3%p)은 이 문서 전체에서 **불변**
- 프롬프트 문구는 지시문에 적힌 대로만 추가하고 기존 문구를 임의 수정하지 않는다

## 하지 말 것

- 배당을 **판정·폼·서술 프롬프트 입력**에 넣지 마라 (4·5단계는 후처리 전용)
- 딥서치를 전 경기 상시 실행으로 바꾸지 마라
- 확률 임계·클리핑·뉴스 상한을 이 문서 범위에서 수정하지 마라
- **캘리브레이션 데이터 없이 게이트 수치를 조정하지 마라**
- `pick_ledger`를 Redis TTL 키로 만들지 마라 (영구 DB 테이블이어야 한다)
- 캘리브레이션 표본이 부족한 상태에서 임계값을 바꾸지 마라
- **구 축구 파이프라인(스켈람·배당 기반)은 건드리지 마라 — 신 축구 경로
  (`soccer_trial`)는 v1.1 공통 적용이다.**
  > 개정 근거(2026-08-31): 3판의 "축구 파이프라인은 건드리지 마라"는 축구가
  > v1.1 범위 밖이던 시절의 조항이다. 4판에서 축구가 실전 전환·공통 적용되면서
  > 그 조항의 원래 취지(**구** 스켈람·배당 경로 동결)만 남긴다.

## 완료 판정

6단계 후 1주 운영에서:
- 딥서치 발동률 **≤30%**
- 크레딧 소진 **0회**
- `pick_ledger` **기록·채점 무결손** (판정 전건 기록, 종료 경기 전건 채점)

이후 30~50픽이 쌓이면 주간 캘리브레이션 리포트를 근거로 게이트 임계(58/63)·
원정 프리미엄·확신도 거부권·딥서치 상한·엣지 괴리 임계(8%p)를 재검토한다 —
**그 재검토는 별도 지시로 하며, 이 문서 범위에서는 수치를 바꾸지 않는다.**
