지시서의 *"KBO 14:00 일요일 슬레이트"* 는 **어제(09-06 일) 것이다.**

```

09-07(Mon)  mlb 15경기 01:10 · soccer 7경기        ← 대부분 종료(현재 12:33)
09-08(Tue)  kbo 5경기 18:30                        ← 다음 야구 슬레이트
```
