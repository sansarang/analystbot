단, **이 134경기는 전부 자료12(실력 레이팅) 도입 이전 표본이다.** 진단은

## 1. 우리는 기준선을 이기는가

| | 적중 | 95% CI |
|---|---|---|
| 우리 판정 | 73/134 = **54.5%** | 46.0–62.7 |

방향은 동전보다 낫다. 시장보다는 못하다.

## 2. 그런데 확률의 **크기**는 정보가 아니다

```
Brier    우리 0.2523  ·  상수(기저) 0.2498  ·  시장 0.2422
logloss  우리 0.6978  ·  상수 0.6927        ·  시장 0.6776
```

**상수보다 나쁘다.** "홈 48.5%"를 전 경기에 똑같이 적어내는 것이 우리 확률보다
낫다는 뜻이다. 같은 100경기로 좁히면 우리 0.2583 vs 시장 0.2422.

### 절제 — 확률을 0.5 쪽으로 눌러본다

```
k=1.0(원본) 0.2523 │ k=0.7 0.2499 │ k=0.4 0.2489(최적) │ k=0.0(상수) 0.2500
```

**최적 수축 k=0.4** — 벌어짐의 60%가 잡음이다. 그런데 최적점조차 상수보다
0.0011 나은 정도다. 사실상 정보가 없다.

분포로도 보인다: 우리 sd **0.091** > 시장 sd 0.082. **시장보다 더 자신 있게
말하면서 덜 맞는다.**

## 3. 재판정은 판정을 낫게 만들지 않는다

판정이 실제로 움직인 89경기에서:

| | 적중 | Brier |
|---|---|---|
| 첫 판정 | 50/89 = 56.2% | **0.2470** |
| 최종 판정 | 49/89 = 55.1% | 0.2496 |

- **방향 뒤집기 11건 중 5건만 맞았다 (45.5%)** — 동전던지기다.
- **확신 강화 44건 → 50.0% · 확신 약화 34건 → 64.7%.**
  재판정이 확신을 키울 때마다 그 방향이 틀렸다.
- 라인업이 미확정→확정으로 바뀐 80경기: Brier **0.2478 → 0.2528**.

## 4. 유료 확정이 무료 예비보다 낫지 않다

무료 예비(gemini) → 유료 확정(opus)으로 값이 바뀐 15경기:

```
무료 예비  10/15 = 66.7%  ·  Brier 0.2487
유료 확정  10/15 = 66.7%  ·  Brier 0.2639   ← 적중 동률, 확률은 더 나쁨
```

표본 15건이라 단정할 수 없다. 다만 **유료 호출이 정확도를 올린다는 증거는
지금 없다.**

## 5. 추천 게이트가 역선택을 한다

```
보드만       57/97 = 58.8%
거부권탈락   10/17 = 58.8%
추천          5/15 = 33.3%   ← 우리가 내보내는 픽
가치주의      1/ 5 = 20.0%
```

확률 문턱 탓이 아니다. **같은 확률대(우세 p≥0.58) 안에서** 갈라보면:

```
p≥0.58 전체      38/65 = 58.5%
  그중 추천        5/13 = 38.5%
  그중 추천 아님  33/52 = 63.5%
```

추천은 **라인업 확정**을 요구하고, §3에서 본 대로 확정 후 판정이 나빠진다.
리그를 통제해도 방향이 같다:

```
mlb  확정 55.6%(72) vs 예상 66.7%(12)
kbo  확정 42.1%(19) vs 미수집 80.0%(10)
```

### 개입안을 전부 재봤다 — 어느 것도 적중률을 못 올린다

| 안 | 적중 | Brier | p≥0.58 건수 |
|---|---|---|---|
| 첫 판정 | 55.2% | 0.2506 | 60 |
| 최종 판정(현행) | 54.5% | 0.2523 | 65 |
| 첫·최종 평균 | 55.2% | 0.2509 | 65 |
| 확신 강화 금지 | 54.5% | 0.2524 | 52 |
| 최종 ×0.5 수축 | 54.5% | **0.2491** | **3** |
| 최종 ×0.4 수축 | 54.5% | **0.2489** | **0** |

수축은 Brier를 상수 아래로 내리지만 **추천이 사라진다.** 확률 변환으로는
못 고친다 — 없는 정보를 만들 수 없기 때문이다.
