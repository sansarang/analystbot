# C3 관문 — 플래툰 실측 판정 (2026-09-05)

**판정: 3리그 모두 불가 → 플래툰 전체 보류.**
지시서 규칙: "하나라도 불가 → 종목 통일 원칙대로 플래툰 전체 보류".

필요 조건: **타자 최근 10타석 × 상대 선발 손타입** 분리 집계.
대원칙(최근 3~5경기만)을 지키려면 "최근 창"과 "손타입"이 **함께** 되어야 한다.

| 리그 | 손타입 스플릿 | 최근 창 | 두 축 조합 | 판정 |
|---|---|---|---|---|
| MLB | ✅ `sitCodes=[vl,vr]` | ✅ `type=lastXGames` | ❌ **무시됨** | 불가 |
| KBO | ✅ `ddlSituation=41` 투수유형별 | ❌ 없음 | ❌ | 불가 |
| NPB | ❌ 시즌표뿐 | ❌ | ❌ | 불가 |

## 실호출 근거

### MLB — 두 축이 각각은 되는데 **조합이 안 된다**

손타입 스플릿(시즌 누적):
```
split=vl PA=76  AVG=.246 OPS=.947
split=vr PA=185 AVG=.248 OPS=.890
```

최근 창 + 손타입 조합 요청:
```
hydrate=stats(group=[hitting],type=[lastXGames],limit=5,sitCodes=[vl,vr])
→ type=lastXGames split=None G=5 PA=23 AVG=.222
  type=lastXGames split=None G=5 PA=23 AVG=.222
```
**`split=None` 이 두 번, PA 가 동일하다.** `sitCodes` 가 무시되고 같은
최근 5경기 집계가 두 번 온 것이다. 손타입으로 갈리지 않는다.

### KBO — 손타입은 있으나 최근 창이 없다

`ddlSituation` 옵션 전량:
```
월별 · 요일별 · 구장별 · 홈/방문별 · 상대팀별 · 주/야간별 ·
전/후반기별 · **투수유형별** · 주자상황별 · 볼카운트별 ·
아웃카운트별 · 이닝별 · 타순별
```
`투수유형별`(value=41)이 있지만 **최근 N경기·N타석 스플릿이 없다**
(2026-09-04 실측에서도 동일 확인). 따라서 나오는 값은 시즌 누적이고,
그것은 대원칙이 판정 입력으로 금지한 것이다.

### NPB — 시즌표뿐

`npb.jp` 팀별 개인 타격은 시즌 누적 단일 표다 (2026-09-04 실측).

## 왜 "MLB만"으로 가지 않는가

3리그가 서로 다른 재료로 판정하면 표본이 갈린다. 자료8(타선 시즌)을
폐지할 때와 같은 이유다 — MLB 만 최근 5경기 타격으로 바꾸는 것도
같은 근거로 보류했다.

## 되살릴 조건

- MLB `sitCodes` 가 `lastXGames` 와 조합되거나,
- KBO 기록실에 최근 N경기 스플릿이 생기거나,
- 우리가 타석 단위 로그를 직접 적재해 세 리그를 같은 방식으로 만들거나.

⚠️ 그 전까지 **오늘 선발의 투구 손(자료11 `선발손`)만** 사실로 싣는다.
   손은 오늘의 사실이고, 스플릿 성적은 시즌 누적이라 다르다.
