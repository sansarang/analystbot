## 0. 왜 이걸 먼저 쟀나

"공식 사이트가 robots 허용이고 6칸 키워드가 다 적중한다"까지는 1b 에서 봤다.
그런데 **키워드 적중은 추출 가능 증명이 아니다.** 우리는 같은 실수를 한 번 했다
— 스포츠나비를 `js` 로 오분류해 헤드리스가 필요하다고 적었는데, 나중에 보니
정적 HTML 에 예고선발이 **그대로 있었다.**

그래서 **헤드리스를 말하기 전에 정적부터** 봤다.

---

## 1. 🔴 결론 — 라리가가 된다. 헤드리스 없이.

`https://www.laliga.com/en-GB/match/{slug}` 의 `__NEXT_DATA__`(83.5KB) 안:

```
props.pageProps.data.lineups.home / .away      선수명·등번호·포지션·주장
props.pageProps.data.lineups.home.subs         교체 명단 3,842B
props.pageProps.match.venue                    {"name": "RCDE Stadium"}
props.pageProps.events[].lineup                교체 이벤트
```

실제 값(발췌):
```json
{"id":1274415,"shirt_number":29,"status":"sub","position":12,"captain":false,
 "person":{"name":"Victor Mullerat","nickname":"Mullerat",...}}
```

🟢 **확정 XI · 결장(subs 로 유추) · 경기장**이 정적으로 나온다.
⚠️ 경기 **목록** 페이지에는 없다 — `lineup` 0회. **상세 페이지**여야 한다.
   (목록만 보고 "없다"고 적을 뻔했다.)
