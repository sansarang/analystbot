## 0. 🔴 DS-5 때와 무엇이 다른가 — 이것부터 적는다

DS-5(커밋 `615a462`)에서 나는 **같은 변경을 만들었다가 되돌렸다.** 그때 적었다:

> "내 변경을 통과시키려고 계약 16개를 고치는 것은 **회귀를 숨기는 수**다."

**지금은 다르다.** 사용자가 규칙을 바꾸기로 결정했다. 계약을 고치는 것이
아니라 **규칙이 바뀐 것**이고, 그 차이가 이 문서의 존재 이유다.

## 2. 전/후 — 운영 실측 (2026-09-21 · 최근 2일 · 기사 있는 경기 11개)

```
                       개정 전    개정 후
기사 있는 경기              11        11
LLM 호출                  11         9      ← 2회 절약 (18%)
증거 문단 0 인 경기           2         2
  → 그 경기 처리       창 경로로 호출   미상(no_relevant_paragraph)
```

미상이 된 둘:
```
Saitama Seibu @ Chiba Lotte Marines   (기사 6건)
Orix Buffaloes @ Hokkaido Nippon-Ham  (기사 6건)
```
그 기사 6건에는 **그 경기 이야기가 아예 없었다** — 아시안게임 식사 문제,
다른 팀(한신) 투수 기사.

⚠️ **추출 카드 수는 전/후가 같다.** 그 두 경기는 전에도 쓸 만한 카드를 못
   만들었다(HYC-1 신뢰 관문이 근거 없는 카드를 이미 버린다).
   달라지는 것은 **호출 수**와 **사유의 이름**이다.
   → "호출을 아꼈다"는 참이고 "카드가 늘었다"는 **거짓**이다.

### 🔴 17건 중 **의미가 바뀐 것은 2건뿐**이다

- **#17** — 규칙 개정의 본체다. 폴백 → 미상.
- **#2** — "창"이 "재순위 문단"으로 바뀌었다(이름만. 시험 내용은 같다).

**나머지 15건은 픽스처만 고쳤다.** 이전 본문이 `"본문 1"` · `"x"*600` 처럼
**증거가 없는 글**이었고, 새 규칙에서는 그런 기사로 추출이 일어나지 않아
**시험 대상에 닿지 못한다.**
⚠️ **검사를 느슨하게 한 것이 아니다** — 각 시험이 지키던 것(호출 1회 · 캐시 ·
   등급 순 · JSON 정본 · 게이트 무관)은 **한 줄도 안 바꿨다.**

## 4. 🔴 개정하다가 숨어 있던 결함 하나를 찾았다

```
UnboundLocalError: cannot access local variable 'used'
```
DS-5 배선(`615a462`)이 재순위 경로를 만들 때 `used` 를 폴백 블록 안에서만
초기화했다. 맨 끝 로그가 그것을 쓴다. **지금까지는 항상 폴백을 거쳐서**
가려져 있었고, 규칙 개정으로 그 경로가 사라지자 드러났다.
→ `used` 를 앞에서 초기화하고, 재순위 경로도 입력 자수를 세게 고쳤다.

⚠️ 이것이 "폴백이 결함을 가린다"의 실례다.
