아래를 모아 `docs/fable/reports/status_<날짜>.md` 로 낸다. **읽기 전용.**

| 절 | 무엇 |
|---|---|
| 커밋 | `git log --oneline -20` |
| 테스트 | `pytest -q` 마지막 20줄 (실제 출력) |
| 운영 | `/health` 응답 — 서버 커밋 해시를 로컬 HEAD 와 **대조**한다 |
| 자가점검 | `app.ops.selfcheck` 최근 3일 |
| 커버리지 | `docs/COVERAGE_*.md` 최신본 — **날짜와 함께** 적는다(낡았으면 낡았다고) |
| 미처리 | `ls docs/fable/inbox/` |

## 규율

- 🔴 상태값(SUCCESS·200 OK)은 **의도한 것이 동작한다는 증거가 아니다.**
  `/health` 는 커밋 해시를 대조해야 의미가 있다.
- 커버리지 문서가 며칠 전 것이면 **그 날짜를 적는다.** 최신인 척하지 않는다.
- 이 파일은 보고서 폴더에 들어가지만 **지시문 보고서가 아니다** — 다섯 절
  형식 계약은 `status_` 파일도 검사하므로, 다섯 절을 갖추거나 이름을 `_` 로 시작한다.
